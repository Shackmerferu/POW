1JavaScript (JS)

1.1 Variables: var, let, const

DeclaraciónDetalle
let Definición Declara una variable cuyo valor puede cambiar. Alcance de bloque { }.

Variantes let nombre = valor;

Cuándo usar Cuando el valor va a cambiar más adelante (contadores, acumuladores, datos de entrada).
const Definición Declara una constante: valor fijo que no se reasigna. Alcance de bloque.

Variantes const PI = 3.14;

Cuándo usar Por defecto. Siempre que el valor no necesite cambiarse (datos de config, referencias al DOM que no se reasignan).
var Definición Declara variable con alcance de función (no de bloque).

Variantes var x = 1;

Cuándo usar Evitar. Solo se encuentra en código viejo; let/const la reemplazan.

Regla práctica: usar const por defecto; si al escribir el código te das cuenta de que el valor cambia, recién ahí usá let.

1.2 Tipos de datos

TipoDetalle
stringDefinición Texto.

Variantes "hola", 'hola', `hola ${nombre}` (template literal)

Cuándo usar Para palabras, nombres, mensajes. Las comillas simples o dobles son intercambiables; el template literal (crase) sirve para interpolar variables y texto en varias líneas.
numberDefinición Número (entero o decimal).

Variantes 5, -2.5, 0.1e2

Cuándo usar Operaciones matemáticas, edades, precios.
booleanDefinición true o false.

Cuándo usar Condiciones, estados (activo/inactivo), validaciones.
nullDefinición "Sin valor" a propósito.

Cuándo usar Cuando querés decir que la variable existe pero está intencionalmente vacía.
undefinedDefinición Valor no asignado (automático).

Cuándo usar Cuando una variable se declaró pero no se le dio valor todavía.
objectDefinición Colección de pares clave: valor.

Variantes { nombre: "Ana", edad: 20 }

Cuándo usar Agrupar datos relacionados de una misma entidad (un usuario, un producto).
arrayDefinición Lista ordenada de valores.

Variantes [1, 2, 3], ["a", "b"]

Cuándo usar Listas de elementos, datos en serie.
functionDefinición Bloque de código reutilizable.

Variantes ver 1.6

Cuándo usar Encapsular lógica que se repite.

1.3 Operadores

OperadorDetalle
AritméticosDefinición Hacen operaciones matemáticas.

Variantes + (suma y concatenación), -, * (multiplicación), / (división), % (resto/módulo), ** (potencia)

Cuándo usar % es ideal para saber si un número es par o períodos (ej. vueltas); ** en vez de Math.pow.
ComparaciónDefinición Comparan valores y devuelven boolean.

Variantes ==, ===, !=, !==, <, >, <=, >=

Cuándo usar === / !== siempre (comparan valor y tipo). == / != convierten tipos implícitamente y provocan errores sutiles; evitarlos.
LógicosDefinición Combinan condiciones.

Variantes && (y), || (o), ! (negación)

Cuándo usar && cuando TODAS deben cumplirse; || cuando basta una; ! para invertir (ej. if (!estado)).
AsignaciónDefinición Guardan un valor.

Variantes =, +=, -=, *=, /=, %=

Cuándo usar += es atajo de a = a + b; conviene para contadores y acumuladores.
IncrementoDefinición Suma o resta 1.

Variantes ++, -- (prefijo ++i o sufijo i++)

Cuándo usar Contadores dentro de bucles.
TernarioDefinición Condicional en una línea.

Variantes condicion ? valorSi : valorNo

Cuándo usar Para asignar un valor simple según una condición (evitar si hay varias condiciones, queda ilegible).

1.4 Condicionales

EstructuraDetalle
if / else if / elseDefinición Ejecuta un bloque según una condición.

Variantes if (cond) {...} / else if (cond2) {...} / else {...}

Cuándo usar El más usado. Cuando las condiciones son distintas entre sí o hay rangos/intervalos.
switchDefinición Según el valor de una variable, ejecuta el caso que coincida.

Variantes case valor: ...; break; default: ...

Cuándo usar Cuando una única variable se compara contra muchos valores fijos (ej. un menú 1-2-3). Más limpio que un if gigante.
TernarioDefinición Ver operador ternario.

Cuándo usar Solo para asignaciones simples de 2 caminos.

En switch no olvidar el break, si no "cae" al siguiente case.

1.5 Bucles

BucleDetalle
forDefinición Repite un número conocido de veces con un contador.

Variantes for (let i = 0; i < n; i++)

Cuándo usar Cuando sabés cuántas iteraciones querés, o recorrés usando índices.
for...ofDefinición Recorre los valores de un array/iterable.

Variantes for (const el of array)

Cuándo usar La forma más simple de recorrer una lista sin usar índices.
for...inDefinición Recorre las claves/propiedades de un objeto.

Variantes for (const clave in obj)

Cuándo usar Iterar sobre propiedades de un objeto.
whileDefinición Repite mientras una condición sea verdadera.

Variantes while (cond) {...}

Cuándo usar Cuando NO sabés cuántas veces se va a repetir (ej. mientras el usuario no acierte).
do...whileDefinición Igual que while, pero ejecuta al menos una vez (la condición se evalúa al final).

Variantes do {...} while (cond)

Cuándo usar Cuando necesitás que el cuerpo corra sí o sí una vez.
ControlVariantes break (corta el bucle), continue (salta a la siguiente iteración)

Cuándo usar break para salir; continue para saltar un caso (ej. números pares).

Riesgo: si la condición de while nunca se vuelve falsa, el bucle se ejecuta para siempre y congela la página.

1.6 Funciones

FormaDetalle
DeclaraciónDefinición Función "hoisted" (se puede llamar antes de definirla).

Variantes function sumar(a, b) { return a + b; }

Cuándo usar La forma clásica; ideal para funciones del programa que se reutilizan.
ExpresiónDefinición Función guardada en una variable.

Variantes const sumar = function (a, b) { return a + b; };

Cuándo usar Cuando la función es parte de un valor o se pasa como argumento.
Arrow (flecha)Definición Sintaxis corta; no tiene su propio this.

Variantes const sumar = (a, b) => a + b;

Cuándo usar Callbacks, funciones cortas, y en general la forma moderna preferida.
ParámetrosDefinición Entradas de la función.

Variantes parámetros por defecto (a, b = 0), resto (...args)

Cuándo usar Parámetros por defecto para valores opcionales; resto para aceptar N argumentos.
returnDefinición Devuelve un valor y corta la función.

Cuándo usar Cuando la función debe producir un resultado para usarlo afuera.
thisDefinición Referencia al contexto que llama la función.

Cuándo usar En arrow this hereda del entorno; en funciones normales depende de cómo se llama.

Una función sin return devuelve undefined.

1.7 Strings (cadenas de texto)

MétodoDetalle
lengthDefinición Cantidad de caracteres (propiedad).

Cuándo usar Límites de longitud (largos de password, etc.).
toUpperCase() / toLowerCase()Definición Texto en mayúsculas / minúsculas.

Cuándo usar Normalizar entradas del usuario y compararlas.

Cuándo usar Búsquedas y validaciones simples.

Cuándo usar Validar prefijos (ej. +54) o extensiones.
slice(inicio, fin)Definición Extrae una parte sin modificar la original.

Variantes "hola".slice(0, 2) → "ho"

Cuándo usar Cortar substrings; acepta índices negativos (cuenta desde el final).
substring(inicio, fin)Definición Igual que slice pero sin índices negativos.

Cuándo usar Cuando no necesitás índices negativos (más predecible).
split(sep)Definición Convierte el string en un array separándolo por un separador.

Variantes "a,b".split(",") → ["a","b"]

Cuándo usar Pasó de texto a lista (ej. CSV).
join(sep)Definición Convierte un array en string uniéndolo (es el inverso de split).

Variantes ["a","b"].join("-") → "a-b"

Cuándo usar Mostrar listas formateadas. (Método de array, ver 1.8.)
replace(viejo, nuevo) / replaceAll()Definición Reemplaza la primera / todas las coincidencias.

Cuándo usar Corregir datos; replaceAll para reemplazar todas.
trim()Definición Quita espacios en blanco de los extremos.

Variantes trimStart, trimEnd

Cuándo usar Limpiar entradas de formularios antes de validar.
indexOf(texto)Definición Posición de la primera coincidencia (-1 si no está).

Variantes indexOf, lastIndexOf

Cuándo usar Buscar posición; para "existe" conviene includes.
charAt(i)Definición Carácter en la posición i.

Cuándo usar Acceder a un carácter puntual.
padStart(n, c) / padEnd()Definición Rellena con caracteres hasta una longitud.

Cuándo usar Formatear con ceros adelante (ej. "5".padStart(2,"0") → "05").
Template literalDefinición String con variables incrustadas.

Variantes `Hola ${nombre}`

Cuándo usar Interpolación: la forma moderna de concatenar.

Alternativa vieja: concatenar con + ("Hola " + nombre). Funciona, pero el template literal es más legible.

MétodoDetalle

Cuándo usar Recorridos y límites.

Cuándo usar Pilas (stack) y acumular en orden.

Cuándo usar Colas (queue); ojo: más lentos en listas largas.

Cuándo usar Buscar índice. Para "¿existe?" usar includes.

Cuándo usar Validar pertenencia.

Cuándo usar Formatear para mostrar.

Cuándo usar Obtener sub-listas sin tocar el original.

Cuándo usar Editar el array en el lugar (agregar/quitar/insertar).

Cuándo usar Combinar listas. El spread es la forma moderna.

Variantes sort((a,b) => a - b) para números

Cuándo usar sort() por defecto ordena como texto (¡cuidado con números!); pasar función comparadora.

Cuándo usar Solo recorrer y hacer algo (sin necesidad de resultado).

Cuándo usar Transformar una lista en otra (ej. doblar valores, extraer nombres).

Cuándo usar Filtrar (ej. mayores de edad).
find(cb)Definición Primer elemento que cumple la condición (o undefined).

Cuándo usar Buscar UN elemento puntual.
reduce(cb, inicial)Definición Reduce toda la lista a un único valor acumulado.

Cuándo usar Sumar todo, promediar, contar.
some(cb) / every(cb)Definición ¿Alguno / todos cumplen la condición? boolean.

Cuándo usar Validaciones generales.

Cómo elegir: forEach para efectos secundarios; map cuando querés la lista transformada; filter para quedarte con un subconjunto; find para uno solo; reduce para sumarizar.
