Librerías de JavaScript y Prototype

Fuente: Javascript_jquery_II.pdf

¿Qué son las librerías/frameworks de JavaScript?

La aparición de JavaScript provocó la existencia de una gran variedad de frameworks JavaScript para manipular el DOM desde el cliente, o para trabajar del lado del servidor. También se los llama Librerías JavaScript.

  • Del lado del cliente: Prototype.js, jQuery, AngularJS, Lightbox (Lightbox 2), W3.js.
  • Del lado del servidor: Node.js.

Prototype JS

Se orienta al desarrollo sencillo y dinámico de aplicaciones web e implementa las técnicas AJAX. Fue base de muchos otros frameworks e inspiró librerías relacionadas (ej. jQuery).

La función $() (función dólar)

Es un atajo de la función del DOM document.getElementById().

// Con JavaScript
var elemento = document.getElementById('primero');

// Con Prototype
var elemento = $('primero');

La función $F()

Permite obtener el valor de cualquier elemento.

// Con JavaScript
document.getElementById("municipio").value

// Con Prototype
$F("municipio")
