jQuery — Eventos y efectos

Fuente: Javascript_jquery_II.pdf

Eventos

Todas las acciones que el usuario realiza sobre la página pueden capturarse por eventos:

  • Eventos del mouse.
  • Eventos del teclado.
  • Eventos ante la acción de los formularios.
  • Eventos de la ventana del navegador.

Capturar y responder a un evento

$("p").click();       // captura el clic de un párrafo

// Definir qué sucede cuando ocurre el evento
$("p").click(function(){
  // acciones aquí
  $(this).hide();      // oculta el párrafo cliqueado
});

Efectos

1. hide() y show()

Ocultan o muestran los elementos seleccionados.

$("#hide").click(function(){
  $("p").hide();
});
$("#show").click(function(){
  $("p").show();
});

2. Fade (desvanecido)

MétodoQué hace
fadeIn()Desvanece el elemento desde transparente hasta visible.
fadeOut()Desvanece hasta que queda invisible.
fadeToggle()Alterna entre fadeIn y fadeOut.
fadeTo()Desvanece hasta una opacidad determinada.

3. Slide (deslizamiento)

MétodoQué hace
slideDown()Desliza el elemento hacia abajo (revela).
slideUp()Desliza hacia arriba (oculta).
slideToggle()Combina los dos efectos anteriores.

4. Animaciones: animate()

$(selector).animate({params}, speed, callback);
  • {params} — propiedades CSS a animar.
  • speed — velocidad del efecto.
  • callback — función que se ejecuta cuando termina la animación.

5. stop()

Frena las animaciones o efectos en curso.

6. Devoluciones de llamada (callback functions)

$(selector).hide(speed, callback);

Los callbacks permiten que el script se ejecute paso a paso: la función de retorno recién corre cuando termina el efecto anterior.

7. Encadenado (chaining)

Con jQuery se pueden encadenar acciones/métodos en una misma línea para ejecutar varios efectos seguidos.
