jQuery — Métodos de AJAX

Fuente: Javascript_jquery_II.pdf

Los cuatro métodos de AJAX en jQuery

  • load()
  • get()
  • post()
  • ajax()

1. load() — el más simple

El resultado devuelto se coloca en un contenedor. Solo muestra texto: si la respuesta trae etiquetas HTML, no las interpreta.

$(selector).load(URL, data, callback);
  • URL — requerido: dirección que se desea llamar.
  • data — opcional: dupla clave/valor que se envía al servidor.
  • callback — opcional: función que se ejecuta al completarse el load().
$(document).ready(function(){
  $("button").click(function(){
    $("#div1").load("Holamundo.txt");
  });
});

Validar nickname con load()

$(document).ready(function(){
  $("#nick").keyup(function(){
    pnickname = $("#nick").val();
    $("#comprobar_mensaje").load("ajax_comprobar_nick.php",
      {nickname: pnickname},
      function(response, status, xhr) {
        if (status == "error") {
          var msg = "Error!, algo ha sucedido: ";
        }
      });
  });
});

2. get()

Garante una petición HTTP GET. GET obtiene datos de un recurso específico; puede devolver datos almacenados en caché. Respet el contenido devuelto: si la respuesta tiene etiquetas HTML, el navegador las interpreta.

$.get(URL, callback);
$(document).ready(function(){
  $("button").click(function(){
    $.get("holamundo.txt", function(data, status){
      alert("Data: " + data + "\nStatus: " + status);
    });
  });
});

3. post()

Envía datos para su procesamiento con una petición POST. POST nunca almacena datos en caché y es más seguro para enviar datos de entrada del usuario.

$.post(URL, data, callback);
$(document).ready(function(){
  $("button").click(function(){
    $.post("post.php",
      { nombre: "Jose Lopez", ciudad: "General pico" },
      function(data, status){
        alert("Data: " + data + "\nStatus: " + status);
      });
  });
});

4. ajax() — configuración completa

$.ajax({
  url: "ruta/del/servidor.php",   // URL a la que se hace la petición
  type: "GET",                    // Método HTTP: GET, POST, PUT, DELETE
  data: { nombre: "Juan", edad: 25 },  // Datos que se envían al servidor
  dataType: "json",               // Tipo de datos esperado: json, text, html, xml
  timeout: 5000,                  // Tiempo máximo de espera (milisegundos)
  beforeSend: function(xhr) {
    // Se ejecuta antes de enviar la petición
    console.log("Enviando petición...");
  },
  success: function(response, status, xhr) {
    // Se ejecuta si la petición fue exitosa
    console.log("Respuesta:", response);
    console.log("Estado:", status);     // "success"
    console.log("Código HTTP:", xhr.status);
  },
  error: function(xhr, status, error) {
    // Se ejecuta si ocurre un error
    console.error("Error:", error);
    console.error("Estado:", status);
    console.error("Código HTTP:", xhr.status);
  },
  complete: function(xhr, status) {
    // Se ejecuta siempre (éxito o error)
    console.log("Petición finalizada con estado:", status);
  }
});

Parámetros más comunes de $.ajax()

ParámetroQué hace
urlDirección a la que se envía la petición.
type / methodMétodo HTTP (GET, POST, etc.).
dataDatos a enviar al servidor.
dataTypeFormato esperado de la respuesta (json, xml, html, text).
timeoutTiempo máximo de espera.
beforeSendCallback antes de enviar la petición.
successCallback cuando la petición se resuelve correctamente.
errorCallback cuando ocurre un error.
completeCallback que se ejecuta al final, sin importar éxito o error.

Versión con promesas (done / fail)

$.ajax({
  type: 'POST',
  url: './ajax_comprobar_nick.php',
  data: { nickname: pnickname }
}).done(function(msg) {
  $("#comprobar_mensaje").html(msg);
}).fail(function(jqXHR, textStatus, errorThrown) {
  $("#comprobar_mensaje").html("ocurrió un error: " + textStatus + " " + errorThrown);
});

El método noConflict()

jQuery usa $ como atajo, pero muchos otros frameworks (Angular, Backbone, Ember, Knockout, Prototype…) también lo usan. Si dos frameworks usan el mismo atajo, uno puede dejar de funcionar.

noConflict() libera el identificador $ para que otros scripts puedan usarlo.

// Variante 1: usar "jQuery" en lugar de $
$.noConflict();
jQuery(document).ready(function(){
  jQuery("button").click(function(){
    jQuery("p").text("jQuery is still working!");
  });
});

// Variante 2: crear tu propio atajo
var jq = $.noConflict();
jq(document).ready(function(){
  jq("button").click(function(){
    jq("p").text("jQuery is still working!");
  });
});
