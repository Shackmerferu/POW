jQuery — Manipulación de HTML y CSS

Fuente: Javascript_jquery_II.pdf

Obtener elementos y contenido (get)

MétodoQué hace
.text()Establece o devuelve el contenido de texto de los elementos seleccionados.
.html()Establece o devuelve el contenido incluido el marcado HTML.
.val()Establece o devuelve el valor de los campos del formulario.
.attr()Obtiene el valor de un atributo.
$("button").click(function(){
  alert($("#w3s").attr("href"));
});

Establecer elementos y contenido (set)

Se usan los mismos métodos que al obtener: text(), html(), val(), attr().

$(document).ready(function(){
  $("#btn1").click(function(){
    $("#test1").text("Hola mundo!");
  });
  $("#btn2").click(function(){
    $("#test2").html("<b>Hello world!</b>");
  });
  $("#btn3").click(function(){
    $("#test3").val("Dolly Duck");
  });
});

Adicionar elementos o contenido (add)

MétodoQué hace
append()Inserta contenido al final de los elementos seleccionados.
prepend()Inserta contenido al comienzo de los elementos seleccionados.
after()Inserta contenido después de los elementos seleccionados.
before()Inserta contenido antes de los elementos seleccionados.
$("p").append(" algún texto.");     // fuera del párrafo, al final
$("p").prepend(" algún texto.");    // al comienzo del párrafo
$("img").after("Some text after");  // después de la imagen
$("img").before("Some text before");// antes de la imagen

Remover elementos o contenido

MétodoQué hace
remove()Elimina el elemento seleccionado y sus elementos secundarios.
empty()Elimina los elementos secundarios del elemento seleccionado (deja el elemento vacío).
$("#div1").remove();
$("#div1").empty();
$("p").remove(".test");   // remueve la clase test de todos los <p>

Manipular hojas de estilo (CSS)

MétodoQué hace
addClass()Agrega una o más clases a los elementos seleccionados.
removeClass()Elimina una o más clases de los elementos seleccionados.
toggleClass()Alterna entre agregar/eliminar clases.
css()Establece o devuelve una o más propiedades de estilo.

El método css()

// Retornar un valor
css("propertyname");
$("p").css("background-color");   // devuelve el color de fondo actual

// Establecer un valor
css("propertyname", "value");
$("p").css("background-color", "yellow");

// Asignación múltiple (objeto)
$("p").css({"background-color": "yellow", "font-size": "200%"});
