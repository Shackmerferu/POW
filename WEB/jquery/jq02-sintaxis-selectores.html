jQuery — uso, sintaxis y selectores

Fuente: Javascript_jquery_II.pdf

¿Qué es jQuery?

jQuery es una biblioteca multiplataforma de JavaScript, fácil de aprender. Su propósito es facilitar el uso de JavaScript, simplificando cosas complicadas como las llamadas AJAX y la manipulación del DOM.

Características: manipulación HTML/DOM, manipulación CSS, métodos de eventos HTML, efectos y animaciones, AJAX y utilidades.

¿Por qué jQuery? Es probablemente la librería más popular y ampliable. La usan Google, Microsoft, IBM, Netflix, y gestores de contenido como WordPress y Joomla, y frameworks como Bootstrap y Material Design.

Formas de usarla

FormaCómo
Descargando la librería e invocándola 
<script src="jquery-3.5.1.min.js"></script>
Haciendo referencia a un CDN (ej. Google) 
<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.5.1/jquery.min.js"></script>
Usando gestores de paquetes npm, yarn

Sintaxis básica

$(selector).action()
  • $ — signo para definir / acceder a jQuery.
  • (selector) — "consulta (o busca)" elementos HTML.
  • .action() — la acción jQuery a realizar sobre los elementos.

Ejemplos de la sintaxis

$(this).hide()        // oculta el elemento actual
$("p").hide()         // oculta todos los elementos <p>
$(".test").hide()     // oculta todos los elementos con class="test"
$("#test").hide()     // oculta el elemento con id="test"

Función de preparación (Read y)

Todos los métodos deben cargarse dentro de una función ready para evitar que los eventos se ejecuten antes de que termine la carga de la página.

$(document).ready(function(){
  // colocar aquí los métodos jQuery
});

// Método abreviado
$(function(){
  // colocar aquí los métodos jQuery
});

Selectores

Los selectores son la parte más importante de jQuery: con $(selector) elegimos qué elementos se manipulan.

SelectorQué selecciona
$("*")Todos los elementos de la página.
$(this)El elemento actual.
$("p")Todos los elementos <p>.
$("p.intro")Los <p> con class="intro".
$("#test")El elemento con id="test".
$(".test")Los elementos con class="test".
$("p:first")El primer <p> de la página.
$("tr:odd")Las filas impares de una tabla.

Ejemplo: ocultar párrafos con un botón

$(document).ready(function(){
  $("button").click(function(){
    $("p").hide();
  });
});
