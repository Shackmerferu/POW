Navegación: navbar, tabs, dropdowns, breadcrumb y paginación

Nav: la base de tabs y pills

<ul class="nav nav-tabs">
  <li class="nav-item"><a class="nav-link active" href="#">Perfil</a></li>
  <li class="nav-item"><a class="nav-link" href="#">Cuenta</a></li>
  <li class="nav-item"><a class="nav-link disabled" href="#">Bloqueado</a></li>
</ul>

<ul class="nav nav-pills">…</ul>       <!-- igual, pero estilo pastilla -->
<nav class="nav nav-fill">…</nav>      <!-- los items reparten el ancho -->
ClaseQué hace
navBase: fila de enlaces sin viñetas.
nav-item + nav-linkCada enlace de la lista.
nav-tabsEstilo pestañas.
nav-pillsEstilo pastillas.
nav-fill / nav-justifiedAncho iguale / ancho según contenido.
active / disabledItem actual / inactivo.
data-bs-toggle="tab"Convierte las pestañas en paneles que cambian (con el JS).

Navbar: la barra de navegación

Es el componente más usado. Estructura típica con menú colapsable en celulares (por eso hace falta el JS de Bootstrap):

<nav class="navbar navbar-expand-lg navbar-dark bg-primary">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Mi Sitio</a>
    <button class="navbar-toggler" type="button" data-bs-toggle="collapse"
            data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav me-auto">
        <li class="nav-item"><a class="nav-link active" href="#">Inicio</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Productos</a></li>
      </ul>
    </div>
  </div>
</nav>
ClaseQué hace
navbarBase de la barra.
navbar-expand-lgEl menú se muestra en una fila desde lg; abajo de eso se colapsa. (También -sm, -md, -xl).
navbar-brandEl logo / nombre de la marca.
navbar-toggler + navbar-toggler-iconEl botón ☰ que abre el menú y su ícono.
collapse navbar-collapseEl bloque de enlaces que se pliega/despliega (con data-bs-toggle="collapse").
navbar-navLos enlaces de la barra (normalmente con me-auto para empujarlos).
navbar-dark / navbar-lightColores de textos para fondo oscuro / claro.
bg-primary… o bg-body-tertiaryFondo de la barra.
fixed-top / sticky-topBarra siempre visible.

Dropdowns: menú desplegable

<div class="dropdown">
  <button class="btn btn-secondary dropdown-toggle" data-bs-toggle="dropdown">
    Acciones
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Editar</a></li>
    <li><a class="dropdown-item active" href="#">Ver</a></li>
    <li><hr class="dropdown-divider"></li>
    <li><a class="dropdown-item text-danger" href="#">Eliminar</a></li>
  </ul>
</div>
ClaseQué hace
dropdownContenedor del menú.
dropdown-toggle + data-bs-toggle="dropdown"El botón que abre/cierra y su flechita.
dropdown-menuEl panel desplegado.
dropdown-itemCada opción.
dropdown-header / dropdown-dividerTítulo / línea separadora.
dropdown-menu-endAlinea el menú a la derecha.

Breadcrumb y paginación

<nav aria-label="breadcrumb">
  <ol class="breadcrumb">
    <li class="breadcrumb-item"><a href="#">Inicio</a></li>
    <li class="breadcrumb-item active" aria-current="page">Productos</li>
  </ol>
</nav>

<nav>
  <ul class="pagination">
    <li class="page-item disabled"><a class="page-link" href="#">«</a></li>
    <li class="page-item active"><a class="page-link" href="#">1</a></li>
    <li class="page-item"><a class="page-link" href="#">2</a></li>
  </ul>
</nav>
ClaseQué hace
breadcrumb + breadcrumb-item activeMiguita de pan: la ruta de dónde estás.
paginationLista de páginas.
page-item + page-linkCada página (el page-link es la cajita clickeable).
pagination-lg / pagination-smTamaños.
active / disabledPágina actual / link deshabilitado.
