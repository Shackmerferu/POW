El sistema de grilla: layout con clases, no con CSS

¿Qué reemplaza?

En CSS normal, para poner dos columnas al lado escribís display:flex o float, width, gap y después ajustás los media queries para el celular. Bootstrap hace todo eso con tres clases: container, row y col.

El layout responsivo deja de ser código CSS propio y pasa a ser clases en el HTML. Tu hoja de estilos queda solo para el diseño (colores, tipografías, tarjetas), no para la estructura.

La estructura básica

<div class="container">          <!-- centra y limita el ancho -->
  <div class="row">               <!-- fila: agrupa columnas -->
    <div class="col">Izquierda</div>
    <div class="col">Derecha</div>
  </div>
</div>

Las col se reparten el ancho de la fila equitativamente y, al achicar la pantalla, se apilan una debajo de otra.

Controlar el ancho de cada columna

La fila se divide en 12 columnas. Con col-N elegís cuántas ocupa cada bloque.

<div class="row">
  <div class="col-sm-8">Contenido principal (8/12)</div>
  <div class="col-sm-4">Barra lateral (4/12)</div>
</div>
ClaseQué defineEjemplo
colIgual ancho automático.Dos col = 50% y 50%.
col-6Ancho fijo de 6 de 12 (mitad), siempre.Usado en pantallas grandes.
col-md-66 de 12 en pantallas medianas o más.En celular se apila solo.
col-sm-44 de 12 en pantallas pequeñas o más.Layout de sidebar clásico.

Los breakpoints (puntos de corte)

Son los umbrales de ancho de pantalla donde cambia el comportamiento. En tu CSS normal los escribirías como @media (min-width: ...); acá van dentro del nombre de la clase.

SufijoPantallaAncho mínimo
-smPhone grande / tablet chica576px
-mdTablet768px
-lgNotebook992px
-xlDesktop1200px
El sufijo significa "a partir de este ancho y mayores". Sin sufijo (col-6) vale siempre; con sufijo (col-md-6) recién en md o más, y abajo de eso la columna ocupa todo el ancho.

Comparando: CSS normal vs Bootstrap

/* CSS normal */                     /* Con Bootstrap */
.row2{display:flex;gap:12px}         <div class="row">…</div>
.row2 > div{flex:1}
@media(max-width:768px){             <div class="col-md-6">…</div>
  .row2{flex-direction:column}
}

El resultado visual es el mismo, pero con Bootstrap no escribís nada en la hoja de estilos: los media queries y el flex los aporta el framework.
