Incluir Bootstrap: un framework CSS como hoja de estilo

¿Qué es Bootstrap y cómo se aplica?

Bootstrap es un framework CSS: un archivo .css listo que trae un montón de estilos ya escritos. No reemplaza tu hoja de estilos: es una hoja de estilo más que se suma a la página. Lo que hace Bootstrap es darte clases (por ejemplo btn, row, card) que aplicás directamente en el class="" del HTML, igual que usarías una clase propia.

La diferencia con el CSS normal: en vez de inventar a mano el estilo para cada elemento, añadís clases ya definidas por Bootstrap al HTML.

El CDN: no hace falta descargarlo

La forma más rápida de probarlo es enlazar el archivo desde un CDN. Van dos cosas en el HTML:

<!-- 1. El CSS de Bootstrap va en el <head>, CON ESTILOS PROPIOS DEBAJO -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="styles.css">

<!-- 2. El JS de Bootstrap va antes de cerrar el <body> (opcional, para componentes como menús) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

El orden importa: primero Bootstrap, después tu CSS

Cuando dos hojas de estilo se aplican al mismo elemento, gana la que se carga después (misma especificidad). Por eso tu styles.css se pone debajo del de Bootstrap: así tus estilos propios le ganan a los del framework.

HojaQué defineCómo se aplica
styles.css (propia)Tu diseño: colores, tipografía, tarjetas propias…Con .clase, #id o elemento, como siempre.
bootstrap.min.css (framework)Capacidad de grid, botones, tablas, utilidades…Con clases predefinidas agregadas al class="" del HTML.
Si tu CSS usara un selector menos específico que la clase de Bootstrap (ej. button frente a .btn), gana Bootstrap. Para sobrescribir con seguridad, usá clases propias con igual o mayor especificidad.

Primer ejemplo: la misma estructura, dos resultados

Sin Bootstrap y con Bootstrap, el HTML cambia poco: solo se agregan clases en el class="".

<p>Solo CSS propio</p>
<p class="btn btn-primary">Con Bootstrap, parece un botón</p>

La clase btn btn-primary ya trae el fondo, el relleno, los bordes redondeados y el hover. Todo lo que antes escribirías a mano en CSS, ahora lo aporta el framework.
