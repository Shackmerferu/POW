Componentes que requieren el JavaScript de Bootstrap

Todo esto necesita el bootstrap.bundle.min.js cargado antes de cerrar el <body>. Sin el JS, los componentes tienen el HTML pero no se animan ni cambian.

El truco general: atributos data-bs-*

La mayoría de los componentes se encienden con atributos en el HTML (sin escribir una línea de JS):

AtributoComponenteValor que espera
data-bs-toggleEl que decide qué componente escollapse, modal, dropdown, tooltip, popover, offcanvas…
data-bs-targetA qué elemento apunta el botónUn selector CSS, ej. #mi-modal o .mi-menu
data-bs-dismissCierra el componentemodal, alert, offcanvas
data-bs-rideArranca solo (carousel)carousel
data-bs-bs-touch/…Opciones por componente…—

Collapse: mostrar / ocultar un bloque

<button class="btn btn-primary" data-bs-toggle="collapse"
        data-bs-target="#detalle">Ver detalle</button>

<div class="collapse" id="detalle">El texto oculto acá.</div>

La clase collapse oculta el bloque; el botón con data-bs-toggle="collapse" + data-bs-target="#id" lo despliega y pliega. Si querés que arranque abierto, agregale también show. Variante collapse-horizontal para abrir en ancho.

Acordeón: varias secciones que se turnan

<div class="accordion" id="acordeon">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button" data-bs-toggle="collapse"
              data-bs-target="#seccion1">Pregunta 1</button>
    </h2>
    <div id="seccion1" class="accordion-collapse collapse show"
         data-bs-parent="#acordeon">
      <div class="accordion-body">Respuesta 1.</div>
    </div>
  </div>
</div>
ClaseQué hace
accordionContenedor (lleva el id que usan los hijos).
accordion-item / accordion-header / accordion-bodyPartes de cada sección.
accordion-buttonEl encabezado clickeable con su flechita.
accordion-collapse collapseEl panel que se pliega.
data-bs-parent="#acordeon"Al abrir una sección, cierra las otras.
accordion-flushSin bordes externos (para tarjetas).

Modal: la ventana emergente

<button class="btn btn-primary" data-bs-toggle="modal"
        data-bs-target="#miModal">Abrir modal</button>

<div class="modal fade" id="miModal" tabindex="-1">
  <div class="modal-dialog modal-dialog-centered">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Título</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Contenido del modal.</div>
      <div class="modal-footer">
        <button class="btn btn-secondary" data-bs-dismiss="modal">Cerrar</button>
        <button class="btn btn-primary">Guardar</button>
      </div>
    </div>
  </div>
</div>
ClaseQué hace
modal + fadeContenedor con animación de entrada.
modal-dialogDa formato a la ventanita.
modal-dialog-centered / modal-dialog-scrollableCentrada en pantalla / con scroll interno.
modal-lg / modal-sm / modal-fullscreenTamaños posibles del diálogo.
modal-header / modal-body / modal-footerLas tres zonas.
data-bs-dismiss="modal"Cierra el modal (la X y el botón Cerrar).

Carousel: el pase de imágenes

<div id="carrusel" class="carousel slide" data-bs-ride="carousel">
  <div class="carousel-inner">
    <div class="carousel-item active"><img src="a.png" class="d-block w-100" alt="…"></div>
    <div class="carousel-item"><img src="b.png" class="d-block w-100" alt="…"></div>
  </div>
  <button class="carousel-control-prev" data-bs-target="#carrusel" data-bs-slide="prev">
    <span class="carousel-control-prev-icon"></span>
  </button>
  <button class="carousel-control-next" data-bs-target="#carrusel" data-bs-slide="next">
    <span class="carousel-control-next-icon"></span>
  </button>
</div>
Clase / atributoQué hace
carousel slide + data-bs-ride="carousel"Activa el auto-deslizamiento.
carousel-inner + carousel-item activeLas diapositivas (la actual lleva active).
carousel-control-prev/nextLas flechas laterales.
carousel-indicatorsLos puntitos de abajo.
carousel-captionLeyenda sobre la imagen.

Tooltip y Popover: mini-cartelitos

Son los únicos que necesitan una línea de JS para inicializarse (por rendimiento Bootstrap no los enciende solo).

<button class="btn btn-secondary" data-bs-toggle="tooltip"
        title="Pequeña ayuda">Leyenda</button>

<button class="btn btn-outline-secondary" data-bs-toggle="popover"
        data-bs-title="Título del popover"
        data-bs-content="Textito del popover">Más info</button>

<script>
  document.querySelectorAll('[data-bs-toggle="tooltip"]')
    .forEach(el => new bootstrap.Tooltip(el));
  document.querySelectorAll('[data-bs-toggle="popover"]')
    .forEach(el => new bootstrap.Popover(el));
</script>

El resto del catálogo

ComponenteClases claveQué hace
offcanvasoffcanvas offcanvas-start + data-bs-toggle="offcanvas"Panel que se desliza desde un lado (menú lateral).
toasttoast + data-bs-toggle="toast"Notificación chica que aparece en una esquina.
scrollspydata-bs-spy="scroll" + data-bs-target="#menu"Marca en el menú la sección que estás viendo al hacer scroll.
dropdown (ya visto)data-bs-toggle="dropdown"Menú desplegable.
tabs / pills (ya visto)data-bs-toggle="tab"Cambia paneles al elegir pestañas.
Regla clave: si el componente se pliega, abre, cierra o desliza, seguro necesita data-bs-toggle + data-bs-target (o data-bs-dismiss) y el bundle JS. Bootstrap no requiere jQuery.
