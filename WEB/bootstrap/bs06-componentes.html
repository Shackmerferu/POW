Componentes: botones, alertas, badges e imágenes

Botones: la clase btn

Todo botón lleva btn + un color. Sin la clase btn no se ve como botón.

<button class="btn btn-primary">Guardar</button>
<a href="#" class="btn btn-outline-danger">Eliminar</a>
Clase de colorQué hace
btn-primary / btn-secondary / btn-success / btn-dangerBotón relleno con ese color de tema.
btn-warning / btn-info / btn-light / btn-darkRellenos restantes del tema.
btn-outline-primary … btn-outline-darkBotón con borde del color, fondo transparente (se rellena al hover).
btn-linkBotón que parece un enlace normal.
ClaseQué hace
btn-lg / btn-smTamaño grande / chico.
btn-block (no existe en BS5)Ya no se usa: para ancho completo se usa d-grid gap-2 en el padre.
activeEstado "presionado" visual.
disabled (o el atributo disabled)Deshabilitado: no se puede clickear.
La btn además trae el hover, el foco y el estado activo ya resueltos. Eso que en CSS normal parece chico, en Bootstrap es parte de la clase.

Agrupar botones: btn-group

<div class="btn-group">
  <button class="btn btn-outline-primary">Día</button>
  <button class="btn btn-outline-primary">Semana</button>
  <button class="btn btn-outline-primary">Mes</button>
</div>

btn-group junta varios botones pegados; btn-group-vertical los apila. btn-toolbar agrupa varios grupos en una barra.

Alertas: avisos de una sola línea

<div class="alert alert-warning" role="alert">Cuidado con este dato</div>

<div class="alert alert-danger alert-dismissible" role="alert">
  No se pudo guardar.
  <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
</div>
ClaseQué hace
alert alert-primary…alert-darkLos 8 colores de tema como aviso.
alert-linkEnlace interno que combina con el color de la alerta.
alert-headingTítulo dentro de la alerta (<h4>).
alert-dismissible + btn-closeAgrega la "X" para cerrar (necesita el JS de Bootstrap).

Badges: etiquetas de etiquetas

<h4>Nuevos mensajes <span class="badge text-bg-danger rounded-pill">3</span></h4>
<span class="badge text-bg-success">En stock</span>
ClaseQué hace
badgeLa base: pastilla chica redondeada.
text-bg-primary…text-bg-darkColor de fondo + texto con contraste (reemplaza al viejo badge-*).
rounded-pillLa convierte en pastilla totalmente ovalada.
position-absolute top-0 start-100 translate-middlePara colgarla de una esquina de un botón o ícono (notificación).

Imágenes y figuras

ClaseQué hace
img-fluidmax-width: 100%; height: auto — la imagen nunca desborda y escala.
img-thumbnailBorde + relleno, como una foto polaroid.
rounded, rounded-circleEsquinas redondeadas / circular (para avatares).
float-start / float-endTexto alrededor de la imagen.
<figure class="figure">
  <img src="foto.png" class="figure-img img-fluid rounded" alt="…">
  <figcaption class="figure-caption">La leyenda de la foto.</figcaption>
</figure>
