Clases de Bootstrap conviviendo con tu hoja de estilos

Bootstrap no es un reemplazo, es un complemento

Bootstrap aporta utilidades y componentes en forma de clases. Tu styles.css sigue haciendo lo de siempre: definir la identidad visual. Las dos cosas se mezclan en el mismo class="".

<button class="btn btn-primary">Guardar</button>
<div class="card p-3 mt-2">Tarjeta de Bootstrap con tu tipografía</div>
En el mismo elemento podés poner una clase de Bootstrap (card) y una clase tuya (tarjeta-destacada): se aplican las dos.

Utilidades: espaciados y alineación sin escribir CSS

Los rellenos y márgenes que en CSS escribís como padding: 16px o margin-top, acá son clases con una fórmula: <propiedad><lado>-<medida>.

ClaseEquivale en CSS a
p-3padding: 1rem (los cuatro lados)
pt-2padding-top: .5rem
mx-automargin: 0 auto (centra horizontal)
mt-4margin-top: 1.5rem
text-centertext-align: center
d-flexdisplay: flex

Medidas disponibles: 0 (nada), 1 (.25rem), 2 (.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem). Con los sufijos de breakpoint se vuelven responsive: mt-md-4 aplica el margen recién en pantallas md.

Componentes: plantillas con clases

Bootstrap trae piezas completas: botones, alertas, tarjetas, menús (navbar), tablas, formularios… Se usan escribiendo el HTML con las clases indicadas.

<div class="alert alert-warning">Cuidado con este dato</div>

<div class="card" style="max-width:300px">
  <div class="card-body">
    <h5 class="card-title">Título</h5>
    <p class="card-text">Texto de la tarjeta.</p>
    <a class="btn btn-outline-primary" href="#">Ver más</a>
  </div>
</div>

Esos estilos ya vienen escritos en bootstrap.min.css, como si fueran clases de tu propia hoja.

Cómo sobrescribir un componente con tu CSS

  1. Tus estilos van después del de Bootstrap en el <head> (mayor prioridad).
  2. Usá una clase propia con igual o mayor especificidad que la de Bootstrap.
<!-- Sobre una .btn de Bootstrap, tu .boton-redondo gana si va después -->
.boton-redondo{ border-radius: 50rem; }
<button class="btn btn-primary boton-redondo">Guardar</button>
Si Bootstrap cambia algo que no querés, la forma limpia es una clase propia encima, no editar el archivo del framework (se pierde al actualizar).

Resumen: la receta de uso

  1. Agregá bootstrap.min.css en el <head>, antes de tu styles.css.
  2. Aplicá clases de Bootstrap (grid, utilidades, componentes) en el HTML.
  3. Decorá con tu styles.css: colores, fuentes y detalles propios.
  4. Sobrescribí cuando haga falta con clases propias de igual especificidad.
