Tipografía y colores: clases para texto y fondo

Tamaños de título: h1–h6 y display

Las etiquetas <h1>…<h6> ya vienen con tamaños definidos, y podés aplicar ese mismo tamaño a cualquier elemento con las clases h1…h6. Para encabezados mucho más grandes está la familia display.

ClaseQué hace
<h1>…</h6> o class="h1"…"h6"Los 6 niveles de título ya estilizados (2.5rem → 1rem).
display-1 … display-6Títulos gigantes de encabezado (5rem → 2.5rem).
leadPárrafo destacado, más grande y claro.
small o <small>Texto chico (85% del tamaño).
mark o <mark>Texto con resaltado amarillo.
<abbr title="…">Abreviatura con subrayado punteado y tooltip nativo.

Alineación, mayúsculas y cortes

ClaseEquivale en CSS a

text-lowercasetext-transform: lowercase
text-capitalizetext-transform: capitalize
text-truncateCorta con "…" cuando el texto desborda (necesita ancho fijo).
text-wrap / text-nowrapPermite / evita el salto de línea.
text-breakRompe palabras largas (URLs) para que no desborden.
text-decoration-noneSin subrayado (muy usado en enlaces).
text-decoration-underline / -line-throughSubrayado / tachado.
La alineación y casi todo lo de texto acepta prefijos de breakpoint: text-sm-center, text-md-end, etc. Igual que las columnas: aplica desde ese ancho en adelante.

Colores de texto: text-*

Bootstrap define 8 colores de tema primary, secondary, success, danger, warning, info, light y dark. Sirven para texto, fondo y muchos componentes.

<p class="text-success">Todo guardado correctamente</p>
<p class="text-danger">El dato es obligatorio</p>
<p class="text-primary">Enlace y texto destacado</p>

Colores de fondo: bg-*

<div class="bg-warning p-2">Caja con fondo amarillo</div>
<div class="bg-dark text-white p-2">Caja oscura con texto blanco</div>
ClaseQué define
bg-primary/…/bg-darkLos 8 colores de tema como fondo.
bg-white / bg-blackFondo blanco / negro fijo.
bg-transparentSin fondo (transparente).
bg-body / bg-body-secondaryEl color de fondo del body y su secundario.
bg-gradientAgrega un degradado lineal al color.
bg-opacity-25/50/75Fondo del color con …% de opacidad.
Para fondo con texto legible existe la combinación text-bg-* (ej. text-bg-danger): pinta el fondo de danger y el texto de un color que contraste solo. Ideal para badges y alertas.
