Utilidades: la herramienta que reemplaza la mitad del CSS

La fórmula del espaciado

Los márgenes y rellenos se escriben con una fórmula de 3 partes: <propiedad><lado>-<medida>.

ParteValoresSignificado
Propiedadp, mpadding / margin
Ladot, b, s, e, x, y o vacíotop, bottom, start (izq), end (der), eje X, eje Y, los cuatro
Medida0–5 o auto0=0 · 1=.25rem · 2=.5rem · 3=1rem · 4=1.5rem · 5=3rem · auto=automático
mt-4        /* margin-top: 1.5rem    */
px-3        /* padding horizontal: 1rem */
mx-auto     /* margin: 0 auto → centra el bloque */
mt-md-4     /* el margen recién desde pantalla md */
pt-0        /* quita el padding superior */
mx-auto es la forma más común de centrar un elemento de ancho fijo; ms-auto / me-auto empujan un elemento a la derecha / izquierda (muy usados en navbars).

Display: d-*

Es el display de CSS como clases. Con prefijos responsive: d-md-flex activa flex desde tableta.

ClaseEquivale en CSS a
d-nonedisplay: none (oculta, es la base del menú hamburguesa)
d-block / d-inline / d-inline-blockbloque / en línea / bloque-en-línea
d-flex / d-inline-flexdisplay: flex y su versión en línea
d-griddisplay: grid (base del botón "ancho completo")
d-table / d-table-row / d-table-celldisplay de tabla
d-print-*Varía el display solo al imprimir.
<div class="d-none d-md-block">Solo visible en tablet o más grande</div>
<div class="d-grid gap-2"><button class="btn btn-primary">Botón a todo lo ancho</button></div>

Flexbox sin escribir CSS

ClaseEquivale en CSS a
flex-row / flex-column / flex-row-reverseflex-direction
flex-wrap / flex-nowrap / flex-wrap-reverseflex-wrap
justify-content-start / -center / -end / -between / -around / -evenlyjustify-content (eje principal)
align-items-start / -center / -end / -baseline / -stretchalign-items (eje secundario)
align-self-*align-self para un solo hijo
flex-grow-1 / flex-shrink-0Crece / no encoge
order-0…order-5order (reordena los hijos)
gap-1…gap-5gap entre hijos (también row-gap-*, column-gap-*)
Todo esto acepta breakpoints: justify-content-md-between, flex-lg-column… Se combina con d-flex para lograr layout típico de "título a la izquierda, botones a la derecha".

Posición, fija y sticky

ClaseQué hace
position-static / -relative / -absolute / -fixed / -stickyposition de CSS.
top-0 / top-50 / top-100top: 0 / 50% / 100% (igual bottom-*, start-*, end-*).
translate-middleCentra exacto sobre el punto (clásico badge "cantidad").
fixed-top / fixed-bottomFija el elemento arriba / abajo de la ventana.
sticky-topSe queda pegado al tope al hacer scroll (el header de esta guía).
sticky-sm-top…sticky-xxl-topIgual pero solo desde ese breakpoint.

Las últimas utilidades sueltas

ClaseQué hace
float-start / float-end / float-noneFlota a la izquierda / derecha (con breakpoints: float-md-end).
clearfixLimpia los flotados del contenedor.
overflow-auto / -hidden / -visible / -scrolloverflow para contenido que desborda.
opacity-25 / -50 / -75 / -100Opacidad del elemento.
visible / invisiblevisibility (ocupa lugar pero no se ve).
user-select-all / -auto / -noneControla si el texto se puede seleccionar.
pe-none / pe-autopointer-events: ignora / acepta clics.
z-0…z-3 / z-n1Capas z-index.
ratio-1x1 / -4x3 / -16x9 / -21x9Envuelve un elemento (ej. video) en proporción fija.
Resumen mental: casi toda utilidad responde a nombre + breakpoint + valor. Si conocés el valor pequeño, el resto son combinaciones sobre el mismo patrón.
