Formularios: todos los controles estilizados

La estructura básica

Tres clases cubren el 90%: form-label para el rótulo, form-control para la caja, y form-text para la ayuda.

<form>
  <label for="email" class="form-label">Correo</label>
  <input type="email" class="form-control" id="email" placeholder="vos@mail.com">
  <div class="form-text">Nunca compartiremos tu correo.</div>
</form>
La clase form-control es la que "arregla" cualquier <input>, <select> y <textarea>. Sin ella los controles se ven con el estilo feo del navegador.

Tipos de campo y sus clases

CampoClase
<input type="text | password | email | number | date …">form-control
<textarea rows="…">form-control (los rows van en el HTML).
<select> (desplegable)form-select
<input type="range"> (slider)form-range (con min, max, step)
<input type="file">form-control (ya viene estilizado)
Grupo de checkbox / radioform-check
Switch (interruptor)form-check form-switch

Checkbox, radio y switch

<div class="form-check">
  <input class="form-check-input" type="checkbox" id="acepto">
  <label class="form-check-label" for="acepto">Acepto los términos</label>
</div>

<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" id="modo">
  <label class="form-check-label" for="modo">Modo oscuro</label>
</div>

<div class="form-check form-check-inline">
  <input class="form-check-input" type="radio" name="grupo" id="a">
  <label class="form-check-label" for="a">Opción A</label>
</div>

La cajita / botoncito es form-check-input y el texto form-check-label. form-check-inline los deja en fila en vez de apilados. Las radios comparten el mismo name para que se seleccione solo una.

Input group: rótulos y botones pegados al campo

<div class="input-group">
  <span class="input-group-text">$</span>
  <input type="text" class="form-control" aria-label="Precio">
  <button class="btn btn-outline-secondary">Verificar</button>
</div>

input-group une el campo con input-group-text (prefijo/sufijo) y hasta botones, sin espacios.

Tamaños, estados y validación

ClaseQué hace
form-control-lg / form-control-smCajas grandes / chicas (igual con form-select-lg).
disabled / readonlyCampo inactivo / de solo lectura (atributos HTML).
is-invalidBorde rojo, marca el error.
is-validBorde verde, marca que pasó.
invalid-feedbackEl mensaje de error debajo del campo (se activa con is-invalid).
valid-feedbackEl mensaje de éxito.
<div>
  <label class="form-label">Usuario</label>
  <input class="form-control is-invalid">
  <div class="invalid-feedback">El usuario ya está en uso.</div>
</div>

<form class="needs-validation" novalidate>
  <!-- Bootstrap valida el formulario solo con un pequeño JS -->
  <input class="form-control" required>
</form>

Floating labels: la etiqueta flotante

<div class="form-floating">
  <input type="email" class="form-control" id="mail" placeholder="nombre@mail.com">
  <label for="mail">Correo</label>
</div>

La etiqueta vive dentro del campo y "flota" arriba cuando el campo tiene texto. Requiere el atributo placeholder para que funcione.
