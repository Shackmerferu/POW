Programación Orientada a la Web

Resumen de la teoría de la materia, organizado en 9 unidades (Lic. G. Lafuente — Facultad de Ingeniería, UNLPam). En cada unidad todos los temas están juntos, separados por encabezado: cada tema trae una definición, su sintaxis y un ejemplo que se ejecuta en vivo debajo.

Elegí una unidad en el selector de arriba o en las tarjetas de abajo.

Unidades Índice de contenido

Unidad 1HTMLEstructura del documento, etiquetas de texto, listas, enlaces, imágenes, tablas, formularios, semántica HTML5 e iframes. Unidad 2CSSFormas de incluir, selectores, cascada y herencia, box model, colores, tipografía, posicionamiento, Flexbox, Grid y responsive. Unidad 3BootstrapCDN, grilla, contenedores y breakpoints, utilidades, componentes, formularios, navegación y componentes con JavaScript. Unidad 4JavaScriptInclusión, variables y tipos, operadores, control de flujo, funciones, arrays y objetos, strings, eventos, DOM y módulos ES6. Unidad 5AJAXConcepto, tecnologías, XMLHttpRequest, GET vs POST, JSON, validación de formularios, Fetch API y patrones con API encadenadas. Unidad 6jQueryLibrerías y Prototype, sintaxis, selectores, eventos, efectos, manipulación HTML/CSS, AJAX con jQuery y noConflict. Unidad 7PHPSintaxis y tipos, variables y superglobales, control y funciones, arrays y strings, formularios, archivos, sesiones y POO. Unidad 8MySQL + PHPXAMPP, crear base e importar .sql, conexión con mysqli, SELECT/INSERT/UPDATE/DELETE, filtros dinámicos, JSON y seguridad. Unidad 9Subida de archivosmultipart/form-data, $_FILES, validación, move_uploaded_file(), guardar en MySQL y subida con AJAX y FormData.
