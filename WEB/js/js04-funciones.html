Funciones

Fuente: Javascript_II.pdf

¿Qué son?

  • Las funciones hacen "cualquier cosa", por ejemplo imprimir un mensaje de alerta.
  • Pueden tomar un dato (parámetros), manipularlo y retornar un valor.
  • Tras ser definidas quedan disponibles; se invocan a través de su nombre cuando se las necesita (por ejemplo, desde un evento).

Declaración y llamado

// Declaración
function nombreFuncion() {
  // Código de la función
}

// Llamado
var x = nombreFuncion();

Ejemplo 1: función sin parámetros

<SCRIPT>
function warning() {
  document.write("<DIV STYLE='color:red; text-align:center; font-size:32pt;'>Warning!</DIV>");
  document.write("<BR>");
  document.write("<DIV STYLE='color:green; text-align:center; font-size:24pt;'>Ud. ha sido avisado!</DIV>");
}
var x = warning();
</SCRIPT>

Ejemplo 2: función con parámetros y retorno

<SCRIPT>
function multiplicar(a, b) {
  var producto = 0;
  producto = a * b;
  return producto;
}
var x = multiplicar(3, 5);
document.write(x);   // muestra 15
</SCRIPT>

¿Qué hace cada parte?

ElementoQué significa
function multiplicar(a, b)Declara la función llamada multiplicar que recibe dos parámetros: a y b.
var producto = 0;Variable local que guarda el resultado de la operación.
return producto;Entrega el valor calculado a quien llamó a la función.
var x = multiplicar(3, 5);Invoca la función con los argumentos 3 y 5; el resultado queda guardado en x.
