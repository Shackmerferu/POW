Formas de mostrar contenido (salida)

Método¿Qué hace?
document.write("texto"+"<BR>")Escribe directamente en la página (borra el contenido actual de la página si se ejecuta tras cargar).
console.log("texto")Muestra en la consola del navegador (ideal para depurar).
window.alert()Abre una ventana de mensaje con un botón Aceptar.

<SCRIPT>
  document.write("Hola Mundo" + "<BR>");
  document.write("<B>Hola JavaScript</B>");

  • El texto puede ir entre comillas simples o dobles.
  • Los tags HTML embebidos en el texto son interpretados por el navegador. <B>… pone el texto en negrita.
  • Para mostrar los tags como texto se usan caracteres de escape: &lt; = <, &gt; = >.

Variables: var, let y const

FormaQué hace
var xDefine una variable con ámbito global o de función.
let x = 5Variable con valor variable. No puede redeclararse; si se usa dentro de un bloque { } no puede accederse fuera de él.
const PI = 3.14Constante con valor fijo. No puede redefinirse (PI = 3 es inválido).
x = 2 (sin n-ada declaración)Se asigna un valor sin declarar: la variable queda global.
Ojo: let y const se agregaron en ES2015; no funcionan en navegadores muy antiguos que no contemplen ese estándar.

Redefinir ≠ reasignar

let x = 4;
let x = 54;   // ERROR: se está REDEFINIENDO (no es válido)

let x = 4;
x = 54;       // OK: se está REASIGNANDO el valor (sin usar let)

Ámbito en bloques

var (o una variable sin declarar) es global en el documento o en la función. let y const pueden limitarse a un bloque { }:

let x = 5;
{
  let x = 5;   // este x vive solo dentro del bloque
  ...
}
// al finalizar el bloque, x vale 5 (el del exterior)

Tipos de datos

  • Cadena de caracteres (string): "Hola JavaScript", 'Hola JavaScript'
  • Números (number): 1, 5, 3.14, 65000
  • Booleanos (boolean): true, false

Reglas de las variables

  • JavaScript distingue mayúsculas/minúsculas: PEPE, Pepe y pepe son variables distintas.
  • Deben comenzar con una letra o subrayado (_); luego letras, números o subrayados.
  • JS no es tipado: las variables no declaran tipo y la conversión es automática.
  • Conviene inicializar indicando el tipo para clarificar: var nombre = "", var año = 0, var vive = true.
  • Una variable puede ser reasignada con otro tipo: var dato = 0; dato = "hola mundo"; es válido.

Respetando el contenido de las variables

Aunque JS no es tipado, hay que respetar qué contiene cada variable. La conversión automática puede dar resultados sorprendentes:

var r = 2;   r = r + 5;     // r = 7      (suma)
var r = "2"; r = r + 5;     // r = "25"   (concatenación de un string y un entero)
var r = "2"; r = r * 5;     // r = 10     (aunque sea string, el * fuerza multiplicación)
var r = "2"; r = r - 5 + r; // r = -32    (resta y luego concatena)
var r = "ra" + 16;          // r = ra16
var r = 2 * 3 + "ra";       // r = 6ra
