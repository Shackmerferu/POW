Strings (cadenas de caracteres)

Fuente: Javascript_II.pdf

¿Qué es un string?

Un string es cero o más caracteres encerrados entre comillas (simples o dobles). Tiene un conjunto de métodos que se le pueden aplicar.

var cad  = "esto es una cadena";
var cad2 = "";      // string vacío
var cad3 = 'hola';
var length = text.length;   // cantidad de caracteres

Métodos de manipulación

MétodoQué hace
lengthCantidad de caracteres de la cadena.
slice()Extrae parte de la cadena según posición (inicio, fin).
substring() / substr()Extraen subcadenas.
replace() / replaceAll()Reemplazan (la primera / todas) las ocurrencias de un texto.
toUpperCase() / toLowerCase()Pasa la cadena a mayúsculas o minúsculas.
concat()Concatena cadenas.
trim() / trimStart() / trimEnd()Eliminan los espacios en blanco (de los extremos, principio o final).
padStart() / padEnd()Rellenan la cadena con caracteres hasta un largo dado.
charAt() / charCodeAt()Devuelven el carácter, o su código, en una posición.
split()Divide la cadena en un arreglo según un separador.

Métodos de búsqueda

MétodoQué hace
indexOf() / lastIndexOf()Devuelve la posición (índice) de la primera / última aparición de un texto.
search()Busca un texto y devuelve su posición.
match() / matchAll()Obtienen las coincidencias con una expresión regular.
includes()Devuelve true si la cadena contiene el texto indicado.
startsWith() / endsWith()Devuelven true si la cadena comienza / termina con el texto indicado.

Template literals (plantillas literales)

Usan comillas invertidas (backticks `` `` ``) para definir la cadena.

  • Permiten incluir comillas dentro del texto sin escaparlas.
  • Permiten escribir string en varias líneas.
  • Permiten interpolar variables y expresiones con ${…}.
var nombre = `el nombre es "pep"`;
var texto = `esto es
un texto`;   // con comillas dobles esto no es posible

let nombre = "Juan";
let apellido = "Perez";
let saludar = `mi nombre es ${nombre} ${apellido}`;

let price = 10;
let VAT = 0.25;
let total = `Total: ${(price * (1 + VAT)).toFixed(2)}`;  // "Total: 12.50"
