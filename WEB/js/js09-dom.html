DOM — Modelo de Objetos del Documento

Fuente: Javascript_II.pdf

¿Qué es el DOM?

  • Es una API (interfaz de programación) que proporciona un conjunto estándar de objetos para representar documentos HTML y XML, y una interfaz estándar para acceder y manipular su contenido, estructura y estilo.
  • El responsable del DOM es el World Wide Web Consortium (W3C).
  • Permite que programas como JavaScript agregen, cambien o eliminen contenido dinámicamente.

Jerarquía de objetos del navegador

window
   + history
   + location
   + document
      + anchor / applet / area / image / link / plugin
      + form
         + button / checkbox / fileUpload / hidden / password
         + radio / reset / select (+ options) / submit / text / textarea
   + frame

Los descendientes de un objeto son propiedades de ese objeto, y se accede con puntos:

document.title = "un simple documento";
document.myform.length = 5;
document.anchors[0].name;
document.forms[0].method;
document.forms[0].elements[1].value;
document.links[0].href;

El objeto window

Es el objeto padre de todos los objetos del navegador.

Acceso directo a los nodos (selectores)

MétodoQué haceDevuelve
getElementById("id")Busca por id (único). El más usado.1 elemento
getElementsByTagName("p")Busca por etiqueta HTML.Colección
getElementsByName("nombre")Busca por atributo name.Colección
getElementsByClassName("clase")Busca por clase CSS.Colección
querySelector("p")Devuelve el primer elemento que coincide con un selector CSS (tag, .clase, #id…).1 elemento
querySelectorAll("p.intro")Devuelve todos los elementos que coinciden con un selector CSS.Lista
// Por id
var cabecera = document.getElementById("encabezado");

// Por etiqueta (recorriendo todos los párrafos)
var parrafos = document.getElementsByTagName("p");
var primerParrafo = parrafos[0];
for (var i = 0; i < parrafos.length; i++) {
  var parrafo = parrafos[i];
}

// Por clase
const x = document.querySelectorAll("p.intro");
document.getElementById("demo").innerHTML = x[0].innerHTML;

// querySelector: primer elemento que coincida
document.querySelector("p").style.backgroundColor = "red";

Crear elementos nuevos

// Crear nodo de tipo Element
var parrafo = document.createElement("p");
// Crear nodo de tipo Text
var contenido = document.createTextNode("Hola Mundo!");
// Añadir el Text como hijo del Element
parrafo.appendChild(contenido);
// Añadir el Element como hijo del body
document.body.appendChild(parrafo);

Eliminar nodos

removeChild() debe invocarse desde el padre del nodo. La forma segura es usar nodoHijo.parentNode:

var parrafo = document.getElementById("sacame");
parrafo.parentNode.removeChild(parrafo);

Acceder y modificar atributos

// Obtener el valor de un atributo
var imagen = document.getElementById("fender");
alert(imagen.getAttribute("src"));       // "stratocaster.jpg"

// Cambiar el valor de un atributo
imagen.setAttribute("src", "GuittarraElectrica.jpg");

innerHTML y style

innerHTML accede y cambia el contenido (HTML) dentro de un elemento. Es muy usado en librerías como jQuery.

Diferencia con document.write: document.write escribe en la página borrando su contenido actual, mientras que innerHTML muestra el contenido dentro de un elemento sin borrar la página.

<p id="demo"></p>
<script>
document.getElementById("demo").innerHTML = 5 + 6;   // muestra 11
</script>
// Modificar estilos CSS desde JavaScript
document.getElementById("intro").style.color = "#fff";
document.getElementById("intro").style.backgroundColor = "#f58220";  // naranja
var brandColor = document.getElementById("intro").style.backgroundColor;

Agregar eventos modernos: addEventListener()

<button id="myBtn">Apretar</button>
<p id="demo"></p>
<script>
document.getElementById("myBtn").addEventListener("click", displayDate);
function displayDate() {
  document.getElementById("demo").innerHTML = Date();
}
</script>
Ventaja: permite agregar varios manejadores al mismo elemento y no sobreescribe los existentes (a diferencia de onclick="…" en el HTML).
