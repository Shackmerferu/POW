Introducción a JavaScript

Fuente: Javascript_II.pdf

¿Qué es JavaScript?

  • Es un lenguaje compacto de "scripting" basado en objetos, pensado para desarrollar aplicaciones de Internet cliente–servidor.
  • Los scripts se embeben en un documento HTML: pueden colocarse tanto en la etiqueta <head> como dentro del <body>.
  • Puede reconocer y responder a eventos del usuario sin necesidad de conexión a la red, por ejemplo con validaciones de formularios.

Un poco de historia

Fue desarrollado originalmente por Brendan Eich para Netscape con el nombre Mocha, luego renombrado LiveScript y finalmente JavaScript.

Desde junio de 2015 se versiona cada año bajo el estándar ECMAScript. El estándar actual de referencia es ECMAScript 2026 (1 de junio de 2026).

Características principales

  • Interpretado: un intérprete incorporado en el navegador ejecuta el código, incluso código generado dinámicamente.
  • Sintaxis similar a Java o C++ que facilita la adaptación. Diferencia: el punto y coma (;) es opcional al final de cada sentencia.
  • Basado en objetos pero sin clases propias: la herencia se logra a través de prototipos.
  • Usa una jerarquía de objetos encabezada por el navegador (el DOM).
  • Proporciona un conjunto de objetos predefinidos muy útiles.
  • Permite capturar y tratar eventos provocados por el usuario o por el navegador.
  • Es la base para incorporar otras tecnologías web como HTML dinámico, XML, y forma parte de AJAX.

Donde se ejecuta

Lado del clienteLado del servidor
  • Se incluye en el documento HTML y se descarga con él.
  • Funciones y variables con el tag <script>…</script>.
  • Es interpretado por la gran mayoría de los navegadores del mercado.
  • Accede a la ventana (window), a los formularios (form), a los enlaces (links)…
  • También puede crear HTML dinámico.
  • Inicialmente lo ejecutaba el servidor Netscape (LiveWire); hoy hay muchos más: Node.js, Jaxer, EJScript, RingoJS, AppengineJS.
  • Accede al estado del servidor (estado por usuario).
  • Maneja requerimientos HTTP concurrentes (chequeos de usuarios y dominios).
  • Accede a bases de datos invocando consultas SQL.

Cómo se incluye en la página

1. Código embebido directamente

<HTML>
  <HEAD>
    <SCRIPT language="JavaScript">
      alert("Hola JavaScript");
    </SCRIPT>
  </HEAD>
  <BODY>
    <P>Esto es un simple alerta JavaScript
  </BODY>
</HTML>

2. Código enlazado desde un archivo externo

<HTML>
  <HEAD>
    <SCRIPT language="JavaScript" src="codigo.js">
    </SCRIPT>
  </HEAD>
  <BODY>
  </BODY>
</HTML>
Consejo: colocar los scripts en la parte inferior del <body> mejora la velocidad de visualización, porque la interpretación de los scripts relentiza la carga de la página.

JavaScript vs Java

JavaJavaScript
Requiere compilación.No requiere compilación: es interpretado por los navegadores.
Lenguaje pesado, potente y robusto, con gran control.Ligero, ágil y poco robusto: no permite hacer de todo.
Orientación a objetos pura.No es clasificable bajo un único paradigma.
Requiere un kit de desarrollo y máquina virtual Java.Solo un navegador (para ver resultados) y un editor de texto.
Fuertemente tipado.Débilmente tipado: las variables pueden cambiar de tipo en la ejecución.
Clases e instancias son entidades distintas; define clases con constructores.Los objetos se definen con funciones constructoras y se crean con new.
Hereda propiedades por la cadena de clases; no agrega propiedades dinámicas.Hereda por la cadena de prototipos y permite agregar/quitar propiedades en tiempo de ejecución.
