Eventos y gestores de eventos

Fuente: Javascript_II.pdf

¿Qué es un evento?

Un evento es una acción que ocurre sobre la página: mover el mouse, clickear, escribir una tecla, enviar un formulario, etc. Los eventos suceden a tres niveles:

  1. A nivel del documento HTML.
  2. A nivel de un formulario individual.
  3. A nivel de un elemento de un formulario.

Cada evento es gestionado por un gestor (manejador) de eventos: una sección de código JavaScript.

Sintaxis: gestores como atributos HTML

<BODY onLoad="cargarfuncion()" onUnload="descargarfuncion()">
<FORM name="nombre_del_formulario" onSubmit="función_o_sentencia">
  <INPUT type="button" name="mycheck" value="HA!" onClick="alert('Te he dicho que no me aprietes')">
<H2 onclick="funcionClick()">Cliquéame</H2>

<!-- Se puede poner una función o varias instrucciones -->
<INPUT type="text" onChange="if(parseInt(this.value) <= 5) { alert('Ponga un número mayor que 5.'); }">

La palabra clave this

this hace referencia al objeto que produjo el evento. Permite acceder a los atributos de esa marca, por ejemplo su value:

<input type="text" onChange="checaCampo(this)">

Cambiar el comportamiento de un enlace (return)

Antes de la función va return, para devolverle el resultado true/false a la etiqueta:

<a href="mi_pagina.html" onclick="return confirm('Ud. quiere ir a mi_pagina.html?');">ir a mi página</a>
<a href="mi_pagina.html" onclick="return confirmar();">ir a mi página</a>

Ejemplo: validar un campo antes de enviar el formulario

<script>
function validateForm() {
  var x = document.forms["myForm"]["fname"].value;
  if (x == "") {
    alert("Name must be filled out");
    return false;
  }
}
</script>

<form name="myForm" action="/action_page.php" onsubmit="return validateForm()" method="post">
  Name: <input type="text" name="fname">
  <input type="submit" value="Submit">
</form>
Actualidad: hoy la mayoría de estas validaciones se resuelven con HTML5 usando el atributo required, evitando escribir ese código JS.

Ejemplo: cambiar imagen con onMouseOver / onMouseOut

<a href="#" onMouseOver="document.the_image.src='stuff/js_on.gif';"
           onMouseOut="document.the_image.src='stuff/js_off.gif';">
  <img src="stuff/js_des.gif" name="the_image" border="0"></a>
