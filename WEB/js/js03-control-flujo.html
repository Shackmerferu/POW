Control de flujo

Fuente: Javascript_II.pdf

Sentencias condicionales

1. if … else

if (condición a evaluar) {
  // Bloque que se ejecuta si la condición es verdadera
} else {
  // Bloque que se ejecuta si la condición es falsa
}

2. if … else if … else

Encadena varias condiciones hasta encontrar la verdadera.

var color = "azul";
if (color == "rojo") {
  document.write("el color es rojo");
  document.write("<HR>");
} else if (color == "azul") {
  document.write("el color es azul");
} else {
  document.write("el color no es ni rojo ni azul");
}

3. switch

Compara una expresión con varios casos. Es útil cuando hay muchas alternativas.

4. Operador ternario condición ? valorSiVerdadero : valorSiFalso

Es un if…else compacto en una sola línea.

Bucles

for

Crea un bucle con tres expresiones opcionales separadas por ; y seguidas de un bloque de sentencias.

for (var i = 0; i <= 1000; i = i + 100) {
  document.write(i + "<BR>");
}

for … in

Itera sobre todas las propiedades (índices) de un objeto o arreglo.

var x;
var misautos = new Array();
misautos[0] = "Ferrari";
misautos[1] = "Volvo";
misautos[2] = "BMW";
for (x in misautos) {
  document.write(misautos[x] + "<br />");
}

while

Ejecuta el bloque mientras la condición sea verdadera.

var i = 0;
while (i <= 1000) {
  document.write(i + "<BR>");
  i = i + 100;
}

Palabras reservadas útiles en bucles

PalabraQué hace
breakTermina (corta) el bucle actual y transfiere el control a la siguiente sentencia fuera del bucle.
continueTermina la iteración actual y continúa el bucle con la próxima iteración.
commentAnotaciones del autor para explicar el script (ignoradas por el intérprete).
