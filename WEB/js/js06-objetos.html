Objetos

Fuente: Javascript_II.pdf

¿Qué es un objeto?

  • Los objetos son variables que pueden almacenar valores y funciones (métodos).
  • Son uno de los conceptos más importantes de JavaScript.
  • Los objetos son colecciones de propiedades; las propiedades pueden modificarse, añadirse y eliminarse.
  • Existen objetos preconstruidos con funciones predefinidas (fecha/hora, matemáticas, etc.).

Crear un objeto personalizado con new Object

<SCRIPT>
var remera = new Object;
remera.color = "roja";
remera.size = 8;
remera.type = "algodon";
document.write(remera.color + "<BR>");
document.write(remera.size + "<BR>");
document.write(remera.type + "<BR>");
</SCRIPT>

Formas de declarar un objeto

Con literal de objeto

const car = { type: "Fiat", model: "500", color: "white" };
// acceso: car.type, car.model, car.color

Declarar vacío y agregar propiedades después

const person = {};
person.firstName = "John";
person.lastName = "Doe";
person.age = 50;
person.eyeColor = "blue";

Con new Object({...})

const person = new Object({
  firstName: "John", lastName: "Doe", age: 50, eyeColor: "blue"
});

Métodos dentro de un objeto

Un método es una función guardada como propiedad. Dentro del método, this hace referencia al propio objeto.

const person = {
  firstName: "John",
  lastName: "Doe",
  id: 5566,
  fullName: function() {
    return this.firstName + " " + this.lastName;
  },
  getId: function() {
    return this.id;
  }
};
let number = person.getId();

Agregar un método después de creado el objeto

person.name = function () {
  return (this.firstName + " " + this.lastName).toUpperCase();
};

Objetos preconstruidos

Fecha/hora: new Date()

<SCRIPT>
var miDia = new Date();
document.write(miDia + "<BR>");
var x = miDia.toGMTString();
document.write(x + "<BR>");
</SCRIPT>

Matemáticas: objeto Math

Constantes: E, LN10, LN2, LOG10E, LOG2E, PI, SQRT1_2, SQRT2.

Métodos: abs(), acos(), atan(), atan2(), ceil(), cos(), exp(), floor(), log(), max(), min(), pow(), random(), round(), sin(), sqrt(), tan().

Útil: Math.random() devuelve un número aleatorio entre 0 y 1; Math.max/min(a, b) devuelven el mayor/menor entre dos valores.
