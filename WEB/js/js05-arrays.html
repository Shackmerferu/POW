Arreglos (arrays)

Fuente: Javascript_II.pdf

¿Qué son?

Los arreglos son útiles para crear, ordenar y manipular listas, generalmente combinándolos con bucles para recorrerlos.

Creación de un arreglo

var nombreArray = new Array();       // arreglo vacío
var nombreArray = new Array(10);     // arreglo con espacio para 10 ítems
var gatos = new Array(4);
gatos[0] = "Tom";
gatos[1] = "Lucas";
gatos[2] = "Adam";
gatos[3] = "Luis";

// También se puede crear con los valores directamente:
var gatos = new Array("Tom", "Lucas", "Adam", "Luis");

Propiedades y métodos

ElementoQué hace
nombreArray.lengthDevuelve la longitud (cantidad de elementos) del arreglo.
sort()Ordena los elementos.
reverse()Invierte el orden de los elementos.
pop()Quita el último elemento del arreglo.
push()Agrega un elemento al final del arreglo.
join()Une los elementos en una cadena separada por un carácter indicado.
toString()Convierte el arreglo a texto.
Extensión de un arreglo: si se necesita más espacio, se reasigna un nuevo tamaño mediante asignación directa al índice siguiente.
