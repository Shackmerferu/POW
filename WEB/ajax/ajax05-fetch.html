Fetch API — el método moderno

Fuente: ajax_II.pdf

¿Qué es fetch()?

Actualmente las llamadas asíncronas en JavaScript se hacen con el método moderno basado en promesas: la API Fetch, que permite descargar (obtener) datos de un servidor web.

  • await fetch() es la API moderna para obtener datos de un servidor HTTP.
  • XMLHttpRequest() era la API heredada (antigua); hoy se usa solo cuando hace falta un control estricto en la carga de información o muchas conexiones síncronas a la vez.
  • Fetch es más sencillo que XMLHttpRequest.

Cómo funciona

  • Se puede usar para cargar archivos de texto, datos JSON, imágenes y muchos otros recursos.
  • La descarga es asíncrona: JavaScript sigue ejecutándose mientras espera la respuesta del servidor.
  • fetch(archivo) devuelve una promesa que se resuelve en un objeto Response.

Forma 1: con promesas (.then())

// Versión larga
fetch(file)
  .then(function(response) {
    return response.text();
  })
  .then(function(data) {
    myDisplayer(data);
  });

// Versión con flechas (arrow functions)
fetch(file)
  .then(response => response.text())
  .then(data => myDisplayer(data));

Forma 2: con función asincrónica (async/await)

async function loadText(file) {
  const response = await fetch(file);
  myDisplayer(await response.text());
}
// llamado a la función
loadText("fetch.txt");

Propiedades/estado de la respuesta

async function loadText(file) {
  const response = await fetch(file);
  myDisplayer(response.ok);   // true si la respuesta fue correcta (status 200-299)
}

Trabajar con datos JSON

async function loadCustomer() {
  const response = await fetch("customer.json");
  const customer = await response.json();
  myDisplayer(customer.name);
}
loadCustomer();

¿Qué devuelve cada cosa?

CódigoQué hace
fetch(archivo)Inicia la descarga y devuelve una promesa.
response.text()Devuelve el contenido como texto.
response.json()Convierte la respuesta en objeto JavaScript (JSON).
response.okBooleano que indica si la respuesta fue exitosa.
awaitDetiene la ejecución de la función hasta que la promesa se resuelve (solo dentro de una función async).
