El objeto XMLHttpRequest

Fuente: ajax_II.pdf

¿Qué es?

Es el objeto clave de AJAX: permite realizar comunicaciones con el servidor en segundo plano, sin recargar la página. Su implementación depende de cada navegador.

Crear el objeto (compatibilidad)

if (window.XMLHttpRequest) {
  peticion_http = new XMLHttpRequest();          // navegadores que siguen estándares
} else if (window.ActiveXObject) {
  peticion_http = new ActiveXObject("Microsoft.XMLHTTP");  // navegadores obsoletos (IE viejos)
}

Propiedades del objeto

PropiedadDescripción
readyStateValor entero que almacena el estado de la petición (0 a 4).
responseTextContenido de la respuesta del servidor en forma de cadena de texto.
responseXMLContenido de la respuesta en formato XML; se procesa como objeto DOM.
statusCódigo de estado HTTP: 200 correcto, 404 "No encontrado", 500 error de servidor, etc.
statusTextEstado HTTP como texto: "OK", "Not Found", "Internal Server Error", etc.

Valores de readyState

ValorEstadoDescripción
0No inicializadoObjeto creado, pero no se invocó open().
1CargandoObjeto creado, pero no se invocó send().
2CargadoSe invocó send(), pero el servidor aún no respondió.
3InteractivoSe recibieron algunos datos (aún no se puede usar responseText).
4CompletoSe recibieron todos los datos de la respuesta.

Procesar la respuesta: onreadystatechange vs onload

  • onreadystatechange: propiedad que permite asignar la función que procesa la respuesta y conocer el estado de la llamada (revisar readyState y status).
  • onload: solo contempla el estado cargado; no hay que revisar los estados intermedios.
peticion_http.onreadystatechange = muestraContenido;

function muestraContenido() {
  if (peticion_http.readyState == 4) {          // respuesta completa
    if (peticion_http.status == 200) {          // respuesta correcta
      alert(peticion_http.responseText);
    }
  }
}

// Con onload no hace falta preguntar los estados:
function muestraContenido() {
  alert(peticion_http.responseText);
}

Realizar la petición: open() y send()

peticion_http.open('GET', 'http://localhost/prueba.txt', true);
peticion_http.send(null);
MétodoQué hace / parámetros
open(tipo, url, asíncrono)Prepara la petición: tipo (GET/POST…), url solicitada y asíncrono (true = asíncrono, false = síncrono).
send(null)Envía la petición. En GET simple va null; en POST lleva los datos.
setRequestHeader("Content-Type", "application/x-www-form-urlencoded")Declara el tipo de contenido al enviar datos por POST.

GET vs POST

GETPOST
Es más simple y rápido; sirve en la mayoría de los casos.Se usa cuando es necesario actualizar un archivo o una base de datos del lado del servidor.
Va con los datos en la URL: ?variable=valor.Envía grandes cantidades de datos (no tiene limitación de tamaño).
Los datos quedan visibles en la URL.Más robusto y seguro para entrada del usuario (caracteres desconocidos).

Asíncrono: ¿true o false?

true (asíncrono): el código JavaScript no espera la respuesta del servidor y puede seguir ejecutando otros scripts mientras llega la respuesta. Recomendado

false (síncrono): no se recomienda: si el servidor es lento, la ejecución del JavaScript se bloquea hasta que la respuesta esté lista (la función puede colgarse).

Ejemplo completo: cargar archivo en un DIV

<div id="demo">
  <h1>AJAX cambiando el contenido de una página</h1>
  <button type="button" onclick="cargar_documento()">Cargar archivo holamundo.txt</button>
</div>

<script>
function cargar_documento() {
  var xhttp = new XMLHttpRequest();
  xhttp.onreadystatechange = function() {
    if (this.readyState == 4 && this.status == 200) {
      document.getElementById("demo").innerHTML = this.responseText;
    }
  };
  xhttp.open("GET", "holamundo.txt", true);
  xhttp.send();
}
</script>
Versión corta con onload:
function loadDoc() {
  const xhttp = new XMLHttpRequest();
  xhttp.onload = function() {
    document.getElementById("demo").innerHTML = this.responseText;
  };
  xhttp.open("GET", "holamundo.txt");
  xhttp.send();
}
