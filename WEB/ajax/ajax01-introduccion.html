Introducción a AJAX

Fuente: ajax_II.pdf

¿Qué es AJAX?

AJAX es el acrónimo de Asynchronous JavaScript + XML ("JavaScript asíncrono + XML").

AJAX no es una tecnología en sí mismo (no es un lenguaje de programación). Es una técnica de desarrollo web que une varias tecnologías independientes para crear aplicaciones interactivas (RIA — Rich Internet Applications).

Estas aplicaciones se ejecutan en el cliente (el navegador del usuario) mientras se mantiene la comunicación asíncrona con el servidor en segundo plano. Así es posible cambiar el contenido de las páginas sin recargarlas, mejorando interactividad, velocidad y usabilidad.

¿Qué tecnologías une AJAX?

Cómo trabaja AJAX

  1. Ocurre un evento (click en un botón, selección, etc.).
  2. Se crea el objeto AJAX (XMLHttpRequest).
  3. Se envía una HttpRequest al servidor.
  4. El servidor procesa la petición.
  5. El servidor crea la respuesta y la envía en segundo plano al navegador.
  6. JavaScript procesa lo recibido.
  7. Se actualiza el contenido de la página.

Modelo tradicional vs Modelo AJAX

Modelo tradicionalModelo AJAX
  • Las acciones del usuario (click, cambiar un valor) disparan llamadas al servidor.
  • El servidor devuelve una nueva página HTML completa.
  • El usuario debe esperar a que se recargue la página con cada cambio.
  • Se crea una capa intermedia entre el usuario y el servidor.
  • El intercambio de datos con el servidor ocurre en segundo plano, sin cortar la interacción.
  • El usuario nunca ve una ventana vacía esperando la respuesta.
  • Las peticiones HTTP directas se sustituyen por peticiones JavaScript al elemento encargado de AJAX.

Origen: el objeto XMLHttpRequest

La historia de AJAX está ligada al objeto XMLHttpRequest, nacido alrededor del año 2000 con productos como Exchange 2000, Internet Explorer 5 y Outlook Web Access (OWA). De la necesidad de no recargar formularios constantemente surgió la primera versión de lo que se llamó XMLHTTP.

Consideraciones importantes

  • Historial: las páginas creadas dinámicamente con AJAX no quedan registradas en el historial del navegador (el botón "Volver" no vuelve al estado anterior).
  • SEO: los buscadores no siempre indexan contenido generado por JavaScript (Google indexa desde 2011, pero puede tardar).
  • Dominios: la Same Origin Policy impide acceder entre dominios distintos; se soluciona con CORS (Cross-Origin Resource Sharing).
  • Carga del servidor: AJAX puede aliviar la renderización del HTML dejándola en el cliente, pero muchas llamadas simultáneas pueden sobrecargar el servidor.
  • Compatibilidad: puede no funcionar en móviles viejos, PDA o algunos lectores de pantalla (accesibilidad).
