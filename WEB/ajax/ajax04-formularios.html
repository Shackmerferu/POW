AJAX con formularios y validación

Fuente: ajax_II.pdf

¿Qué pasa con los formularios?

Tenemos que tomar cada campo del formulario (o las variables a evaluar) y concatenarlos de la forma "variable=valor" para poder enviarlos, sumando cada par con &.

Enviar los datos con el método POST

function cargarContenido() {
  var t1, t2, contenedor;
  contenedor = document.getElementById('contenedor');
  t1 = document.getElementById('texto1').value;
  t2 = document.getElementById('texto2').value;

  var ajax = new XMLHttpRequest();
  ajax.open("POST", "ejemploajax2.php", true);
  ajax.onreadystatechange = function() {
    if (ajax.readyState == 4) {
      contenedor.innerHTML = ajax.responseText;
    }
  };
  // Declara el tipo de contenido antes de enviar
  ajax.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
  // Envía los datos concatenados variable=valor
  ajax.send("t1=" + t1 + "&t2=" + t2);
}

Enviar variables con el método GET

// Los datos van en la URL: ?VARIABLE=VALOR
ajax.open("GET", "ejemploajax2.php?VARIABLE=VALOR", true);
// Se agregan más variables con &variable=valor
ajax.open("GET", "ejemploajax2.php?t1=hola&t2=mundo", true);
ajax.send();

Validación en vivo: chequear un nick sin enviar el formulario

Se quiere comprobar la disponibilidad de un campo en una base de datos (ej. el nickname de un usuario) sin enviar el formulario. Se dispara con el evento onkeyup: cada vez que el usuario suelta una tecla se consulta al servidor.

function comprobar_nick(str) {
  if (str.length == 0) {
    document.getElementById("mensaje").innerHTML = "";
    return;
  } else {
    var xmlhttp = new XMLHttpRequest();
    xmlhttp.onreadystatechange = function() {
      if (this.readyState == 4 && this.status == 200) {
        document.getElementById("mensaje").innerHTML = this.responseText;
      }
    };
    // consulta al PHP que valida en la base de datos
    xmlhttp.open("GET", "ajax_comprobar_nick.php?nickname=" + str, true);
    xmlhttp.send();
  }
}
<p>Complete Datos:</p>
<form>
  Primer Nombre:
  <input type="text" onkeyup="comprobar_nick(this.value)">
  <span id="mensaje"></span>
</form>

Frameworks de AJAX

Existen muchos frameworks JavaScript que ya contemplan la creación y el uso de AJAX:

  • XAJAX: librería/framework de AJAX para PHP.
  • Prototype.js, jQuery, Angular.js: librerías de cliente con sus propios métodos de AJAX.

Usar un framework no condiciona a implementar tú mismo los mecanismos de AJAX o a migrar de framework.
