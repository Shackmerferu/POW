Unidad 3 · Bootstrap

Bootstrap es un framework CSS (con componentes JavaScript opcionales) que trae estilos y componentes ya resueltos. Se usa agregando clases a tu HTML, en vez de escribir todo el CSS a mano; conviven perfectamente con tu propia hoja de estilos.

Nota: las vistas previas de esta unidad cargan Bootstrap desde internet (CDN). Sin conexión se verá el HTML sin los estilos del framework.

1. Qué es e incluir Bootstrap

Bootstrap se puede incluir de tres maneras: descargando los archivos, por CDN (lo más simple) o con un gestor de paquetes (npm). El CSS va en el <head> antes de tu propia hoja, para que tus reglas puedan sobrescribir las del framework.

Las etiquetas <script> van al final del <body>; hacen falta solo para los componentes interactivos (modal, dropdown, etc.).

Ejemplo 
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <!-- 1. Bootstrap (CDN) -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
  <!-- 2. Tus propios estilos DESPUÉS, para poder sobrescribir -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <button class="btn btn-primary">Ya estoy usando Bootstrap</button>

  <!-- 3. JS del framework al final del body -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
</body>

2. Sistema de grilla

La grilla de Bootstrap se basa en 12 columnas y tres elementos: un .container (o .container-fluid), una .row y una o más .col. El ancho de cada columna se expresa con un número del 1 al 12 y se puede definir distinto por tamaño de pantalla.

Las filas se envuelven en row y, si las columnas suman más de 12, bajan a la línea siguiente.

ClaseSignificado
colReparte el espacio en partes iguales.
col-6Ocupa 6 de 12 columnas (la mitad).
col-md-44 columnas a partir del breakpoint md.
col-lg-33 columnas a partir de lg.
g-3 / gy-2Separación (gap) entre columnas y filas.
offset-md-2Deja 2 columnas vacías a la izquierda.
Ejemplo 
<div class="container text-center">
  <div class="row g-2">
    <div class="col-6"><div class="p-2 bg-primary text-white">col-6</div></div>
    <div class="col-6"><div class="p-2 bg-primary text-white">col-6</div></div>
  </div>
  <div class="row g-2 mt-1">
    <div class="col-12 col-md-4"><div class="p-2 bg-success text-white">col-12 / md-4</div></div>
    <div class="col-12 col-md-4"><div class="p-2 bg-success text-white">col-12 / md-4</div></div>
    <div class="col-12 col-md-4"><div class="p-2 bg-success text-white">col-12 / md-4</div></div>
  </div>
</div>

3. Contenedores y breakpoints

El contenedor centra el contenido y le pone un ancho máximo según el tamaño de la pantalla. Bootstrap define breakpoints con un nombre: sm, md, lg, xl y xxl. Las clases de grilla llevan el breakpoint en el medio (col-md-…) y significan “desde este tamaño en adelante”.

BreakpointPrefijoDesde
Extra small(sin prefijo)< 576px
Smallsm≥ 576px
Mediummd≥ 768px
Largelg≥ 992px
Extra largexl≥ 1200px
Extra extra largexxl≥ 1400px
Ejemplo 
<div class="container">…contenedor centrado con ancho máximo…</div>
<div class="container-fluid">…ocupa todo el ancho…</div>

<!-- Apilado en celular, en 4 columnas desde md, 6 desde lg -->
<div class="row">
  <div class="col-12 col-md-3 col-lg-2">A</div>
</div>

4. Tipografía y colores

Bootstrap ya da estilo a los títulos y párrafos. Para el texto ofrece display-* (títulos grandes), text-* (color), fw-* (grosor) y fs-* (tamaño). Los colores de fondo se aplican con bg-* y el color del texto con text-*, en variantes solid (600) y subtle (100).

ClaseEfecto
display-1 … display-6Títulos de gran tamaño.
leadPárrafo destacado.
text-primary, text-dangerColor del texto.
text-center, text-endAlineación.
fw-bold, fst-italicNegrita, cursiva.
bg-primary, bg-warningColor de fondo.
bg-primary-subtleFondo suave de ese color.
Ejemplo 
<p class="display-4">Título display</p>
<p class="lead">Párrafo lead, más grande y gris.</p>
<p class="text-primary fw-bold">Texto azul en negrita</p>
<p class="text-danger text-decoration-underline">Texto rojo subrayado</p>
<p class="bg-info-subtle p-2">Fondo suave</p>
<p class="bg-dark text-white p-2">Fondo oscuro, texto blanco</p>

5. Utilidades de espaciado y layout

Las utilidades son clases de un solo propósito que se combinan libremente. Las de espaciado siguen el patrón {propiedad}{lado}-{tamaño}: m es margin, p es padding; el lado puede ser t (arriba), b (abajo), s/e (izq./der.) o x/y (ambos); el tamaño va de 0 a 5.

También hay utilidades de display, flexbox, bordes, sombras y tamaño.

ClaseEfecto
m-3 / p-3Margen / relleno en todos los lados.
mt-2 / px-4Margen arriba / relleno a los costados.
mx-autoCentra horizontalmente.
d-flex, d-none, d-md-blockDisplay y su variante por breakpoint.
justify-content-betweenReparte con flexbox.
border, rounded, shadowBorde, esquinas redondeadas, sombra.
w-50, h-100Ancho/alto.
Ejemplo 
<div class="d-flex justify-content-between align-items-center bg-light border rounded p-3">
  <span>Izquierda</span>
  <span>Derecha</span>
</div>

<div class="mx-auto mt-3 p-3 bg-warning rounded shadow" style="width:180px;text-align:center">
  Centrado con mx-auto
</div>

<div class="d-none d-md-block mt-2 text-success">Solo visible desde md</div>

6. Botones, alertas y badges

Los botones se crean con la clase .btn más una variante de color (btn-primary, btn-success…) o btn-outline-* (solo contorno). Las alertas (.alert) muestran mensajes y los badges (.badge) etiquetas pequeñas, muy útiles dentro de un botón o título.

Ejemplo 
<button class="btn btn-primary">Primario</button>
<button class="btn btn-success">Éxito</button>
<button class="btn btn-danger btn-sm">Peligro pequeño</button>
<button class="btn btn-outline-secondary">Contorno</button>
<button class="btn btn-primary">Mensajes <span class="badge bg-light text-dark">4</span></button>

<div class="alert alert-success mt-3">Operación realizada con éxito.</div>
<div class="alert alert-warning mt-2">Atención: revisá los datos.</div>

7. Tablas, tarjetas y listas

Las tablas se estilizan con .table y variantes (table-striped, table-hover, table-bordered). Las tarjetas (.card) son contenedores flexibles con cabecera, cuerpo y pie. Las listas (.list-group) y las barras de progreso (.progress) completan los componentes básicos.

Ejemplo 
<table class="table table-striped table-hover">
  <thead><tr><th>#</th><th>Nombre</th></tr></thead>
  <tbody><tr><td>1</td><td>Ana</td></tr><tr><td>2</td><td>Luis</td></tr></tbody>
</table>

<div class="card" style="width:220px">
  <div class="card-header">Encabezado</div>
  <div class="card-body">
    <h5 class="card-title">Título</h5>
    <p class="card-text">Texto de la tarjeta.</p>
    <a href="#" class="btn btn-primary btn-sm">Ver más</a>
  </div>
</div>

<ul class="list-group mt-3">
  <li class="list-group-item">Primer ítem</li>
  <li class="list-group-item active">Ítem activo</li>
</ul>

<div class="progress mt-3" style="height:12px">
  <div class="progress-bar" style="width:65%">65%</div>
</div>

8. Formularios

Bootstrap estiliza los controles con .form-control (inputs y textarea), .form-select (listas), .form-check (radio y checkbox) y .input-group (agregar botones o texto al campo). Incluye estilos de validación (is-valid / is-invalid) y etiquetas flotantes (form-floating).

Ejemplo 
<form>
  <div class="mb-3">
    <label for="mail" class="form-label">Correo</label>
    <input type="email" class="form-control" id="mail" placeholder="tu@correo.com">
    <div class="form-text">Nunca compartiremos tu correo.</div>
  </div>

  <div class="mb-3">
    <label class="form-label">Provincia</label>
    <select class="form-select"><option>La Pampa</option><option>Córdoba</option></select>
  </div>

  <div class="form-check mb-3">
    <input class="form-check-input" type="checkbox" id="ok">
    <label class="form-check-label" for="ok">Acepto los términos</label>
  </div>

  <div class="input-group mb-3">
    <span class="input-group-text">@</span>
    <input type="text" class="form-control" placeholder="usuario">
  </div>

  <div class="mb-3">
    <input type="text" class="form-control is-invalid" value="dato mal">
    <div class="invalid-feedback">Este campo tiene un error.</div>
  </div>

  <div class="form-floating">
    <input type="text" class="form-control" id="fl" placeholder="Nombre">
    <label for="fl">Nombre</label>
  </div>

  <button class="btn btn-primary mt-3">Enviar</button>
</form>

9. Navegación

La navbar es la barra de navegación responsiva: se puede colapsar en un botón hamburguesa en pantallas chicas con collapse. También hay tabs y pills (pestañas y botones de pestaña), dropdowns (menús desplegables), breadcrumbs (migas de pan) y paginación.

Ejemplo 
<nav class="navbar navbar-expand-md navbar-dark bg-dark">
  <a class="navbar-brand" href="#">Mi Sitio</a>
  <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#menu">
    <span class="navbar-toggler-icon"></span>
  </button>
  <div class="collapse navbar-collapse" id="menu">
    <ul class="navbar-nav">
      <li class="nav-item"><a class="nav-link active" href="#">Inicio</a></li>
      <li class="nav-item dropdown">
        <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown">Unidades</a>
        <ul class="dropdown-menu"><li><a class="dropdown-item" href="#">HTML</a></li></ul>
      </li>
    </ul>
  </div>
</nav>

<nav class="mt-3">
  <div class="nav nav-tabs">
    <button class="nav-link active" data-bs-toggle="tab" data-bs-target="#a">Pestaña A</button>
    <button class="nav-link" data-bs-toggle="tab" data-bs-target="#b">Pestaña B</button>
  </div>
</nav>

<ul class="pagination mt-3">
  <li class="page-item"><a class="page-link" href="#">«</a></li>
  <li class="page-item active"><a class="page-link" href="#">1</a></li>
  <li class="page-item"><a class="page-link" href="#">2</a></li>
</ul>

10. Componentes con JavaScript

Estos componentes necesitan el JS de Bootstrap y se activan con atributos data-bs-*, sin escribir JavaScript propio: collapse (plegar/desplegar), accordion, modal (ventana emergente), carousel (carrusel), tooltip y popover.

También se pueden controlar por código: new bootstrap.Modal(el).show().

Ejemplo 
<!-- Modal -->
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#m1">Abrir modal</button>
<div class="modal fade" id="m1">
  <div class="modal-dialog"><div class="modal-content">
    <div class="modal-header"><h5 class="modal-title">Título</h5>
      <button class="btn-close" data-bs-dismiss="modal"></button></div>
    <div class="modal-body">Cuerpo del modal.</div>
    <div class="modal-footer">
      <button class="btn btn-secondary" data-bs-dismiss="modal">Cerrar</button>
    </div>
  </div></div>
</div>

<!-- Acordeón -->
<div class="accordion" id="ac">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button" data-bs-toggle="collapse" data-bs-target="#i1">Sección 1</button>
    </h2>
    <div id="i1" class="accordion-collapse collapse show">
      <div class="accordion-body">Contenido de la sección.</div>
    </div>
  </div>
</div>

<button class="btn btn-outline-info" data-bs-toggle="collapse" data-bs-target="#oculto">Mostrar / ocultar</button>
<div id="oculto" class="collapse mt-2">Texto plegable.</div>
