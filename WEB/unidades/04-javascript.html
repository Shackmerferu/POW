Unidad 4 · JavaScript

JavaScript es un lenguaje interpretado, basado en objetos, embebido en el documento HTML. Es el único lenguaje que corre en el navegador: permite responder a eventos del usuario sin conectarse a la red, validar formularios y modificar el HTML dinámicamente. Es la base de AJAX.

1. Qué es y cómo se incluye

JavaScript fue creado por Brendan Eich en Netscape (se llamó Mocha, después LiveScript y finalmente JavaScript). Se estandariza como ECMAScript. Su sintaxis es parecida a Java o C++, pero no es lo mismo que Java: no implementa clases ni herencia clásica (la herencia se hace por prototipos).

Se ejecuta del lado del cliente (en el navegador) y también del lado del servidor (Node.js). Se incluye con la etiqueta <script> en el <head> o en el <body>, o en un archivo externo.

Ejemplo 
<head>
  <script>
    // Código embebido
    console.log("JavaScript en el head");
  </script>
  <!-- O un archivo externo -->
  <script src="app.js" defer></script>
</head>
<body>
  <p id="msg"></p>
  <script>
    document.getElementById("msg").textContent = "JavaScript ejecutándose en el body";
  </script>
</body>

2. Variables y tipos de datos

Una variable es un nombre que apunta a un valor. Se declara con var (ámbito de función, se usa poco hoy), let (ámbito de bloque y reasignable) o const (ámbito de bloque, no se reasigna).

JavaScript es de tipado débil: la misma variable puede cambiar de tipo, y el tipo se controla con typeof.

TipoEjemplo
numberlet n = 42; (enteros y decimales)
stringlet s = "hola";
booleanlet ok = true;
undefinedDeclarada sin valor
nullAusencia de valor intencional
objectArreglos, objetos, Date…
functionUna función es un valor
Ejemplo 
let nombre = "Ana";        // string
const edad = 22;           // number (constante)
var activo = true;         // boolean
let nada;                  // undefined
let vacio = null;          // null

console.log(typeof nombre);  // "string"
console.log(typeof edad);    // "number"
console.log(typeof activo);  // "boolean"

// tipado débil: cambia de tipo
let x = 10;
x = "ahora soy texto";

3. Operadores

Los operadores se agrupan según lo que hacen. Es clave distinguir == (compara solo el valor, hace conversión de tipo) de === (compara valor y tipo), y recordar que + sirve tanto para sumar como para concatenar texto.

GrupoOperadores
Aritméticos+ - * / % ++ -- **
Asignación= += -= *= /= %=
Comparación== != < > <= >=
Identidad=== / !== (comparan tipo y valor)
Lógicos&& (y), || (o), ! (no)
Ternariocondición ? valorSi : valorNo
Tipotypeof, instanceof
Ejemplo 
let a = 7, b = 2;
console.log(a + b);   // 9
console.log(a % b);   // 1  (resto)
console.log(a ** b);  // 49 (potencia)

console.log("7" == 7);   // true  (compara solo el valor)
console.log("7" === 7);  // false (distinto tipo)

let edad = 20;
let acceso = (edad >= 18) ? "mayor" : "menor";   // ternario

4. Control de flujo

Las estructuras condicionales permiten ejecutar código solo si se cumple una condición. if / else if / else es lo más general; switch es cómodo cuando se compara la misma variable contra muchos valores; y el operador ternario es un if de una sola línea.

Ejemplo 
let nota = 8;

if (nota >= 7) {
  console.log("Aprobado");
} else if (nota >= 4) {
  console.log("Recuperatorio");
} else {
  console.log("Libre");
}

let dia = 3;
switch (dia) {
  case 1: console.log("Lunes"); break;
  case 2: console.log("Martes"); break;
  default: console.log("Otro día");
}

let estado = (nota >= 7) ? "OK" : "NO";

5. Bucles

Los bucles repiten un bloque varias veces. for se usa cuando se conoce la cantidad de iteraciones; while mientras la condición sea verdadera; do…while garantiza al menos una ejecución; y for…of / for…in recorren colecciones y objetos.

BucleCuándo usarlo
for (let i=0; i<n; i++)Cantidad de repeticiones conocida.
while (cond)Mientras se cumpla una condición.
do {…} while (cond)Al menos una vuelta siempre.
for (const v of arr)Recorrer valores de un arreglo.
for (const k in obj)Recorrer claves de un objeto.
Ejemplo 
for (let i = 1; i <= 3; i++) {
  console.log("for:", i);
}

let j = 0;
while (j < 3) { console.log("while:", j); j++; }

let k = 0;
do { console.log("do-while:", k); k++; } while (k < 2);

const frutas = ["manzana", "pera"];
for (const f of frutas) console.log("of:", f);

const persona = { nombre: "Ana", edad: 22 };
for (const clave in persona) console.log("in:", clave, persona[clave]);

6. Funciones

Una función agrupa código reutilizable. Puede recibir parámetros y devolver un valor con return. Si no devuelve nada, retorna undefined. Hay funciones declaradas, expresadas (asignadas a una variable), flecha (arrow) y funciones anónimas (callbacks).

Ejemplo 
// Declarada
function saludar(nombre) {
  return "Hola, " + nombre;
}

// Expresada
const sumar = function (a, b) { return a + b; };

// Flecha (arrow function)
const multiplicar = (a, b) => a * b;

// Parámetros con valor por defecto
function potencia(base, exp = 2) { return base ** exp; }

console.log(saludar("Ana"));    // Hola, Ana
console.log(sumar(2, 3));       // 5
console.log(multiplicar(4, 5)); // 20
console.log(potencia(3));       // 9

7. Arreglos

Un arreglo (array) es una lista ordenada de valores a la que se accede por índice, empezando en 0. Su cantidad de elementos está en la propiedad length. Trae muchísimos métodos útiles para agregar, quitar, buscar y transformar.

MétodoQué hace
push() / pop()Agrega / quita al final.
unshift() / shift()Agrega / quita al principio.
lengthCantidad de elementos.
join(sep)Une los elementos en un string.
sort(), reverse()Ordena / invierte.
indexOf(x)Posición de un valor (-1 si no está).
slice(a,b), splice()Copia un tramo / modifica el original.
map, filter, forEachRecorrer y transformar.
Ejemplo 
const frutas = ["pera", "manzana", "uva"];

console.log(frutas[0]);        // "pera"
console.log(frutas.length);    // 3

frutas.push("kiwi");           // agrega al final
frutas.unshift("banana");      // agrega al principio
console.log(frutas.join(", ")); // banana, pera, manzana, uva, kiwi

console.log(frutas.indexOf("uva"));  // 3

const mayus = frutas.map(f => f.toUpperCase());
const largos = frutas.filter(f => f.length > 4);

frutas.sort();
console.log(frutas.reverse());

8. Objetos

Un objeto agrupa datos en pares clave: valor. Se accede con objeto.clave (notación de punto) o objeto["clave"] (corchetes). Si un valor es una función, se llama método y dentro de él this apunta al propio objeto.

JavaScript incluye objetos preconstruidos muy usados: Math (matemática), Date (fechas), JSON, Array, String.

Ejemplo 
const persona = {
  nombre: "Ana",
  edad: 22,
  saludar: function () {           // método
    return "Hola, soy " + this.nombre;
  }
};

console.log(persona.nombre);        // "Ana"
console.log(persona["edad"]);       // 22
console.log(persona.saludar());     // "Hola, soy Ana"
persona.ciudad = "General Pico";    // se agrega una propiedad

// Objetos preconstruidos
console.log(Math.max(3, 9, 5));             // 9
console.log(Math.round(4.6));               // 5
const hoy = new Date();
console.log(hoy.getFullYear());

9. Strings

Las cadenas (strings) se escriben entre comillas simples, dobles o backticks. Todas tienen la propiedad length y un gran conjunto de métodos. Los template literals (backticks) permiten insertar variables con ${…} y escribir varias líneas.

MétodoQué hace
lengthCantidad de caracteres.
toUpperCase() / toLowerCase()Cambia mayúsculas/minúsculas.
indexOf(x)Posición de un texto (-1 si no está).
slice(a,b)Extrae un tramo.
replace(a,b)Reemplaza la primera aparición.
split(sep)Parte el string y devuelve un arreglo.
trim()Quita espacios al inicio y al final.
charAt(i)El carácter en esa posición.
Ejemplo 
const nombre = "Ana";
const txt = "  Hola Mundo  ";

console.log(txt.length);              // 14
console.log(txt.trim());              // "Hola Mundo"
console.log(txt.toUpperCase());
console.log(txt.indexOf("Mundo"));    // 7
console.log(txt.slice(2, 6));         // "Hola"
console.log(txt.replace("Mundo", "JS"));
console.log("a,b,c".split(","));      // ["a","b","c"]

// Template literal
console.log(`Hola ${nombre}, tenés ${nombre.length} letras.`);

10. Entrada y salida

JavaScript tiene varias formas de comunicarse con el usuario: alert() (ventana de aviso), prompt() (pide un dato), confirm() (sí/no), y console.log() para depurar. Para escribir en la página se usa el DOM (innerHTML, textContent).

Ejemplo 
<p id="resultado"></p>
<button onclick="saludar()">Ejecutar</button>

<script>
  function saludar() {
    const nom = prompt("¿Cómo te llamás?");
    if (confirm("¿Seguro que es " + nom + "?")) {
      document.getElementById("resultado").textContent = "Hola, " + nom;
      console.log("Saludo mostrado");
    }
  }
</script>

11. Eventos

Un evento es una acción del usuario o del navegador (clic, tecla, carga de la página…). JavaScript puede capturarlo de dos formas: con un atributo en la etiqueta (onclick="...") o, mejor, asignando un gestor de eventos con addEventListener. Dentro del manejador, this es el elemento que disparó el evento.

EventoCuándo ocurre
onclickAl hacer clic.
onmouseover / onmouseoutEntrar / salir con el mouse.
onchangeAl cambiar el valor de un campo.
onsubmitAl enviar un formulario.
onkeyup / onkeypressAl soltar / presionar una tecla.
onloadAl terminar de cargar la página.
Ejemplo 
<button id="b">Clickeame</button>
<p id="salida">Sin cambios</p>

<script>
  const b = document.getElementById("b");
  const s = document.getElementById("salida");

  // Gestor de eventos (recomendado)
  b.addEventListener("click", function () {
    s.textContent = "¡Clic detectado!";
  });
</script>

12. DOM

El DOM (Document Object Model) es la representación en forma de árbol de objetos que el navegador hace del HTML. JavaScript lo usa para leer y modificar la página en caliente: cambiar textos, estilos, atributos, agregar o quitar elementos.

Seleccionar elementos es el primer paso: getElementById, querySelector, getElementsByClassName. Modificar: innerHTML, textContent, style, setAttribute, classList, createElement, appendChild, remove.

MétodoQué hace
getElementById(id)Un elemento por su id.
querySelector(sel)El primer elemento que coincide con el selector CSS.
querySelectorAll(sel)Todos los que coinciden.
element.innerHTMLHTML interno (interpreta etiquetas).
element.textContentTexto interno (no interpreta HTML).
element.style.propCambia un estilo en línea.
classList.add/remove/toggleAdministra clases.
document.createElement()Crea un nodo nuevo.
Ejemplo 
<div id="caja">Contenido original</div>
<button id="go">Transformar</button>

<script>
  const caja = document.getElementById("caja");

  document.getElementById("go").addEventListener("click", function () {
    caja.textContent = "Texto cambiado por el DOM";   // cambia el texto
    caja.style.color = "crimson";                     // cambia el estilo
    caja.classList.add("resaltado");                  // agrega una clase

    const nuevo = document.createElement("p");        // crea un nodo
    nuevo.textContent = "Párrafo creado con createElement";
    caja.appendChild(nuevo);                          // lo inserta
  });
</script>

13. Módulos ES6

A medida que un proyecto crece, conviene dividir el código en archivos. Los módulos ES6 permiten exportar cosas desde un archivo e importarlas en otro. El archivo que importa debe cargarse con <script type="module">, y cada módulo tiene su propio ámbito (las variables no se filtran al global).

  • export: expone una variable, función o clase.
  • export default: expone un único valor principal.
  • import: trae lo exportado (con ./ para archivos locales).

Importante: los módulos solo funcionan servidos por HTTP (no abriendo el archivo con file://), por eso conviene servirlos con Apache/XAMPP o un servidor de desarrollo.

Ejemplo 
// ---- api.js ----
export async function getDatos(url) {
  const res = await fetch(url);
  return res.json();
}

export const CATEGORIA_MASCULINO = 1;
export const CATEGORIA_FEMENINO  = 3;

// ---- main.js ----
import { getDatos, CATEGORIA_MASCULINO } from "./api.js";

const data = await getDatos(`api/jugadores.php?id_categoria=${CATEGORIA_MASCULINO}`);
console.log(data.productos);

// ---- index.html ----
<!-- type="module" habilita import/export y el ámbito de módulo -->
<script type="module" src="main.js"></script>
