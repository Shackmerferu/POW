Unidad 6 · jQuery

jQuery es una biblioteca (librería) multiplataforma de JavaScript orientada a simplificar el trabajo con el DOM, los eventos, los efectos y AJAX. Su lema es “escribir menos, hacer más”: lo que en JavaScript puro son varias líneas, en jQuery es una. Se usa la biblioteca completa o CDN.

Nota: las vistas previas de esta unidad cargan jQuery por CDN, así que ejecutan código real. Sin conexión, verás el HTML sin la interacción.

1. Librerías en JavaScript y Prototype

La aparición de JavaScript dio lugar a una gran variedad de frameworks o librerías que facilitan manipular el DOM desde el cliente o trabajar del lado del servidor.

Prototype.js fue la referencia inicial de AJAX e inspiró a jQuery. Su característica más conocida es la función $() (llamada función dólar), que es un atajo a document.getElementById().

LibreríaDónde corre
Prototype.js, jQuery, AngularJS, lightbox, W3.jsDel lado del cliente.
Node.jsDel lado del servidor.
Atajo de PrototypeEquivalente en JavaScript
$("primero")document.getElementById("primero")
$F("municipio")document.getElementById("municipio").value
$$("div p")Elementos según selectores CSS.
$A() / $H() / $R()Convierte a array / crea array asociativo / crea un rango.
Ejemplo 
// Con JavaScript puro
const elemento = document.getElementById("primero");
const valor = document.getElementById("municipio").value;

// Con Prototype
const elemento2 = $("primero");
const valor2 = $F("municipio");
const parrafos = $$("div p");     // selectores CSS
const lista = $A(document.getElementsByTagName("li"));

2. Qué es jQuery y cómo incluirlo

jQuery simplifica las tareas complicadas de JavaScript: manipulación HTML/DOM, CSS, eventos, efectos y animaciones, AJAX y utilidades. Es la biblioteca más popular y la más extensible; la usan Google, Microsoft, IBM, Netflix y gestores de contenidos como WordPress o Joomla, además de frameworks como Bootstrap.

Se incluye de tres maneras: descargando el archivo, por CDN, o con gestores de paquetes (npm, yarn).

Ejemplo 
<!-- 1. Archivo descargado -->
<script src="jquery-3.5.1.min.js"></script>

<!-- 2. CDN (Google) — la más cómoda -->
<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.5.1/jquery.min.js"></script>

<!-- 3. Gestor de paquetes -->
<!-- npm install jquery -->

3. Sintaxis y función ready()

Toda la biblioteca gira alrededor de $(selector).accion(): el $ accede a jQuery, el (selector) busca los elementos HTML y .accion() hace algo con ellos.

Los métodos deben colocarse dentro de $(document).ready() para que los eventos se enganchen después de que la página terminó de cargar. Existe una forma abreviada: $(function(){…}).

CódigoAcción
$(this).hide()Oculta el elemento actual.
$("p").hide()Oculta todos los <p>.
$(".test").hide()Oculta los elementos con class="test".
$("#test").hide()Oculta el elemento con id="test".
Ejemplo 
<script src="https://ajax.googleapis.com/ajax/libs/jquery/3.5.1/jquery.min.js"></script>
<script>
  $(document).ready(function () {
    $("#btn").click(function () {
      $("p").hide();
    });
  });

  // Forma abreviada
  $(function () {
    // aquí van los métodos
  });
</script>

<button id="btn">Ocultar párrafos</button>
<p>Párrafo 1</p><p>Párrafo 2</p>
Resultado · clic en el botón

4. Selectores

Los selectores son la parte más importante de jQuery: son los mismos de CSS, más algunos propios de la biblioteca (posición, filtros). Se pueden combinar y encadenar.

SelectorSelecciona
$("*")Todos los elementos.
$(this)El elemento actual.
$("p.intro")Los <p> con class="intro".
$("p:first")El primer <p>.
$("tr:odd")Las filas impares de una tabla.
$("#id")El elemento con ese id.
$(".clase")Los elementos con esa clase.
$(this).children()Los hijos del elemento actual.
Ejemplo 
$(document).ready(function () {
  $("button").click(function () {
    $("p").hide();          // oculta todos los párrafos
  });
  $("tr:odd").css("background-color", "#eef2ff");   // filas impares
});

<table>
  <tr><td>Fila 1</td></tr>
  <tr><td>Fila 2</td></tr>
  <tr><td>Fila 3</td></tr>
</table>

5. Eventos

Todas las acciones del usuario pueden ser capturadas por eventos: del mouse, del teclado, de los formularios y de la ventana del navegador. Primero se “engancha” el evento al selector y luego se le pasa una función con lo que debe hacer.

EventoCuándo
click()Al hacer clic.
dblclick()Doble clic.
mouseenter() / mouseleave()Entrar / salir con el mouse.
keyup() / keypress()Teclado.
change()Cambia el valor de un campo.
submit()Se envía un formulario.
focus() / blur()Toma / pierde el foco.
on()Enlaza cualquier evento (forma general).
Ejemplo 
$(function () {
  $("p").click(function () {
    $(this).hide();          // this = el párrafo clickeado
  });

  $("#msg").mouseenter(function () {
    $(this).css("background-color", "#fffbeb");
  });
});
Resultado · clic en el párrafo / pasar el mouse

6. Efectos y animaciones

jQuery trae efectos listos para usar. Todos aceptan una velocidad ("slow", "fast" o milisegundos) y una función de callback que se ejecuta al terminar. Con el encadenado (chaining) se pueden aplicar varios efectos seguidos sobre el mismo elemento.

GrupoMétodos
Mostrar/ocultarhide(), show(), toggle()
Desvanecer (fade)fadeIn(), fadeOut(), fadeToggle(), fadeTo()
Deslizar (slide)slideDown(), slideUp(), slideToggle()
Animaciónanimate({params}, speed, callback)
Detenerstop()
Ejemplo 
$("#ocultar").click(function () { $("p").hide("slow"); });
$("#mostrar").click(function () { $("p").show("fast"); });

$("#fade").click(function () {
  $("#caja").fadeToggle(600);
});

$("#slide").click(function () {
  $("#caja2").slideToggle("slow");
});

$("#animar").click(function () {
  $("#caja").animate({ width: "260px", opacity: 0.4 }, 800)
             .animate({ height: "120px" }, 600);
});

7. Manipulación de HTML y CSS

jQuery permite obtener (get) y establecer (set) contenido y atributos con los mismos métodos: text(), html(), val(), attr(). Además, puede agregar (append, prepend, after, before), quitar (remove, empty) y administrar estilos (addClass, removeClass, toggleClass, css).

Sin argumentos, el método devuelve el valor; con argumento, lo establece.

MétodoQué hace
text()Contenido de texto.
html()Contenido incluyendo etiquetas HTML.
val()Valor de un campo de formulario.
attr("href")Lee / escribe un atributo.
append() / prepend()Inserta al final / al comienzo.
after() / before()Inserta después / antes del elemento.
remove() / empty()Elimina el elemento / sus hijos.
addClass() / css()Clases CSS / propiedades de estilo.
Ejemplo 
$(function () {
  $("#btnText").click(function () { $("#t1").text("Nuevo texto"); });
  $("#btnHtml").click(function () { $("#t2").html("<b>Texto en negrita</b>"); });
  $("#btnAttr").click(function () { alert($("#link").attr("href")); });
  $("#btnAdd").click(function () { $("#lista").append("<li>Nuevo ítem</li>"); });
  $("#btnCss").click(function () { $("#t1").css({ "background-color": "yellow", "font-size": "150%" }); });
});

8. AJAX con jQuery

jQuery reduce AJAX a un método. load() carga el resultado directamente en un contenedor; $.get() y $.post() hacen la petición y ejecutan un callback; y $.ajax() es la versión completa, con todos los parámetros configurables.

GET puede usar caché; POST nunca la usa. Si la respuesta trae etiquetas HTML, el navegador las interpreta.

MétodoSintaxis
load()$(sel).load(URL, data, callback)
$.get()$.get(URL, callback)
$.post()$.post(URL, data, callback)
$.ajax()$.ajax({url, type, data, dataType, success, error, complete})
Ejemplo 
$("#btn").click(function () {
  $("#div1").load("hola.txt");          // carga directa en el div
});

$("button").click(function () {
  $.get("hola.txt", function (data, status) {
    alert("Data: " + data + "\nStatus: " + status);
  });
});

$.ajax({
  url: "comprobar_nick.php",
  type: "POST",
  data: { nickname: "ana" },
  dataType: "json",
  success: function (r) { $("#msg").html(r.mensaje); },
  error: function (xhr, status, err) { $("#msg").html("Error: " + status); },
  complete: function () { console.log("Petición finalizada"); }
});
Resultado · petición real con $.ajax()

9. noConflict()

jQuery usa $ como atajo, pero otros frameworks (Angular, Backbone, Prototype…) usan el mismo símbolo. Si dos lo usan a la vez, uno deja de funcionar. $.noConflict() libera el $ para que lo use otro script; desde ahí se escribe jQuery en lugar de $, o se crea un atajo propio.

Ejemplo 
// Liberar $ y usar jQuery con su nombre completo
$.noConflict();
jQuery(document).ready(function () {
  jQuery("button").click(function () {
    jQuery("p").text("jQuery sigue funcionando!");
  });
});

// O crear un atajo propio
const jq = $.noConflict();
jq(document).ready(function () {
  jq("p").text("Atajo propio jq");
});
