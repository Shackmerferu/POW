Unidad 9 · Subida de archivos

Subir archivos (imágenes, PDF, etc.) al servidor combina tres piezas: un formulario HTML con enctype="multipart/form-data", la superglobal $_FILES en PHP y move_uploaded_file() para guardar el archivo en disco. Además, con AJAX + FormData se puede subir sin recargar la página.

Nota: el código PHP no se ejecuta en el navegador. Cada ejemplo muestra el código y, debajo, el resultado que produciría el servidor con XAMPP.

1. El formulario con multipart/form-data

Para enviar archivos el <form> debe llevar enctype="multipart/form-data" y método POST. El campo de archivo es <input type="file"> (con name, y accept para limitar tipos).

Sin enctype="multipart/form-data" el navegador solo envía el nombre del archivo, no su contenido, y PHP nunca lo recibe en $_FILES.

Sintaxis 
<form action="subir.php" method="POST" enctype="multipart/form-data">
  <input type="text"   name="nombre"   placeholder="Nombre del club">
  <input type="file"   name="logo"     accept="image/*">
  <button type="submit">Guardar</button>
</form>

2. La superglobal $_FILES

Cuando el navegador envía un archivo, PHP lo deposita en una carpeta temporal y describe todo en la superglobal $_FILES, indexada por el name del input:

ClaveContiene
$_FILES['logo']['name']Nombre original del archivo (ej. tania.png).
$_FILES['logo']['type']Tipo MIME (ej. image/png).
$_FILES['logo']['tmp_name']Ruta temporal en el servidor (de donde se mueve).
$_FILES['logo']['error']Código de error (0 = sin error, 4 = no se subió archivo).
$_FILES['logo']['size']Tamaño en bytes.
Ejemplo · inspeccionar lo recibido 
<?php
  // Llega por POST con enctype multipart/form-data
  echo $_FILES['logo']['name'];      // tania.png
  echo $_FILES['logo']['type'];      // image/png
  echo $_FILES['logo']['tmp_name'];  // C:\xampp\tmp\phpA1B2.tmp
  echo $_FILES['logo']['size'];      // 20480
  echo $_FILES['logo']['error'];     // 0
?>

3. Validar antes de guardar

Nunca hay que guardar un archivo sin validarlo. Controles mínimos:

  • Que error === 0 (que se haya subido bien).
  • Que la extensión esté permitida (png, jpg, jpeg, gif, webp).
  • Que el tamaño no supere un máximo (ej. 2 MB).
  • Opcional: comprobar el tipo real con getimagesize().

Es habitual generar un nombre único (para no pisar archivos con el mismo nombre) usando uniqid() o la fecha, conservando la extensión original.

Ejemplo 
<?php
  $archivo   = $_FILES['logo'];
  $permitidos = ['png', 'jpg', 'jpeg', 'gif', 'webp'];
  $ext = strtolower(pathinfo($archivo['name'], PATHINFO_EXTENSION));

  $errores = [];
  if ($archivo['error'] !== 0)              $errores[] = "Error al subir el archivo.";
  if (!in_array($ext, $permitidos))         $errores[] = "Extensión no permitida.";
  if ($archivo['size'] > 2 * 1024 * 1024)   $errores[] = "El archivo supera 2 MB.";

  if (empty($errores)) {
      $nuevoNombre = uniqid("logo_") . "." . $ext;   // logo_67a1f3.png
      echo "OK, se guardará como $nuevoNombre";
  } else {
      echo implode(" | ", $errores);
  }
?>

4. move_uploaded_file() y carpetas

El archivo temporal se mueve a su destino final con move_uploaded_file($tmp, $destino). Devuelve true si pudo. La carpeta destino debe existir y tener permisos de escritura; por convención se guardan las imágenes en carpetas como img/logos/ o img/fotos_jugadores/.

Para armar rutas se usa __DIR__ (carpeta del script actual), lo que evita problemas de rutas relativas. Si la carpeta no existe, se puede crear con mkdir().

Sintaxis 
move_uploaded_file($_FILES['campo']['tmp_name'], $rutaDestino);
Ejemplo 
<?php
  $archivo = $_FILES['logo'];
  $ext     = strtolower(pathinfo($archivo['name'], PATHINFO_EXTENSION));
  $nuevo   = uniqid("logo_") . "." . $ext;

  $carpeta = __DIR__ . "/img/logos/";          // ruta física en el servidor
  if (!is_dir($carpeta)) mkdir($carpeta, 0777, true);

  $destino = $carpeta . $nuevo;

  if (move_uploaded_file($archivo['tmp_name'], $destino)) {
      echo "Imagen guardada en img/logos/$nuevo";
      // Para mostrarla en el navegador:  api/img/logos/$nuevo
  } else {
      echo "No se pudo guardar la imagen.";
  }
?>

5. Guardar el nombre del archivo en MySQL

En la base de datos no se guarda la imagen, sino su nombre/ruta (ej. logo_67a1f3.png). El flujo completo: recibir → validar → mover → INSERT con el nombre en la columna logo. Esta combinación une esta unidad con la anterior (MySQL).

Ejemplo · equipos_insertar.php 
<?php
  header('Access-Control-Allow-Origin: *');
  header('Content-Type: application/json');
  extract($_REQUEST);
  require("conexion.php");

  $conexion = mysqli_connect($server_db, $usuario_db, $password_db)
      or die("No se puede conectar con el servidor");
  mysqli_select_db($conexion, $base_db);

  // 1) Subir el logo
  $archivo = $_FILES['logo'];
  $ext     = strtolower(pathinfo($archivo['name'], PATHINFO_EXTENSION));
  $nuevo   = uniqid("logo_") . "." . $ext;
  $carpeta = __DIR__ . "/img/logos/";
  if (!is_dir($carpeta)) mkdir($carpeta, 0777, true);
  move_uploaded_file($archivo['tmp_name'], $carpeta . $nuevo);

  // 2) Guardar el equipo con el nombre del archivo
  $nombre = mysqli_real_escape_string($conexion, $nombre);
  $sql = "INSERT INTO equipos (nombre, logo, puntos)
          VALUES ('$nombre', '$nuevo', 0)";

  if (mysqli_query($conexion, $sql)) {
      echo json_encode(['status' => 200,
                        'mensaje' => "Club $nombre guardado con logo $nuevo"]);
  } else {
      echo json_encode(['status' => 500,
                        'mensaje' => mysqli_error($conexion)]);
  }
  mysqli_close($conexion);
?>

6. Subida con AJAX y FormData

Para subir sin recargar la página se usa FormData: un objeto que empaqueta los campos del formulario (incluido el archivo) y se envía con fetch por POST. No hay que fijar el Content-Type: el navegador lo calcula solo con el boundary correcto.

Se puede construir desde un formulario real (new FormData(form)) o a mano con append().

Sintaxis 
const fd = new FormData();
fd.append("nombre", valor);        // campos de texto
fd.append("logo", inputFile.files[0]);   // el archivo
fetch(url, { method: "POST", body: fd });
Ejemplo · fetch con FormData 
<script>
  const form = document.getElementById("formClub");

  form.addEventListener("submit", async (e) => {
    e.preventDefault();

    const fd = new FormData(form);   // toma todos los campos + el archivo

    const resp = await fetch("api/equipos_insertar.php", {
      method: "POST",
      body: fd                       // ¡sin headers de Content-Type!
    });

    const data = await resp.json();  // { status, mensaje }
    document.getElementById("msg").textContent = data.mensaje;
  });
</script>
Ejemplo · jQuery con FormData 
$("#formClub").on("submit", function (e) {
  e.preventDefault();
  const fd = new FormData(this);

  $.ajax({
    url: "api/equipos_insertar.php",
    type: "POST",
    data: fd,
    processData: false,   // no convertir a query string
    contentType: false,   // dejar que el navegador ponga el boundary
    success: function (data) {
      $("#msg").text(data.mensaje);
    }
  });
});

7. Patrón completo: formulario → Ajax → PHP → BD

Este es el patrón integrador que pide el parcial (página huérfana registrar_club.html):

  1. HTML: formulario con enctype, campo de texto y type="file".
  2. JS: interceptar el submit, armar FormData y enviar por AJAX.
  3. PHP: validar, mover la imagen a img/logos/ e INSERT en MySQL.
  4. Respuesta: JSON {status, mensaje} que el JS muestra en pantalla.
Ejemplo · las tres piezas juntas 
<!-- registrar_club.html -->
<form id="formClub" enctype="multipart/form-data">
  <input type="text" name="nombre" required placeholder="Nombre del club">
  <input type="file" name="logo" accept="image/*" required>
  <button type="submit">Registrar club</button>
</form>
<p id="msg"></p>

<script>
document.getElementById("formClub").addEventListener("submit", async (e) => {
  e.preventDefault();
  const fd = new FormData(e.target);
  const resp = await fetch("api/equipos_insertar.php", { method: "POST", body: fd });
  const data = await resp.json();
  document.getElementById("msg").textContent =
    data.status === 200 ? "✔ " + data.mensaje : "✘ " + data.mensaje;
});
</script>
