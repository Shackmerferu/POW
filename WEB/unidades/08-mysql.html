Unidad 8 · MySQL + PHP

MySQL (o MariaDB) es el gestor de bases de datos relacionales que trae XAMPP. PHP se conecta a él para leer y escribir datos: esa combinación es la que da vida a una web dinámica. Esta unidad cierra el circuito AJAX → PHP → MySQL.

Nota: el código SQL y PHP no se ejecuta en el navegador. En cada ejemplo se muestra el código y, debajo, el resultado que produciría el servidor. Para probarlo de verdad usá XAMPP (Apache + MySQL) y MySQL Workbench/phpMyAdmin.

1. Qué es MySQL y el flujo web

MySQL es un motor de base de datos: guarda la información en tablas (filas y columnas) y se consulta con el lenguaje SQL. Junto con Apache y PHP forma la pila LAMP (Linux) o, en Windows, XAMPP (Apache + MySQL/MariaDB + PHP).

El circuito completo de una web reactiva es:

Navegador (HTML/CSS/JS)  →  AJAX (fetch)  →  PHP (API)  →  MySQL (datos)  →  y la respuesta vuelve como JSON.

Hay tres formas de conectarse desde PHP: la extensión mysqli (procedural u orientada a objetos) y PDO. En esta materia usamos mysqli procedural, que es lo que aparece en las API del parcial.

ConceptoQué es
Base de datosContenedor de tablas relacionadas (ej. la_tania).
TablaConjunto de filas con columnas fijas (ej. jugadores).
Fila / registroUn elemento (un jugador, un partido).
Columna / campoUn atributo con su tipo (ej. nombre varchar(50)).
PK / Clave primariaCampo que identifica unívocamente la fila (id_jugador).
FK / Clave foráneaCampo que referencia la PK de otra tabla.

2. XAMPP: crear la base e importar un .sql

Antes de codificar PHP hay que preparar el motor. Con XAMPP se hace así:

  1. En el XAMPP Control Panel iniciar Apache y MySQL.
  2. Abrir http://localhost/phpmyadmin y crear la base de datos (ej. la_tania).
  3. Pestaña Importar → elegir el archivo .sql → Continuar. Eso crea las tablas y carga los datos de prueba.
  4. Copiar los archivos del proyecto dentro de C:\xampp\htdocs\ (ej. htdocs\la_tania) para acceder como http://localhost/la_tania/....

El .sql no es más que un archivo de texto con sentencias SQL separadas por ;.

Sintaxis SQL 
-- Crear la base
CREATE DATABASE la_tania CHARACTER SET utf8mb4;

-- Usarla
USE la_tania;

-- Crear una tabla
CREATE TABLE jugadores (
  id_jugador INT NOT NULL AUTO_INCREMENT,   -- PK autoincremental
  nombre     VARCHAR(50)  NOT NULL,
  apellido   VARCHAR(150) NOT NULL,
  apodo      VARCHAR(50)  NOT NULL,
  dni        VARCHAR(40)  NOT NULL,
  biografia  TEXT,
  imagen     TEXT,
  id_categoria INT NOT NULL,
  PRIMARY KEY (id_jugador)
);

-- Insertar datos
INSERT INTO jugadores (nombre, apellido, apodo, dni, imagen, id_categoria)
VALUES ('Albino', 'Blanco', 'Cañita Voladora', '1', 'prof.jpg', 1);

3. Conectarse con mysqli y conexion.php

La conexión se hace con mysqli_connect(servidor, usuario, password, base) y luego se ejecutan consultas con mysqli_query(). Es una buena práctica poner los datos de conexión en un archivo aparte (conexion.php) e incluirlo con require en cada endpoint.

Funciones principales del flujo procedural:

FunciónPara qué sirve
mysqli_connect(...)Abrir la conexión al servidor y a la base.
mysqli_query($c, $sql)Ejecutar una sentencia SQL.
mysqli_num_rows($res)Cuántas filas devolvió un SELECT.
mysqli_fetch_object($res)Fila como objeto (para JSON).
mysqli_fetch_assoc($res)Fila como array asociativo.
mysqli_insert_id($c)Último id autogenerado por un INSERT.
mysqli_affected_rows($c)Filas afectadas por INSERT/UPDATE/DELETE.
mysqli_error($c)Mensaje de error de la última consulta.
mysqli_close($c)Cerrar la conexión.
Ejemplo · conexion.php + uso 
<?php
  // ---- conexion.php : solo datos ----
  $server_db   = "localhost";
  $usuario_db  = "root";
  $password_db = "";          // en XAMPP por defecto va vacío
  $base_db     = "la_tania";
?>

<?php
  // ---- endpoint.php : conectarse y consultar ----
  require("conexion.php");

  $conexion = mysqli_connect($server_db, $usuario_db, $password_db)
      or die("No se puede conectar con el servidor");

  mysqli_select_db($conexion, $base_db)
      or die("No se puede seleccionar base de datos");

  $instruccion = "SELECT * FROM jugadores";
  $consulta = mysqli_query($conexion, $instruccion)
      or die("Fallo en la consulta: " . mysqli_error($conexion));

  $nfilas = mysqli_num_rows($consulta);
  echo "Filas: $nfilas";

  mysqli_close($conexion);
?>
Resultado

4. SELECT y recorrer resultados

SELECT trae datos. Se eligen las columnas (* = todas), la tabla (FROM), el orden (ORDER BY) y el límite (LIMIT). El resultado es un cursor que se recorre fila por fila con while + mysqli_fetch_object().

Sintaxis 
SELECT columnas | *  FROM tabla
[WHERE condición]
[ORDER BY columna ASC | DESC]
[LIMIT n];
Ejemplo 
<?php
  require("conexion.php");
  $conexion = mysqli_connect($server_db, $usuario_db, $password_db);
  mysqli_select_db($conexion, $base_db);

  $instruccion = "SELECT id_jugador, nombre, apellido FROM jugadores
                  WHERE id_categoria = 1
                  ORDER BY apellido DESC";

  $consulta = mysqli_query($conexion, $instruccion) or die("Fallo");
  $nfilas   = mysqli_num_rows($consulta);

  if ($nfilas > 0) {
      while ($row = mysqli_fetch_object($consulta)) {
          echo $row->id_jugador . " - " . $row->nombre . " " . $row->apellido . "<br>";
      }
  } else {
      echo "Sin resultados";
  }
  mysqli_close($conexion);
?>
Resultado

5. INSERT, UPDATE y DELETE

Estas tres sentencias modifican los datos:

  • INSERT agrega una fila nueva.
  • UPDATE modifica filas existentes (¡no olvidar el WHERE!).
  • DELETE elimina filas (¡también necesita WHERE!).

Para valores que vienen del usuario se usa mysqli_real_escape_string() para escapar comillas y evitar errores/inyección. Para INSERT conviene registrar mysqli_affected_rows() y mysqli_insert_id().

Sintaxis 
INSERT INTO tabla (col1, col2) VALUES (val1, val2);
UPDATE tabla SET col1 = val1 WHERE condición;
DELETE FROM tabla WHERE condición;
Ejemplo · guardar un palmarés (patrón de la API) 
<?php
  require("conexion.php");
  $conexion = mysqli_connect($server_db, $usuario_db, $password_db);
  mysqli_select_db($conexion, $base_db);

  extract($_REQUEST);           // crea $dni, $anio, $detalle desde GET/POST

  $dni     = mysqli_real_escape_string($conexion, $dni);
  $detalle = mysqli_real_escape_string($conexion, $detalle);
  $anio    = (int) $anio;       // forzar entero por seguridad

  $instruccion = "INSERT INTO palmares (dni, anio, detalle)
                  VALUES ($dni, $anio, '$detalle')";

  if (mysqli_query($conexion, $instruccion)) {
      $data = ['status' => 200,
               'mensaje' => 'Palmarés guardado',
               'id' => mysqli_insert_id($conexion)];
  } else {
      $data = ['status' => 500,
               'mensaje' => mysqli_error($conexion)];
  }
  echo json_encode($data);
  mysqli_close($conexion);
?>

6. Consultas con filtros dinámicos (WHERE)

Un patrón muy usado en las API es armar el WHERE según los parámetros recibidos. Se empieza con un filtro neutro (where 1) y se van concatenando condiciones solo si el parámetro existe. Así un mismo endpoint sirve para varias búsquedas.

La API del parcial usa exactamente esto en jugadores.php, partidos.php y palmares_listar.php.

Ejemplo · filtros incrementales 
<?php
  extract($_REQUEST);           // $id_categoria, $id_jugador, ...

  $filtros = "where 1";         // filtro base (siempre verdadero)

  if (isset($id_categoria))
      $filtros .= " and id_categoria=" . (int)$id_categoria;

  if (isset($id_jugador))
      $filtros .= " and id_jugador=" . (int)$id_jugador;

  $instruccion = "select * from jugadores " . $filtros;
  // → con ?id_categoria=1 queda:  select * from jugadores where 1 and id_categoria=1
?>
Ejemplo · partidos por localía (A/B) 
<?php
  // localia=A busca el equipo como local (id_equipo_A)
  // localia=B lo busca como visitante (id_equipo_B)
  $filtros = "where 1";
  if (isset($id_categoria))
      $filtros .= " and id_categoria=" . (int)$id_categoria;
  if (isset($id_equipo) and isset($localia)) {
      $localia = "id_equipo_" . $localia;      // id_equipo_A o id_equipo_B
      $filtros .= " and $localia=" . (int)$id_equipo;
  }
  $instruccion = "select * from partidos_canicas " . $filtros;
?>

7. Convertir resultados a JSON para la API

El navegador consume JSON. En PHP se arma un array y se envía con json_encode(). Primero hay que avisar al cliente que la respuesta es JSON con header('Content-Type: application/json'), y (para permitir llamadas desde otro origen) Access-Control-Allow-Origin: *.

El formato típico de las API del parcial es { status, cantidad, productos }. En JavaScript se accede con data.productos.

Ejemplo · endpoint completo (patrón menu.php) 
<?php
  header('Access-Control-Allow-Origin: *');
  header('Content-Type: application/json');
  extract($_REQUEST);
  require("conexion.php");

  $conexion = mysqli_connect($server_db, $usuario_db, $password_db)
      or die("No se puede conectar con el servidor");
  mysqli_select_db($conexion, $base_db);

  $instruccion = "select * from item_menu";
  $consulta = mysqli_query($conexion, $instruccion) or die("Fallo");
  $nfilas   = mysqli_num_rows($consulta);

  if ($nfilas > 0) {
      $data = null;
      while ($row = mysqli_fetch_object($consulta)) {
          $data[] = $row;        // cada fila es un objeto
      }
      echo json_encode([
          'status'    => 200,
          'cantidad'  => $nfilas,
          'productos' => $data      // <-- el array de filas
      ]);
  } else {
      echo json_encode(['status' => 500, 'mensaje' => 'Sin datos']);
  }
  mysqli_close($conexion);
?>

8. json_decode y consumir una API con PHP

Así como json_encode() convierte PHP → JSON, json_decode($texto, true) hace JSON → PHP (array asociativo si el segundo parámetro es true). Sirve cuando un script PHP necesita consumir los datos de otra API o de un servicio externo.

Para descargar el contenido se usa file_get_contents() sobre la URL (las mismas funciones que se usaron para archivos).

Ejemplo 
<?php
  // PHP consumiendo la propia API
  $json = file_get_contents("http://localhost/la_tania/api/equipos.php");
  $datos = json_decode($json, true);         // true = array asociativo

  echo "Cantidad de equipos: " . $datos['cantidad'] . "<br>";

  foreach ($datos['productos'] as $equipo) {
      echo $equipo['nombre'] . " - " . $equipo['puntos'] . " pts<br>";
  }
?>

9. Seguridad: escape e inyección SQL

Cuando se concatenan datos del usuario dentro de una consulta hay riesgo de inyección SQL: alguien puede escribir comillas y SQL malicioso en un campo. Ejemplo: si en el buscador escriben ' OR '1'='1, una consulta mal armada devolvería toda la tabla.

Medidas mínimas:

  • Escapar texto con mysqli_real_escape_string($conexion, $valor).
  • Convertir los numéricos con (int) o (float).
  • La forma recomendada (nivel avanzado) son las consultas preparadas (prepared statements) con mysqli_prepare() y bind_param().
  • Nunca confiar en $_REQUEST/$_GET/$_POST sin validar.
Ejemplo · consulta preparada 
<?php
  $conexion = mysqli_connect($server_db, $usuario_db, $password_db);
  mysqli_select_db($conexion, $base_db);

  // El signo ? es un marcador de posición
  $sql = "SELECT * FROM jugadores WHERE id_categoria = ? AND dni = ?";
  $stmt = mysqli_prepare($conexion, $sql);

  $cat = 1; $dni = "5";
  mysqli_stmt_bind_param($stmt, "is", $cat, $dni);  // i=entero, s=string
  mysqli_stmt_execute($stmt);

  $res = mysqli_stmt_get_result($stmt);
  while ($row = mysqli_fetch_assoc($res)) {
      echo $row['nombre'] . " " . $row['apellido'] . "<br>";
  }
  mysqli_stmt_close($stmt);
  mysqli_close($conexion);
?>
Resultado
