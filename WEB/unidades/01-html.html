Unidad 1 · HTML

HTML (HyperText Markup Language) es un lenguaje de marcado, no de programación: describe la estructura y el contenido de una página mediante etiquetas. Abajo están todos los temas de la unidad, cada uno con su definición y su ejemplo ejecutándose en vivo.

1. Estructura del documento

Todo documento HTML se organiza en un árbol de etiquetas. La raíz es <html>, que contiene dos ramas: <head> (metadatos: título, codificación, CSS, scripts) y <body> (todo lo visible).

La primera línea, <!DOCTYPE html>, le indica al navegador que use el modo estándar HTML5.

EtiquetaFunción
<!DOCTYPE html>Declara el tipo de documento (HTML5).
<html lang="es">Elemento raíz; lang define el idioma.
<head>Contenido no visible: metadatos, estilos, scripts.
<meta charset="UTF-8">Juego de caracteres; permite tildes y ñ.
<meta name="viewport">Adaptación a dispositivos móviles.
<title>Título que se muestra en la pestaña del navegador.
<body>Todo el contenido visible de la página.
Ejemplo · documento mínimo 
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola mundo</h1>
  <p>Esta es mi primera página HTML.</p>
</body>
</html>

2. Etiquetas de texto y títulos

Los títulos van de <h1> (más importante) a <h6> (menos importante). Los párrafos se escriben con <p>. Para dar formato se usan etiquetas semánticas (con significado) en lugar de etiquetas puramente visuales.

<br> es de vacío (no se cierra) y produce un salto de línea; <hr> dibuja una línea separadora.

EtiquetaSignificado
<strong>Importancia / negrita semántica.
<em>Énfasis / cursiva semántica.
<mark>Texto resaltado (como con marcador).
<blockquote>Cita en bloque (párrafo sangrado).
<code>Fragmento de código.
<br> / <hr>Salto de línea / línea horizontal.
Ejemplo 
<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Esto es <strong>muy importante</strong> y esto <em>enfatizado</em>.</p>
<p>Fórmula: <code>x = a + b</code></p>
<blockquote>Cita textual de un autor.</blockquote>
<hr>
<p>Después de la línea.<br>Con salto de línea.</p>

3. Listas

HTML ofrece tres tipos de listas:

No ordenada (<ul>): viñetas. Ordenada (<ol>): numerada. De definición (<dl>): pares término (<dt>) y definición (<dd>). Cada ítem de las dos primeras se marca con <li>, y las listas se pueden anidar.

Ejemplo 
<ul>
  <li>HTML</li>
  <li>CSS
    <ul><li>Selectores</li><li>Box model</li></ul>
  </li>
</ul>

<ol>
  <li>Analizar</li>
  <li>Diseñar</li>
  <li>Programar</li>
</ol>

<dl>
  <dt>DOM</dt>
  <dd>Modelo de Objetos del Documento</dd>
</dl>

4. Enlaces

Los enlaces (hipervínculos) se crean con <a> y su atributo href, que indica el destino. El texto entre las etiquetas es lo que se ve y se puede clicar.

El atributo target decide dónde se abre: en la misma pestaña (por defecto) o en una nueva (_blank).

DestinoCódigo
Sitio externo<a href="https://sitio.com">…</a>
Archivo local<a href="otra.html">…</a>
Ancla interna<a href="#seccion">…</a>
Correo<a href="mailto:x@y.com">…</a>
Nueva pestañatarget="_blank"
Ejemplo 
<a href="https://developer.mozilla.org" target="_blank">
  Documentación de MDN
</a>
<a href="mailto:info@unlpam.edu.ar">Escribinos</a>
<a href="#temas">Ir a Temas</a>

<h2 id="temas">Temas</h2>

5. Imágenes

Las imágenes se insertan con <img>, una etiqueta de vacío (no tiene cierre). Sus atributos clave son src (ruta del archivo) y alt (texto alternativo que se muestra si la imagen no carga y que leen los lectores de pantalla).

Es importante indicar width y height para que el navegador reserve el espacio antes de descargarla.

Ejemplo 
<img src="https://picsum.photos/300/120"
     alt="Imagen de ejemplo"
     width="300" height="120">

<!-- Imagen que hace de enlace -->
<a href="https://unlpam.edu.ar">
  <img src="logo.png" alt="Logo UNLPam" width="80">
</a>

6. Tablas

Las tablas se construyen por filas: cada fila (<tr>) contiene celdas de encabezado (<th>) o de datos (<td>). La tabla se envuelve en <table>.

Para accesibilidad se agrega <caption> (título de la tabla) y se puede agrupar con <thead>, <tbody> y <tfoot>.

Ejemplo 
<table border="1">
  <caption>Alumnos</caption>
  <thead>
    <tr><th>Legajo</th><th>Apellido</th><th>Nota</th></tr>
  </thead>
  <tbody>
    <tr><td>1234</td><td>Pérez</td><td>8</td></tr>
    <tr><td>5678</td><td>Gómez</td><td>9</td></tr>
  </tbody>
</table>

7. Formularios

Un formulario (<form>) es la vía por la que el usuario envía datos al servidor. El atributo action indica a qué página se envían y method cómo (GET o POST). Cada control lleva un name, que es la clave con la que el servidor recibe el valor.

<label for="…"> asocia el rótulo con el campo y mejora la accesibilidad.

Etiqueta / atributoFunción
<input type="text">Campo de texto de una línea.
type="password"Texto oculto con asteriscos.
type="email" / "number" / "date"Campos con validación automática.
type="radio" / "checkbox"Opción única / múltiple.
<textarea>Texto de varias líneas.
<select> + <option>Lista desplegable.
required, placeholderObligatorio, texto guía.
<button type="submit">Envía el formulario.
Ejemplo 
<form action="procesar.php" method="post">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre" placeholder="Tu nombre" required>

  <label for="clave">Clave:</label>
  <input type="password" id="clave" name="clave">

  <label for="pais">País:</label>
  <select id="pais" name="pais">
    <option value="ar">Argentina</option>
    <option value="cl">Chile</option>
  </select>

  <label><input type="checkbox" name="acepta"> Acepto los términos</label>

  <button type="submit">Enviar</button>
</form>

8. Semántica HTML5

HTML5 incorporó etiquetas semánticas: describen qué es cada bloque, no cómo se ve. Esto mejora la accesibilidad, el posicionamiento (SEO) y hace el código más legible.

Antes se usaban <div> con id para todo; hoy se reemplazan por estas etiquetas.

EtiquetaRepresenta
<header>Encabezado de la página o de una sección.
<nav>Bloque de navegación (menú de enlaces).
<main>Contenido principal (uno solo por página).
<section>Sección temática del documento.
<article>Contenido autónomo (noticia, post).
<aside>Contenido lateral o complementario.
<footer>Pie de página.
<figure> / <figcaption>Imagen u objeto con su leyenda.
Ejemplo 
<body>
  <header><h1>Mi sitio</h1></header>
  <nav><a href="#inicio">Inicio</a> | <a href="#blog">Blog</a></nav>
  <main>
    <article>
      <h2>Noticia</h2>
      <p>Cuerpo de la noticia.</p>
    </article>
  </main>
  <aside>Enlaces relacionados</aside>
  <footer>&copy; 2026 UNLPam</footer>
</body>

9. Atributos globales

Hay atributos que se pueden usar en cualquier etiqueta. Los más útiles son id (identificador único), class (grupo reutilizable), style (CSS en línea), title (tooltip) y los data-* (datos personalizados que lee JavaScript).

AtributoPara qué sirve
idIdentifica un elemento de forma única (anclas, CSS, JS).
classAgrupa elementos para aplicarles el mismo estilo.
styleDeclara CSS directamente sobre la etiqueta.
titleTexto emergente al pasar el mouse.
data-*Guarda datos propios para usar desde JS.
hiddenOculta el elemento.
Ejemplo 
<p class="destacado" id="aviso" style="color:#b00" title="Soy un tooltip">
  Pasá el mouse por encima
</p>
<button data-id="42" data-accion="borrar">Borrar</button>

10. HTML dinámico

El HTML dinámico es el HTML que se genera o modifica después de cargar la página. La idea no es escribir el HTML a mano, sino dejar que JavaScript lo construya o lo cambie en respuesta a un evento.

Es la base de AJAX: el script recibe datos y los inserta en el documento sin recargarlo.

Ejemplo 
<p id="salida">Contenido original</p>
<button onclick="document.getElementById('salida').innerHTML = 'Contenido cambiado por JavaScript'">
  Cambiar el texto
</button>
<script>
  // También se puede crear HTML desde cero:
  document.write("<p>Generado dinámicamente</p>");
</script>

11. Iframes

<iframe> incrusta otra página completa dentro de la actual, dentro de un marco con scroll propio. Se usa para mapas, videos, documentos o cualquier contenido externo.

Cada iframe es un contexto aislado (su propio window y document).

AtributoFunción
srcURL de la página a incrustar.
width / heightTamaño del marco.
titleDescripción para accesibilidad.
allowfullscreenPermite pantalla completa (videos).
loading="lazy"Lo carga solo cuando se ve.
Ejemplo 
<iframe src="https://www.example.com"
        width="400" height="180"
        title="Ejemplo" loading="lazy">
</iframe>

<iframe src="https://www.openstreetmap.org/export/embed.html?bbox=-64.5,-35.7,-63.5,-35.2"
        width="400" height="180" title="Mapa">
</iframe>
