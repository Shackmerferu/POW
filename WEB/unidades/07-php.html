Unidad 7 · PHP

PHP (PHP: Hypertext Preprocessor) es un lenguaje de scripting del lado del servidor: el código se ejecuta en el servidor y al navegador le llega solo el HTML resultante. Es la contraparte natural de AJAX: AJAX pide los datos, PHP los genera (normalmente desde una base de datos MySQL).

Nota: PHP no se puede ejecutar en el navegador. En esta unidad cada ejemplo muestra el código y, debajo, el resultado que produciría el servidor (XAMPP + Apache). Para probarlo de verdad, guardá el archivo en htdocs y abrilo como http://localhost/archivo.php.

1. Qué es PHP y cómo se ejecuta

PHP es un lenguaje interpretado y de código abierto pensado para la web. Se incrusta dentro del HTML entre las marcas <?php … ?>. Cuando el navegador pide la página, el servidor (Apache) ejecuta el PHP y envía al cliente solo el HTML ya generado: el usuario nunca ve el código fuente.

Para trabajar localmente se usa un paquete como XAMPP, que instala Apache, PHP y MySQL. Los archivos van en la carpeta htdocs y se accede por http://localhost/….

ArchivoFunción
htdocs/Raíz de los sitios (equivalente al “www”).
index.phpSe carga por defecto al entrar a una carpeta.
php.iniConfiguración de PHP (límites, extensiones).
Ejemplo · hola.php 
<!DOCTYPE html>
<html>
<body>
  <h1><?php echo "Hola desde PHP"; ?></h1>
  <p>Fecha del servidor: <?php echo date("d/m/Y"); ?></p>
</body>
</html>

2. Sintaxis, echo y tipos de datos

Las sentencias terminan en ; y las variables empiezan con $. Para mostrar algo en pantalla se usa echo o print. Los comentarios son iguales que en C/JS: //, # o /* … */.

PHP es de tipado débil (la variable no se declara con tipo, lo toma del valor), aunque admite declaraciones de tipo opcionales.

bool$ok = true;
array$v = [1, 2, 3];
objectnew Persona()

<?php
  $nombre = "Ana";

  $activo = true;

3. Variables y superglobales

El ámbito decide dónde “vive” una variable. Las variables declaradas fuera de una función son globales y no se ven dentro de las funciones salvo que se declaren con global o se acceda por $GLOBALS. Las declaradas dentro de una función son locales. static conserva el valor entre llamadas.

PHP trae superglobales: arrays disponibles en cualquier parte del script.

SuperglobalContiene
$_GETDatos enviados por la URL (método GET).
$_POSTDatos enviados por un formulario (método POST).
$_REQUESTGET + POST + COOKIE.
$_SERVERInfo del servidor y de la petición.
$_FILESArchivos subidos.
$_SESSION / $_COOKIESesión / cookies.
Ejemplo 
<?php
  $contador = 0;

  function incrementar() {
    static $veces = 0;   // conserva el valor entre llamadas
    $veces++;
    global $contador;    // accede a la variable global
    $contador++;
    return $veces;
  }

  echo incrementar();  // 1
  echo incrementar();  // 2
  echo $contador;      // 2

  echo $_SERVER['PHP_SELF'];        // ruta del script
  echo $_SERVER['REQUEST_METHOD'];  // GET o POST
?>

4. Operadores y control de flujo

Los operadores son casi los mismos que en JavaScript: aritméticos, de asignación, comparación (==, ===), lógicos (&&, ||, and, or) y el ternario. Para el control de flujo: if / elseif / else, switch y los bucles for, while, do…while y foreach (propio de arrays).

Ejemplo 
<?php
  $nota = 8;

  if ($nota >= 7) {
    echo "Aprobado";
  } elseif ($nota >= 4) {
    echo "Recuperatorio";
  } else {
    echo "Libre";
  }

  switch ($nota) {
    case 10: echo "Sobresaliente"; break;
    case 8:
    case 9:  echo "Distinguido";   break;
    default: echo "Bueno";
  }

  for ($i = 1; $i <= 3; $i++) { echo "for: $i "; }

  $j = 0;
  while ($j < 2) { echo "while: $j "; $j++; }

  $color = ($nota >= 7) ? "verde" : "rojo";
?>

5. Funciones

Una función agrupa código reutilizable y puede recibir parámetros y devolver un valor con return. Los parámetros pueden tener valor por defecto y se puede declarar el tipo devuelto (a partir de PHP 7).

PHP también admite funciones anónimas (closures) y funciones con número variable de argumentos (...$args).

Ejemplo 
<?php
  // Función con tipo y valor por defecto
  function saludar(string $nombre = "invitado"): string {
    return "Hola, $nombre";
  }
  echo saludar("Ana");     // Hola, Ana
  echo saludar();          // Hola, invitado

  // Con return implícito / paso por referencia
  function duplicar(&$n) { $n *= 2; }
  $x = 5;
  duplicar($x);
  echo $x;                 // 10

  // Función anónima
  $doble = function ($n) { return $n * 2; };
  echo $doble(4);          // 8

  // Argumentos variables
  function sumar(...$nums) { return array_sum($nums); }
  echo sumar(1, 2, 3, 4);  // 10
?>

6. Arrays y strings

PHP tiene arrays indexados (por número) y asociativos (por clave), y ambos pueden anidarse. Los recorridos se hacen con foreach. Para las cadenas hay funciones de largo, corte, búsqueda y reemplazo, y el operador . concatena.

Función de arrayQué hace
count($a)Cantidad de elementos.
array_push() / array_pop()Agrega al final / quita el último.
sort() / rsort()Ordena ascendente / descendente.
implode(sep, $a)Une el array en un string.
array_keys() / array_values()Las claves / los valores.
in_array(x, $a)¿Existe el valor?
Función de stringQué hace
strlen($s)Largo.
strtoupper() / strtolower()Mayúsculas / minúsculas.
substr($s, ini, n)Extrae un tramo.
str_replace()Reemplaza.
explode(sep, $s)String → array.
trim($s)Quita espacios extremos.
Ejemplo 
<?php
  $frutas = ["pera", "manzana", "uva"];          // indexado
  $persona = ["nombre" => "Ana", "edad" => 22];  // asociativo

  echo $frutas[0];              // pera
  echo count($frutas);          // 3
  array_push($frutas, "kiwi");
  echo implode(", ", $frutas);  // pera, manzana, uva, kiwi

  foreach ($persona as $clave => $valor) {
    echo "$clave: $valor ";
  }

  // Strings
  $t = "  Hola Mundo  ";
  echo strlen($t);              // 14
  echo trim($t);                // "Hola Mundo"
  echo strtoupper($t);          // "  HOLA MUNDO  "
  echo substr($t, 2, 4);        // "Hola"
  echo str_replace("Mundo", "PHP", $t);
  print_r(explode(" ", trim($t)));
?>

7. Formularios: GET y POST

El formulario HTML envía los datos al script PHP indicado en action, usando el método GET o POST. PHP los recibe en la superglobal correspondiente. Con $_GET los datos viajan en la URL (visibles); con $_POST van en el cuerpo (más adecuado para contraseñas y altas).

Dentro del mismo archivo se puede detectar el envío con if ($_SERVER["REQUEST_METHOD"] == "POST"), el patrón “formulario y proceso en la misma página”.

Ejemplo 
<!-- formulario.html -->
<form action="procesar.php" method="post">
  <label>Nombre:</label>
  <input type="text" name="nombre">
  <label>Correo:</label>
  <input type="email" name="correo">
  <button>Enviar</button>
</form>

<?php  // procesar.php
  if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $nombre = htmlspecialchars($_POST["nombre"]);   // sanitizar
    $correo = filter_var($_POST["correo"], FILTER_VALIDATE_EMAIL);

    if ($correo) {
      echo "Gracias $nombre, te contactaremos a $correo";
    } else {
      echo "El correo no es válido";
    }
  }
?>

8. Archivos, cookies y sesiones

PHP puede leer y escribir archivos del servidor con fopen, fwrite, fclose, o de una sola vez con file_get_contents y file_put_contents.

Para mantener estado entre páginas se usan cookies (se guardan en el navegador del usuario) y sesiones (se guardan en el servidor y se identifican con una cookie de sesión). Con session_start() se abre la sesión y se lee/escribe $_SESSION. Las sesiones son la base de un login.

Ejemplo 
<?php
  // --- Archivos ---
  file_put_contents("log.txt", "Nueva visita\n", FILE_APPEND);
  $contenido = file_get_contents("log.txt");
  echo $contenido;

  // --- Cookies ---
  setcookie("usuario", "ana", time() + 3600);   // 1 hora
  echo $_COOKIE["usuario"] ?? "";

  // --- Sesiones ---
  session_start();
  $_SESSION["nombre"] = "Ana";
  $_SESSION["tipo_usuario"] = "admin";

  // --- Login simple ---
  if ($_POST["usuario"] == "ana" && $_POST["clave"] == "1234") {
    $_SESSION["logueado"] = true;
    header("Location: home.php");    // redirige
  } else {
    header("Location: index.php");
  }
?>
Resultado · flujo del login

9. Programación orientada a objetos

PHP soporta POO: class define un molde con propiedades y métodos; new crea los objetos. La visibilidad puede ser public, protected o private. El constructor es __construct() y $this es el objeto actual.

Se puede heredar con extends y aplicar interfaces (implements) y traits (use) para reutilizar código entre clases no relacionadas.

Ejemplo 
<?php
  class Persona {
    public string $nombre;
    protected int $edad;

    public function __construct(string $nombre, int $edad) {
      $this->nombre = $nombre;
      $this->edad   = $edad;
    }

    public function saludar(): string {
      return "Hola, soy {$this->nombre}";
    }
  }

  class Alumno extends Persona {          // herencia
    private string $legajo;

    public function __construct($n, $e, $legajo) {
      parent::__construct($n, $e);        // llama al constructor padre
      $this->legajo = $legajo;
    }

    public function saludar(): string {   // sobrescritura
      return parent::saludar() . " (legajo $this->legajo)";
    }
  }

  $p = new Persona("Ana", 22);
  echo $p->saludar();                     // Hola, soy Ana

  $a = new Alumno("Luis", 20, "1234");
  echo $a->saludar();                     // Hola, soy Luis (legajo 1234)

  // Trait (reutilización de métodos)
  trait Saludable { public function bien() { return "Todo bien"; } }
?>
Resultado
