Unidad 2 · CSS

CSS (Cascading Style Sheets) describe la presentación del HTML: colores, tipografía, espaciados, tamaños, posición y adaptación a cada pantalla. Separa el contenido (HTML) del diseño (CSS).

1. Formas de incluir CSS

Hay tres maneras de aplicar estilos, y se pueden combinar. La recomendada es la hoja externa, porque un solo archivo .css da estilo a todas las páginas y el navegador lo guarda en caché.

FormaCómoAlcance
Externa<link rel="stylesheet" href="estilos.css"> en el <head>Todas las páginas que la enlacen.
Interna<style>…</style> en el <head>Solo esa página.
En líneastyle="color:red" en la etiquetaSolo ese elemento.
Ejemplo 
<!-- 1. Hoja externa (recomendada) -->
<head>
  <link rel="stylesheet" href="styles.css">
</head>

<!-- 2. Estilos internos -->
<style>
  h1 { color: navy; }
</style>

<!-- 3. Estilos en línea -->
<p style="color: crimson;">Texto rojo</p>

2. Sintaxis, reglas y comentarios

Una regla de CSS tiene dos partes: el selector (a qué elementos aplica) y el bloque de declaraciones entre llaves, con pares propiedad: valor;. Los comentarios se escriben entre /* … */.

Ejemplo 
/* selector { propiedad: valor; } */
p {
  color: #333333;
  font-size: 16px;
  line-height: 1.5;
}

/* Un bloque puede tener varias propiedades
   y hay que terminar cada una con punto y coma */

3. Selectores

El selector es la parte más importante de CSS: decide a quién se aplican los estilos. Se pueden combinar y agrupar, y también se basan en el estado o en la posición del elemento.

SelectorSelecciona
pTodos los elementos de esa etiqueta.
.alertaTodos los elementos con class="alerta".
#navEl elemento con id="nav".
*Todos los elementos.
div pPárrafos dentro de un div (descendiente).
ul > liHijos directos (child).
h1 + pPárrafo inmediatamente después de un h1 (adyacente).
a:hoverCuando el mouse está encima (pseudo-clase).
input[type="text"]Por atributo.
li:first-childEl primer hijo (pseudo-clase estructural).
Ejemplo 
<style>
  p            { color: #444; }
  .destacado   { background: #fffbeb; }
  #unico       { border-left: 4px solid #4f46e5; }
  a:hover      { color: red; }
  ul li:first-child { font-weight: bold; }
</style>

<p>Párrafo normal</p>
<p class="destacado">Párrafo destacado</p>
<p id="unico">Párrafo con id</p>
<a href="#">Pasá el mouse por este enlace</a>
<ul><li>Primero</li><li>Segundo</li></ul>

4. Cascada, herencia y especificidad

Cuando dos reglas afectan al mismo elemento, gana la que tiene mayor especificidad. El orden de prioridad aproximado es: estilos en línea > id > clase/atributo/pseudo-clase > etiqueta. Si empatan, gana la que aparece última (cascada).

La herencia hace que propiedades como el color o la tipografía pasen del contenedor a sus hijos, salvo que se sobrescriban. !important fuerza una declaración.

Ejemplo 
<style>
  p        { color: green; }        /* etiqueta  →  baja prioridad */
  .aviso   { color: orange; }       /* clase     →  media */
  #final   { color: crimson; }      /* id        →  alta */

  body { font-family: Georgia, serif; } /* se hereda en los hijos */
</style>

<p>Queda verde</p>
<p class="aviso">Queda naranja</p>
<p class="aviso" id="final">Queda carmesí (gana el id)</p>

5. Box model (modelo de caja)

Todo elemento es una caja rectangular formada por cuatro capas, de adentro hacia afuera: contenido, padding (relleno interno), border (borde) y margin (separación externa).

Con box-sizing: border-box el ancho declarado incluye padding y borde, lo que hace el cálculo mucho más predecible (es lo que aplican Bootstrap y la mayoría de los resets).

PropiedadQué controla
width / heightAncho y alto del contenido.
paddingEspacio interno (1 a 4 valores).
marginEspacio externo. auto centra horizontalmente.
borderAncho, estilo y color del borde.
border-radiusRedondeo de esquinas.
box-sizingIncluye padding y borde en el ancho.
Ejemplo 
<style>
  .caja {
    box-sizing: border-box;
    width: 260px;
    padding: 16px;
    border: 3px solid #4f46e5;
    border-radius: 10px;
    margin: 20px auto;      /* auto = centrada */
  }
</style>

<div class="caja">Caja con contenido, padding, borde y margen.</div>

6. Colores y fondos

Los colores se pueden declarar con nombre, hexadecimal (#rrggbb), rgb/rgba (con transparencia) o hsl. Los fondos aceptan color, imagen, degradados y repetición.

SintaxisEjemplo
Nombrecolor: crimson;
Hexadecimalcolor: #4f46e5;
RGB / RGBArgba(79,70,229,0.5)
HSLhsl(243, 75%, 59%)
Degradadobackground: linear-gradient(90deg,#4f46e5,#06b6d4);
Imagenbackground-image: url(fondo.jpg);
Ejemplo 
<style>
  .c1 { color: crimson; }
  .c2 { background: #4f46e5; color: #fff; }
  .c3 { background: rgba(79, 70, 229, .25); }
  .c4 { background: linear-gradient(90deg, #4f46e5, #06b6d4); color: #fff; }
</style>

<p class="c1">Texto carmesí</p>
<p class="c2">Fondo sólido</p>
<p class="c3">Fondo con transparencia</p>
<p class="c4">Fondo con degradado</p>

7. Unidades y tipografía

Las medidas pueden ser absolutas (px, no dependen del contexto) o relativas (em, rem, %, vw, vh). Las relativas son la base del diseño flexible y responsivo.

Para el texto se usan font-family, font-size, font-weight, font-style, line-height, text-align, text-decoration y text-transform.

Ejemplo 
<style>
  html { font-size: 16px; }              /* 1rem = 16px */
  .titulo {
    font-family: Georgia, serif;
    font-size: 1.6rem;                   /* relativo a la raíz */
    font-weight: 700;
    line-height: 1.2;
    text-transform: uppercase;
  }
  .texto {
    font-size: 14px;
    text-align: justify;
    text-decoration: underline;
    color: #555;
  }
  .ancho { width: 60%; }                 /* relativo al contenedor */
</style>

<p class="titulo">Título en mayúsculas</p>
<p class="texto">Párrafo justificado y subrayado.</p>
<div class="ancho" style="background:#eef2ff;padding:6px">60% del ancho</div>

8. Enlaces, listas y tablas

Los enlaces tienen estados (pseudo-clases): :link sin visitar, :visited visitado, :hover con el mouse encima y :active mientras se mantiene apretado (se declaran en ese orden). Las listas y tablas también se estilizan: se puede quitar la viñeta con list-style y colapsar bordes con border-collapse.

Ejemplo 
<style>
  a:link    { color: #4f46e5; text-decoration: none; }
  a:visited { color: #7c3aed; }
  a:hover   { color: crimson; text-decoration: underline; }
  a:active  { color: orange; }

  ul.sin-vineta { list-style: none; padding-left: 0; }

  table { border-collapse: collapse; width: 100%; }
  th, td { border: 1px solid #ddd; padding: 8px; }
  tbody tr:nth-child(even) { background: #f6f7f9; } /* filas alternadas */
  th { background: #eef2ff; }
</style>

<table><tr><th>A</th><th>B</th></tr><tr><td>1</td><td>2</td></tr><tr><td>3</td><td>4</td></tr></table>

9. Visualización y posicionamiento

display decide cómo se comporta la caja: block (ocupa toda la línea), inline (solo su contenido), inline-block (en línea pero acepta ancho y alto), none (la oculta y no reserva espacio).

position saca al elemento del flujo normal: static (por defecto), relative, absolute (relativo al ancestro posicionado), fixed (fijo a la ventana) y sticky (se pega al hacer scroll).

Valor de positionComportamiento
staticFlujo normal, ignora top/left.
relativeSe desplaza desde su posición original.
absoluteSe ubica respecto al ancestro posicionado.
fixedFijo respecto a la ventana al hacer scroll.
stickyNormal hasta llegar al límite, luego se pega.
Ejemplo 
<style>
  .padre { position: relative; height: 110px; background: #eef2ff; }
  .hijo  { position: absolute; top: 12px; right: 12px;
           background: crimson; color: #fff; padding: 6px 10px; }
  .inline-block { display: inline-block; width: 120px;
                  background: #06b6d4; color: #fff; padding: 8px; margin: 4px; }
</style>

<div class="padre">
  Contenedor posicionado
  <span class="hijo">absolute</span>
</div>
<div class="inline-block">Caja 1</div><div class="inline-block">Caja 2</div>

10. Flexbox

Flexbox es un modelo de layout en una dimensión (fila o columna). Se activa con display: flex en el contenedor, que distribuye y alinea a sus hijos (los ítems).

Resuelve de forma sencilla el centrado, el reparto de espacio y el orden, tanto en filas como en columnas.

PropiedadAplica aQué hace
display: flexContenedorActiva el modelo flex.
flex-directionContenedorrow / column.
justify-contentContenedorAlinea en el eje principal.
align-itemsContenedorAlinea en el eje cruzado.
flex-wrapContenedorPermite que los ítems salten de línea.
gapContenedorSeparación entre ítems.
flexÍtemCómo crece o se encoge.
Ejemplo 
<style>
  .barra {
    display: flex;
    justify-content: space-between;  /* separa a los extremos */
    align-items: center;
    gap: 10px;
    background: #eef2ff; padding: 12px; border-radius: 8px;
  }
  .tarjeta { flex: 1; background: #4f46e5; color: #fff;
             padding: 14px; text-align: center; border-radius: 6px; }
</style>

<div class="barra">
  <div class="tarjeta">1</div>
  <div class="tarjeta">2</div>
  <div class="tarjeta">3</div>
</div>

11. Grid

Grid es un modelo de layout en dos dimensiones (filas y columnas a la vez). Se activa con display: grid y se definen las pistas con grid-template-columns y grid-template-rows.

La unidad fr reparte el espacio disponible. Es ideal para maquetas completas de página.

Ejemplo 
<style>
  .grilla {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* 3 columnas iguales */
    grid-template-rows: auto auto;
    gap: 10px;
  }
  .celda { background: #06b6d4; color: #fff; padding: 16px;
           text-align: center; border-radius: 6px; }
  .ancha { grid-column: span 2; background: #4f46e5; } /* ocupa 2 columnas */
</style>

<div class="grilla">
  <div class="celda">1</div>
  <div class="celda">2</div>
  <div class="celda">3</div>
  <div class="celda ancha">Ocupa 2 columnas</div>
  <div class="celda">5</div>
</div>

12. Diseño responsivo

El diseño responsivo adapta la página al tamaño del dispositivo. Se logra con media queries (@media), medidas relativas y el meta viewport del <head>.

La idea es mobile first: se escribe primero el estilo para celular y luego se amplía con min-width.

Ejemplo 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<style>
  .columnas { display: flex; flex-direction: column; gap: 10px; }
  .caja { background: #eef2ff; padding: 12px; border-radius: 6px; }

  /* A partir de 600px se ponen en fila */
  @media (min-width: 600px) {
    .columnas { flex-direction: row; }
    .caja { flex: 1; }
  }
</style>

<div class="columnas">
  <div class="caja">Columna A</div>
  <div class="caja">Columna B</div>
</div>
