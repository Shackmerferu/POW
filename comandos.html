Estructura Base

<!DOCTYPE html>
Declaración del tipo de documento.
Se coloca en la primera línea de todo archivo HTML. Le indica al navegador que el documento está en modo estándar HTML5.
<!DOCTYPE html>
<html>
Elemento raíz del documento HTML.
Envuelve todo el contenido de la página. El atributo lang define el idioma del documento para accesibilidad y SEO.
<html lang="es"> <!-- contenido del documento --> </html>
<head>
Contenedor de metadatos del documento.
Agrupa información que no se muestra visualmente: título, charset, estilos, scripts, favicon y otros metadatos.
<head> <meta charset="UTF-8"> <title>Mi Página</title> <link rel="stylesheet" href="style.css"> </head>
<body>
Contenido visible del documento.
Contiene todo el contenido que se renderiza en el navegador: texto, imágenes, formularios, etc.
<body> <h1>Hola Mundo</h1> <p>Contenido visible</p> </body>
<title>
Título del documento.
Define el texto que aparece en la pestaña del navegador. Obligatorio en todo documento HTML y esencial para SEO.
<title>Mi Sitio Web</title>
<meta>
Metadatos del documento.
Define información como charset, viewport (responsiveness), descripción para SEO, robots, autor, y refresh.
<meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <meta name="description" content="Descripción del sitio">
<link>
Enlaza recursos externos.
Se usa para conectar hojas de estilo CSS, favicon, fuentes, prefetch y preconnect. No tiene contenido visual.
<link rel="stylesheet" href="styles.css"> <link rel="icon" href="favicon.ico">
<style>
Define estilos CSS internos.
Permite escribir CSS directamente en el HTML dentro del <head>. Útil para estilos de página o cuando no se usa un archivo externo.
<style> body { background: #0f0f0f; } h1 { color: #7dd3fc; } </style>
<script>
Incluye o ejecuta JavaScript.
Carga scripts externos con src o escribe código JS inline. Usar defer para no bloquear el render o async para carga paralela.
<script src="app.js" defer></script> <script> console.log("Hola"); </script>
<base>
Define la URL base para enlaces relativos.
Especifica la URL base que se usará para resolver todos los enlaces relativos en el documento. Solo uno por página.
<head> <base href="https://misitio.com/" target="_blank"> </head>

Textos y Contenido

<h1> a <h6>
Encabezados de diferentes niveles.
Definen la jerarquía de títulos. <h1> es el más importante (solo uno por página recomendado), bajando hasta <h6>.
<h1>Título Principal</h1> <h2>Subtítulo</h2> <h3>Sección menor</h3>
<p>
Párrafo de texto.
Agrupa texto en párrafos. Los navegadores añaden margen vertical automáticamente. Es el elemento base para contenido de texto.
<p>Este es un párrafo de texto que el navegador renderiza con espaciado entre párrafos.</p>
<br>
Salto de línea.
Inserta un salto de línea dentro de un elemento. Es un elemento vacío (sin cierre). Usar con moderación; preferir CSS para espaciado.
<p>Línea uno<br>Línea dos</p>
<hr>
Separador temático.
Representa una pausa temática entre párrafos (cambio de tema). Visualmente se muestra como una línea horizontal.
<p>Contenido anterior</p> <hr> <p>Contenido posterior</p>
<pre>
Texto preformateado.
Preserva espacios, saltos de línea y formato. Ideal para mostrar código, arte ASCII o cualquier texto donde el formato importe.
<pre> Nombre Edad ───────────── Ana 25 Carlos 30 </pre>
<blockquote>
Cita en bloque.
Representa un contenido citado de otra fuente. Los navegadores lo indentan por defecto. Usar cite para la URL de origen.
<blockquote cite="https://ejemplo.com"> <p>La citación va aquí</p> </blockquote>
<q>
Cita inline.
Para citas textuales cortas dentro de un párrafo. El navegador añade comillas automáticamente según el idioma.
<p>Einstein dijo: <q>La imaginación es más importante que el conocimiento</q>.</p>
<abbr>
Abreviatura.
Representa una abreviatura o acrónimo. El atributo title muestra la explicación completa al pasar el cursor.
<abbr title="HyperText Markup Language">HTML</abbr>
<cite>
Título de una obra citada.
Indica el título de una obra creativa (libro, película, canción). Se renderiza en itálica por defecto.
<p>Mi libro favorito es <cite>Don Quijote</cite>.</p>
<address>
Información de contacto.
Proporciona información de contacto del autor/propietario del documento. Usar dentro de <header> o <footer>.
<address> Escrito por <a href="mailto:info@ejemplo.com">María</a> </address>

Formato de Texto

<strong>
Importancia fuerte.
Indica que el contenido tiene importancia fuerte (generalmente se muestra en negrita). Es semántico, a diferencia de <b>.
<p>¡<strong>Advertencia!</strong> No tocar.</p>
<b>
Negrita estilística (sin énfasis semántico).
Pone el texto en negrita pero sin implicar importancia extra. Para atención visual sin significado semántico (nombres de producto, etc.).
<p>El producto <b>ProMax</b> está disponible.</p>
<em>
Énfasis semántico.
Añade énfasis al texto (generalmente en itálica). Tiene significado semántico para lectores de pantalla.
<p>Esto es <em>muy importante</em>.</p>
<i>
Itálico estilístico.
Texto en itálico sin énfasis semántico. Para términos técnicos, palabras en otro idioma, pensamientos, etc.
<p>El término <i>status quo</i> viene del latín.</p>
<small>
Texto secundario o pequeño.
Para texto de notas al pie, derechos de autor, aclaraciones legales. Se renderiza más pequeño.
<p>Producto registrado® <small>© 2024 Empresa S.A.</small></p>
<mark>
Texto resaltado.
Resalta texto con fondo amarillo (por defecto). Ideal para resultados de búsqueda o contenido destacado.
<p>Busca: <mark>HTML</mark> en el documento.</p>
<del>
Texto eliminado.
Muestra texto que fue borrado del documento. Se renderiza con tachado. Útil para mostrar ediciones.
<p>Precio: <del>$100</del> <ins>$75</ins></p>
<ins>
Texto insertado.
Indica contenido recién agregado. Se renderiza con subrayado. Complemento natural de <del>.
<p>Precio: <del>$100</del> <ins>$75</ins></p>
<s>
Texto ya no relevante.
Muestra contenido que ya no es correcto o relevante (sin indicar edición). Diferente de <del> que implica borrado deliberado.
<p><s>$200</s> $150 - ¡Oferta!</p>
<sub>
Subíndice.
Texto que se muestra como subíndice (más abajo y pequeño). Para fórmulas químicas, notas al pie, etc.
<p>Agua: H<sub>2</sub>O</p>
<sup>
Superíndice.
Texto que se muestra como superíndice (más arriba y pequeño). Para potencias, exponentes, etc.
<p>x<sup>2</sup> + y<sup>2</sup> = z<sup>2</sup></p>
<code>
Código en línea.
Representa un fragmento de código. Se renderiza con fuente monoespaciada. Combinar con <pre> para bloques de código.
<p>Usa <code>console.log()</code> para depurar.</p>
<kbd>
Entrada de teclado.
Representa una pulsación de tecla o combinación de teclas. Ideal para instrucciones y documentación.
<p>Presiona <kbd>Ctrl</kbd> + <kbd>S</kbd> para guardar.</p>
<samp>
Salida de ejemplo.
Muestra la salida de un programa o sistema. Para documentar resultados esperados.
<p>El programa imprime: <samp>Error 404: No encontrado</samp></p>
<var>
Variable matemática o de programación.
Representa una variable en contexto matemático o de programación. Se muestra en itálica.
<p>Si <var>x</var> = 5, entonces <var>x</var><sup>2</sup> = 25</p>

Enlaces e Imágenes

<a>
Enlace (ancla).
Crea hipervínculos a otras páginas, archivos o secciones. Usar target="_blank" para nueva pestaña y rel="noopener" por seguridad.
<a href="https://google.com" target="_blank" rel="noopener">Ir a Google</a>
<img>
Imagen.
Inserta una imagen. El atributo alt es obligatorio para accesibilidad. Usar loading="lazy" para carga diferida.
<img src="foto.jpg" alt="Descripción" width="300" loading="lazy">
<picture>
Contenedor de imagen responsiva.
Permite servir diferentes versiones de imagen según el tamaño de pantalla o formato soportado. Envuelve <source> y <img>.
<picture> <source media="(min-width: 800px)" srcset="grande.webp"> <img src="pequeña.jpg" alt="Imagen"> </picture>
<source>
Fuente multimedia alternativa.
Define fuentes alternativas para <picture>, <video> o <audio>. Permite formatos y resoluciones múltiples.
<video controls> <source src="video.webm" type="video/webm"> <source src="video.mp4" type="video/mp4"> </video>
<area>
Zona clickeable en un mapa de imagen.
Define áreas clickeables dentro de un <map>. Puede ser rectangular, circular o poligonal.
<map name="mapa"> <area shape="rect" coords="0,0,100,100" href="zona1.html"> </map>
<map>
Mapa de imagen.
Define un mapa de imagen con áreas clickeables. Se conecta con <img> mediante el atributo usemap.
<img src="plano.jpg" usemap="#plano" alt="Plano"> <map name="plano"> <area shape="circle" coords="150,100,50" href="info.html"> </map>

Listas

<ul>
Lista desordenada.
Lista con viñetas (puntos). Usar cuando el orden no importa: características, opciones, etc.
<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>
<ol>
Lista ordenada.
Lista numerada o con letras. Usar para pasos, rankings, prioridades. Atributo type: 1, A, a, I, i.
<ol type="1"> <li>Primero</li> <li>Segundo</li> <li>Tercero</li> </ol>
<li>
Elemento de lista.
Cada ítem dentro de <ul> o <ol>. Puede contener cualquier contenido, incluyendo otras listas anidadas.
<li>Texto del ítem</li> <li> <img src="icon.png" alt="Icono"> Con imagen </li>
<dl>
Lista de definiciones.
Agrupa pares de término y descripción. Ideal para glosarios, FAQ, metadatos.
<dl> <dt>HTML</dt> <dd>Lenguaje de marcado para páginas web</dd> </dl>
<dt>
Término en lista de definiciones.
Define el término o nombre dentro de un <dl>. Se empareja con <dd>.
<dt>CSS</dt>
<dd>
Descripción en lista de definiciones.
Contiene la descripción o definición del término <dt>. Se indenta por defecto.
<dd>Hojas de estilo en cascada para diseñar la apariencia web</dd>

Tablas

<table>
Tabla de datos.
Estructura tabular de datos (no para diseño). Usar con <thead>, <tbody>, <tfoot> para semántica correcta.
<table> <caption>Usuarios</caption> <thead>...</thead> <tbody>...</tbody> </table>
<tr>
Fila de tabla.
Define una fila dentro de la tabla. Contiene celdas <td> o <th>.
<tr> <td>Dato 1</td> <td>Dato 2</td> </tr>
<td>
Celda de datos.
Celda estándar de tabla con contenido de datos. Usar colspan y rowspan para celdas que abarcan múltiples filas/columnas.
<td colspan="2">Contenido ampliado</td>
<th>
Celda de encabezado.
Celda de encabezado (generalmente en negrita y centrada). Usar en filas de <thead> o primera columna.
<th scope="col">Nombre</th> <th scope="col">Edad</th>
<thead>
Grupo de encabezados de tabla.
Agrupa las filas de encabezado. Mejora la accesibilidad y permite estilos específicos para el encabezado.
<thead> <tr> <th>Nombre</th> <th>Edad</th> </tr> </thead>
<tbody>
Grupo de cuerpo de tabla.
Contiene las filas de datos principales. Se genera automáticamente si se omite, pero es mejor incluirlo explícitamente.
<tbody> <tr><td>Ana</td><td>25</td></tr> </tbody>
<tfoot>
Grupo de pies de tabla.
Contiene filas de resumen al final de la tabla (totales, promedios). Siempre después de <tbody>.
<tfoot> <tr> <td>Total</td> <td>$1,500</td> </tr> </tfoot>
<caption>
Título de la tabla.
Describe el contenido de la tabla. Esencial para accesibilidad. Se posiciona arriba o abajo con CSS.
<table> <caption>Ventas mensuales 2024</caption> <!-- filas y celdas --> </table>
<colgroup> / <col>
Agrupación y estilo de columnas.
<colgroup> agrupa columnas; <col> define propiedades de cada una. Para ancho, fondo o estilos por columna.
<colgroup> <col span="2" style="background: #eee"> <col style="background: #ddd"> </colgroup>

Formularios

<form>
Formulario de entrada.
Contenedor de campos de formulario. action define la URL de envío; method puede ser GET o POST.
<form action="/enviar" method="POST"> <!-- campos del formulario --> <button type="submit">Enviar</button> </form>
<input>
Campo de entrada.
El elemento más versátil del formulario. Type: text, email, password, number, checkbox, radio, date, file, range, color, url, tel, search, hidden.
<input type="text" name="nombre" placeholder="Tu nombre" required> <input type="email" name="email"> <input type="checkbox" name="acepto">
<textarea>
Área de texto multilínea.
Campo de texto con múltiples líneas. Atributos: rows, cols, placeholder, maxlength.
<textarea name="mensaje" rows="5" cols="40" placeholder="Escribe aquí..."></textarea>
<select> / <option>
Menú desplegable de selección.
<select> crea el menú; <option> cada elemento. Usar selected para valor por defecto.
<select name="pais"> <option value="">Seleccionar...</option> <option value="ar" selected>Argentina</option> <option value="mx">México</option> </select>
<label>
Etiqueta de campo.
Asocia un texto descriptivo con un campo. Esencial para accesibilidad. Usar for con el id del campo.
<label for="email">Email:</label> <input type="email" id="email" name="email">
<button>
Botón clickeable.
Botón interactivo. Type: submit (envía form), reset (limpia), button (sin acción por defecto).
<button type="submit">Enviar</button> <button type="reset">Limpiar</button> <button type="button" onclick="alert('hi')">Click</button>
<fieldset>
Grupo de campos.
Agrupa campos relacionados con un borde visual. Mejora accesibilidad y organización de formularios complejos.
<fieldset> <legend>Datos personales</legend> <input type="text" name="nombre"> </fieldset>
<legend>
Título de fieldset.
Define el título/caption de un <fieldset>. Aparece dentro del borde del grupo.
<fieldset> <legend>Información de envío</legend> <!-- campos --> </fieldset>
<datalist>
Lista de sugerencias para input.
Proporciona opciones predefinidas para un <input>. El usuario puede elegir o escribir su propio valor.
<input list="colores" name="color"> <datalist id="colores"> <option value="Rojo"> <option value="Azul"> <option value="Verde"> </datalist>
<optgroup>
Grupo de opciones.
Agrupa opciones dentro de un <select> con una etiqueta. Para listas con categorías.
<select> <optgroup label="América"> <option>Argentina</option> <option>Brasil</option> </optgroup> </select>
<output>
Resultado de un cálculo.
Muestra el resultado de una operación del formulario. Se actualiza con JavaScript. Asociar con for a los inputs involucrados.
<input type="number" value="5" id="a"> × <input type="number" value="3" id="b"> = <output name="resultado" for="a b">15</output>

Semánticos HTML5

<header>
Encabezado de sección o página.
Contenido introductorio: logo, navegación, título. Puede usarse múltiples veces (uno por <article>, <section>, etc.).
<header> <h1>Mi Sitio</h1> <nav>...</nav> </header>
<footer>
Pie de sección o página.
Contenido final: copyright, enlaces, info de contacto. Como <header>, puede usarse múltiples veces.
<footer> <p>© 2024 Mi Empresa</p> <a href="/privacidad">Privacidad</a> </footer>
<nav>
Bloque de navegación.
Contiene enlaces de navegación principales. No todos los enlaces necesitan estar en <nav>, solo los principales.
<nav> <a href="/">Inicio</a> <a href="/about">Nosotros</a> <a href="/contact">Contacto</a> </nav>
<main>
Contenido principal.
El contenido dominante de la página. Solo uno por documento. Excluye header, footer, nav, sidebar repetitivos.
<main> <article>...</article> </main>
<article>
Contenido independiente.
Contenido que tiene sentido por sí solo: blog post, noticia, tweet, widget. Puede contener otros artículos (comentarios).
<article> <h2>Título del Post</h2> <p>Contenido del artículo...</p> </article>
<section>
Sección temática genérica.
Agrupa contenido por tema. Diferente de <div>: tiene significado semántico. Usar con un título interno.
<section> <h2>Características</h2> <p>Lista de features...</p> </section>
<aside>
Contenido lateral.
Contenido tangencialmente relacionado: sidebars, publicidad, enlaces relacionados, biografía del autor.
<aside> <h3>Artículos relacionados</h3> <ul>...</ul> </aside>
<figure>
Contenido independiente (imagen, diagrama).
Envuelve contenido independiente del flujo: imágenes, gráficos, código. Se asocia con <figcaption>.
<figure> <img src="diagrama.png" alt="Arquitectura"> <figcaption>Arquitectura del sistema</figcaption> </figure>
<figcaption>
Caption de figure.
Describe el contenido de un <figure>. Puede ir antes o después del contenido que describe.
<figcaption>Figura 1: Diagrama de flujo del sistema</figcaption>
<div>
Contenedor genérico (bloque).
Contenedor sin significado semántico. Usar cuando ningún otro elemento semántico se ajusta. Base del layout con CSS/JS.
<div class="container"> <p>Contenido genérico</p> </div>
<span>
Contenedor genérico (inline).
Contenedor inline sin significado semántico. Para aplicar estilos o scripts a fragmentos de texto dentro de un párrafo.
<p>Esta palabra es <span class="resaltada">especial</span>.</p>

Multimedia

<video>
Reproductor de video.
Incrusta video con controles nativos. Atributos: controls, autoplay, loop, muted, poster, preload.
<video controls width="640" poster="thumb.jpg"> <source src="video.mp4" type="video/mp4"> Tu navegador no soporta video. </video>
<audio>
Reproductor de audio.
Incrusta audio con controles. Mismos atributos que video. Soporta múltiples formatos con <source>.
<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> Tu navegador no soporta audio. </audio>
<iframe>
Marco en línea (contenido externo).
Incrusta contenido de otra página: YouTube, Google Maps, etc. Usar loading="lazy" y sandbox por seguridad.
<iframe src="https://youtube.com/embed/ID" width="560" height="315" loading="lazy" sandbox="allow-scripts" title="Video" ></iframe>
<embed>
Contenido externo embebido.
Incrusta contenido externo (plugins, SVG, PDF). El contenido es autónomo. Usar cuando se conoce el tipo exacto.
<embed src="diagrama.svg" type="image/svg+xml" width="400">
<object>
Contenido externo genérico.
Incrusta contenido externo con fallback. Puede contener <param> para configuración. Más flexible que <embed>.
<object data="doc.pdf" type="application/pdf" width="600"> <p>Tu navegador no soporta PDFs. <a href="doc.pdf">Descargar</a></p> </object>

Detalles

<details>
Contenido colapsable (acordeón).
Crea un widget expandible sin JavaScript. El contenido se oculta por defecto y se muestra al hacer clic en <summary>.
<details> <summary>Ver más información</summary> <p>Contenido oculto que se muestra al expandir.</p> </details>
<summary>
Resumen/cabecera de details.
Define el elemento clickeable que muestra/oculta el contenido de <details>. Requerido dentro de <details>.
<details> <summary>¿Cómo funciona?</summary> <p>Funciona con JavaScript nativo del navegador.</p> </details>
<dialog>
Diálogo modal o no modal.
Crea un diálogo/modal nativo. Método showModal() para modal, show() para no modal. Sin librerías externas.
<dialog id="miDialog"> <h2>Título del diálogo</h2> <p>Contenido del modal</p> <button onclick="this.closest('dialog').close()">Cerrar</button> </dialog>

Progreso y Medición

<progress>
Barra de progreso.
Muestra el progreso de una tarea (carga, descarga). Atributos: value (0 a max) y max.
<progress value="70" max="100">70%</progress> <progress></progress> <!-- indeterminado -->
<meter>
Medición escalar.
Muestra un valor dentro de un rango conocido: disco duro, temperatura, puntuación. Atributos: value, min, max, low, high, optimum.
<meter value="0.7" min="0" max="1" low="0.2" high="0.8" optimum="0.9"> 70% de uso </meter>
<time>
Fecha/hora legible por máquina.
Representa una fecha/hora específica. El atributo datetime tiene el formato ISO 8601 para máquinas; el contenido es legible para humanos.
<time datetime="2024-03-15">15 de marzo de 2024</time> <time datetime="14:30">2:30 PM</time>
<data>
Valor legible por máquina.
Asocia un contenido con un valor legible por máquina. Similar a <time> pero para cualquier valor: IDs, códigos, etc.
<data value="3958">Camiseta XL</data> <data value="8972">Pantalón M</data>

Comentarios y Otros

<!-- comentarios -->
Comentario HTML.
No se renderiza en el navegador. Para notas del desarrollador, explicar código, o deshabilitar temporalmente elementos.
<!-- Este es un comentario --> <!-- TODO: completar esta sección --> <!-- <p>Este párrafo está deshabilitado</p> -->
<noscript>
Contenido sin JavaScript.
Muestra contenido alternativo cuando JavaScript está deshabilitado. También para SEO o fallback de <iframe>.
<noscript> <p>JavaScript está deshabilitado. Actívalo para usar esta página.</p> </noscript>
<template>
Plantilla de contenido.
Almacena contenido HTML que no se renderiza pero está disponible para clonar con JavaScript. Ideal para componentes dinámicos.
<template id="card-template"> <div class="card"> <h3></h3> <p></p> </div> </template>
<canvas>
Lienzo para gráficos dinámicos.
Área para dibujar gráficos 2D/3D con JavaScript (Canvas API o WebGL). Juegos, visualizaciones, editor de imágenes.
<canvas id="miCanvas" width="800" height="600"> Tu navegador no soporta canvas. </canvas>
<svg>
Gráficos vectoriales escalables.
Incrusta SVG para gráficos vectoriales: iconos, logos, ilustraciones, diagramas. Escalable sin pérdida de calidad.
<svg width="100" height="100" viewBox="0 0 100 100"> <circle cx="50" cy="50" r="40" fill="#7dd3fc"/> </svg>

Atributos Globales

class
Nombre de clase CSS.
Define una o más clases para aplicar estilos CSS o seleccionar con JavaScript. Se pueden asignar múltiples clases separadas por espacios.
<div class="container active dark"> Contenido estilizado </div>
id
Identificador único.
Identifica un elemento de forma única en la página. Un solo id por elemento. Usar para JavaScript, CSS y anclas.
<div id="main-content">...</div> <a href="#main-content">Ir al contenido</a>
style
Estilos CSS inline.
Aplica estilos CSS directamente al elemento. Para estilos dinámicos o puntuales. Preferir clases para mantenimiento.
<p style="color: #7dd3fc; font-size: 1.2rem;"> Texto estilizado inline </p>
title
Información emergente (tooltip).
Muestra un tooltip al pasar el cursor sobre el elemento. No reemplaza alt en imágenes.
<button title="Guardar documento"> 💾 Guardar </button>
lang
Idioma del contenido.
Define el idioma del contenido del elemento. Esencial para accesibilidad y SEO. Hereda a los hijos.
<p lang="en">This is English text</p> <p lang="fr">C'est du français</p>
hidden
Oculta el elemento.
Oculta el elemento del renderizado y accesibilidad. Equivalente a display: none. Toggle con JS para mostrar/ocultar.
<div hidden>Este contenido no se ve</div> <div hidden="until-found">Oculto hasta búsqueda</div>
tabindex
Orden de tabulación.
Controla el orden de foco con Tab. 0 = flujo natural, -1 = foco por JS pero no Tab, 1+ = prioridad (evitar).
<div tabindex="0">Foco con Tab</div> <div tabindex="-1">Foco solo por JS</div>
draggable
Elemento arrastrable.
Hace que un elemento sea arrastrable. Usar con eventos dragstart, dragover, drop.
<div draggable="true"> Arrástrame a otra lista </div>

Etiquetas Obsoletas

<font>
Cambiar fuente, color o tamaño (OBSOLETO).
No usar. Reemplazado por CSS: font-family, color, font-size. Presente en HTML 4, eliminado en HTML5.
<!-- ❌ NO USAR --> <font color="red" size="5">Texto</font> <!-- ✅ Usar CSS --> <p class="destacado">Texto</p>
<center>
Centrar contenido (OBSOLETO).
No usar. Reemplazado por CSS: text-align: center o margin: auto. Eliminado en HTML5.
<!-- ❌ NO USAR --> <center>Texto centrado</center> <!-- ✅ Usar CSS --> <p style="text-align: center">Texto centrado</p>
<big>
Aumentar tamaño de texto (OBSOLETO).
No usar. Reemplazado por CSS: font-size o em. Eliminado en HTML5.
<!-- ❌ NO USAR --> <big>Texto más grande</big> <!-- ✅ Usar CSS --> <p style="font-size: 1.5em">Texto más grande</p>
<strike>
Tachar texto (OBSOLETO).
No usar. Reemplazado por <del> (borrado semántico) o <s> (ya no relevante) según el contexto.
<!-- ❌ NO USAR --> <strike>Texto tachado</strike> <!-- ✅ Usar HTML5 --> <s>Texto tachado</s> o <del>Borrado</del>
