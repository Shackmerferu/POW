1. Qué es Bootstrap

Bootstrap es un framework de front-end (CSS + JavaScript) que provee un sistema de rejilla, componentes ya estilizados y cientos de clases utilitarias. La idea central es componer la interfaz con clases en el HTML en lugar de escribir todo el CSS desde cero.

CSS puro Bootstrap
.contenedor { max-width: 960px; margin: 0 auto; } <div class="container">
.col { width: 33.33%; padding: 0 12px; } <div class="col-md-4">
.boton { background: #0d6efd; color: #fff; padding: .375rem .75rem; } <button class="btn btn-primary">
.texto { font-weight: 700; text-align: center; } <p class="fw-bold text-center">
@media (min-width: 768px) { .menu { display: flex; } } <div class="d-none d-md-flex">

Características principales

  • Mobile-first: los estilos base son para móvil y los breakpoints (sm, md, lg, xl, xxl) agregan comportamiento hacia arriba.
  • Grid de 12 columnas basado en Flexbox, con gutters y offsets.
  • Componentes: navbar, cards, modals, alerts, formularios, tablas, etc.
  • Utilidades: espaciado, color, tipografía, flex, display, bordes, sombras.
  • JavaScript propio (vanilla), sin jQuery. Usa Popper para dropdowns, tooltips y popovers.
  • Personalizable con variables CSS en tiempo de ejecución y con Sass en tiempo de compilación.

Ventajas y límites

Ventajas Límites / cuidados
Desarrollo rápido y consistente. Páginas clonadas si no se personaliza.
Responsive resuelto con clases. HTML con muchas clases, a veces difícil de leer.
Documentación extensa y comunidad grande. Peso extra si se usa el CSS completo.
Accesibilidad y estados ya contemplados. Para diseños muy a medida conviene Sass o CSS propio.
Compatible con cualquier backend (PHP, Node, etc.). No es un framework de lógica: solo interfaz.

Idea clave: Bootstrap no reemplaza a CSS; lo usa por debajo. Saber CSS permite entender qué hace cada clase, sobrescribirla y decidir cuándo conviene escribir estilos propios.

2. Inclusión y archivos

Bootstrap requiere obligatoriamente la etiqueta viewport para que el diseño responsive funcione:

<meta name="viewport" content="width=device-width, initial-scale=1">

Opción 1: CDN (la más rápida)

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi página</title>
  <!-- CSS de Bootstrap -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <h1 class="text-primary">Hola Bootstrap</h1>

  <!-- JS de Bootstrap (incluye Popper) -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

Opción 2: descarga local

Se descarga el ZIP desde el sitio oficial y se copian las carpetas css/ y js/ al proyecto:

<link rel="stylesheet" href="css/bootstrap.min.css">
<script src="js/bootstrap.bundle.min.js"></script>

Opción 3: npm (proyectos con build)

npm install bootstrap

import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';

Archivos que trae Bootstrap

Archivo Contenido / uso
bootstrap.css Todo el framework sin minificar (para depurar).
bootstrap.min.css Todo el framework minificado (producción).
bootstrap-grid.css Solo grid y utilidades de layout.
bootstrap-utilities.css Solo utilidades (colores, espaciado, etc.).
bootstrap.bundle.min.js JS + Popper. Recomendado.
bootstrap.min.js JS sin Popper (requiere cargarlo aparte).

Si se usa bootstrap.min.js y no se carga Popper, los dropdowns, tooltips y popovers no funcionan. Para empezar conviene siempre bootstrap.bundle.min.js.

Orden de carga

  • El CSS de Bootstrap va en el <head>, antes del CSS propio (para poder sobrescribirlo).
  • El JS va al final del <body> o con defer en el <head>.
  • No cargar Bootstrap dos veces (CDN + local): duplica peso y puede generar conflictos.

3. Variables y personalización

Bootstrap 5 expone gran parte de su diseño como variables CSS en :root, con el prefijo --bs-. Permiten cambiar colores, tipografía o bordes sin recompilar.

Variables más usadas

Variable Valor por defecto Controla
--bs-primary #0d6efd Color primario (texto, bordes, algunos fondos).
--bs-primary-rgb 13, 110, 253 Mismo color para usar con rgb() / rgba().
--bs-body-bg #fff Fondo del body.
--bs-body-color #212529 Color de texto base.
--bs-body-font-family stack system-ui Familia tipográfica base.
--bs-body-font-size 1rem Tamaño de texto base.
--bs-body-line-height 1.5 Altura de línea base.
--bs-border-color #dee2e6 Color de bordes por defecto.
--bs-border-radius .375rem Radio de esquinas por defecto.
--bs-link-color #0d6efd Color de enlaces.
--bs-link-hover-color #0a58ca Color de enlaces en hover.
--bs-font-monospace SFMono-Regular, ... Familia monoespaciada.

Cambiar variables en tiempo de ejecución

:root {
  --bs-body-font-family: "Inter", system-ui, sans-serif;
  --bs-body-font-size: 1.05rem;
  --bs-body-line-height: 1.65;
  --bs-primary: #6f42c1;
  --bs-primary-rgb: 111, 66, 193;
  --bs-border-radius: .75rem;
}

/* También se pueden redefinir en un componente */
.mi-panel {
  --bs-border-color: #6f42c1;
  border: 1px solid var(--bs-border-color);
}

Ojo: cambiar --bs-primary no repinta .btn-primary ni .text-primary, porque esos colores se compilan con Sass. Las variables en runtime solo afectan a las reglas que las consumen (body, enlaces, bordes, etc.). Para cambiar la paleta completa hay que recompilar con Sass (ver sección 24).

Personalización rápida con Sass

npm install bootstrap sass

// custom.scss
$primary: #6f42c1;
$font-family-sans-serif: "Inter", system-ui, sans-serif;
$font-size-base: 1.05rem;
$border-radius: .75rem;

@import "bootstrap/scss/bootstrap";

sass scss/custom.scss css/custom.css --watch

Las variables de Sass se declaran antes del @import; si se declaran después, no tienen efecto.

4. Contenedores y Grid

El sistema de rejilla se apoya en tres piezas: contenedor (centra y limita el ancho), fila (.row) y columnas (.col).

<div class="container">
  <div class="row">
    <div class="col-12 col-md-6 col-lg-4">Columna 1</div>
    <div class="col-12 col-md-6 col-lg-4">Columna 2</div>
    <div class="col-12 col-md-12 col-lg-4">Columna 3</div>
  </div>
</div>
  • El .container aplica padding lateral y centra el contenido.
  • El .row usa márgenes negativos para compensar el padding de las columnas (gutter).
  • Cada columna tiene padding horizontal: por eso el contenido nunca va directo dentro de .row.
  • Las columnas suman 12 por fila. Si se pasa, la columna baja a la línea siguiente.

Contenedores

Clase Comportamiento Ancho máximo
.container Ancho fijo según breakpoint, centrado. 540 / 720 / 960 / 1140 / 1320 px
.container-sm 100% hasta sm; luego ancho fijo. 540 px en adelante
.container-md 100% hasta md; luego ancho fijo. 720 px en adelante
.container-lg 100% hasta lg; luego ancho fijo. 960 px en adelante
.container-xl 100% hasta xl; luego ancho fijo. 1140 px en adelante
.container-xxl 100% hasta xxl; luego ancho fijo. 1320 px en adelante
.container-fluid Siempre 100% del ancho disponible. Sin límite

Clases de columna

Clase Efecto
.col Reparte el espacio en partes iguales entre las columnas de la fila.
.col-6 Ocupa 6 de 12 columnas (50%) desde móvil.
.col-md-4 Ocupa 4 de 12 (33%) desde md; antes se comporta como .col-12.
.col-auto Ancho según el contenido.
.col-md-auto Ancho según contenido desde md.
.row-cols-1 … .row-cols-6 Define cuántas columnas por fila (el hijo no necesita .col-*).
.row-cols-md-3 3 columnas por fila desde md.

Auto-layout y anchos iguales

<!-- Todas las columnas miden lo mismo -->
<div class="row">
  <div class="col">1</div>
  <div class="col">2</div>
  <div class="col">3</div>
</div>

<!-- Una columna fija al contenido y otra que ocupa el resto -->
<div class="row">
  <div class="col-auto">Etiqueta</div>
  <div class="col">Contenido flexible</div>
</div>

Gutters (separación entre columnas)

Por defecto el gutter es 1.5rem (24 px). Se controla con g-*, gx-* (horizontal) y gy-* (vertical), con valores de 0 a 5.

<div class="row g-4">        <!-- 1.5rem en ambos ejes -->
  <div class="col-md-6">...</div>
  <div class="col-md-6">...</div>
</div>

<div class="row gx-2 gy-4"> <!-- horizontal .5rem, vertical 1.5rem -->
  <div class="col-6">...</div>
</div>

<div class="row g-0">        <!-- sin separación -->
  <div class="col-6">...</div>
</div>

Offset, orden y alineación

<!-- Desplazar 2 columnas -->
<div class="col-md-4 offset-md-2">...</div>

<!-- Orden visual -->
<div class="col order-2">Primera en el HTML, segunda visualmente</div>
<div class="col order-1">Segunda en el HTML, primera visualmente</div>
<div class="col order-md-last">Al final desde md</div>

<!-- Alineación vertical dentro de la fila -->
<div class="row align-items-center">
  <div class="col">...</div>
  <div class="col align-self-end">...</div>
</div>

<!-- Alineación horizontal -->
<div class="row justify-content-center">
  <div class="col-md-6">...</div>
</div>

Anidamiento

Una columna puede contener otra .row con sus propias columnas. La fila interna vuelve a dividir en 12 el ancho de la columna padre.

<div class="row">
  <div class="col-md-6">
    <div class="row">
      <div class="col-6">Mitad izquierda</div>
      <div class="col-6">Mitad derecha</div>
    </div>
  </div>
</div>

Regla de oro: .container → .row → .col. No poner columnas sin fila, ni contenido directo dentro de una fila. Si una columna no tiene ancho definido y es la única, usar .col-12.

5. Tipografía

Bootstrap define una base tipográfica directamente en body. Todo lo demás (títulos, párrafos, listas, citas) hereda de ahí y se ajusta con clases utilitarias.

body {
  font-family: var(--bs-body-font-family);  /* system-ui, -apple-system, ... */
  font-size: var(--bs-body-font-size);      /* 1rem = 16px */
  font-weight: var(--bs-body-font-weight);  /* 400 */
  line-height: var(--bs-body-line-height);  /* 1.5 */
  color: var(--bs-body-color);
  background-color: var(--bs-body-bg);
}

Variables tipográficas

Variable Valor por defecto Función
--bs-font-sans-serif system-ui, -apple-system, "Segoe UI", Roboto, ... Stack de fuentes sin serifa.
--bs-font-monospace SFMono-Regular, Menlo, Monaco, Consolas, ... Stack monoespaciado.
--bs-body-font-family var(--bs-font-sans-serif) Familia aplicada al body.
--bs-body-font-size 1rem Tamaño base; el resto de la escala está en rem.
--bs-body-font-weight 400 Peso base del texto.
--bs-body-line-height 1.5 Interlineado base.
--bs-body-color #212529 Color de texto base.
--bs-heading-color inherit Color de los títulos.
--bs-link-color #0d6efd Color de enlaces.
--bs-link-hover-color #0a58ca Color de enlaces en hover.

Tipografía base personalizada

:root {
  --bs-body-font-family: "Inter", system-ui, sans-serif;
  --bs-body-font-size: 1.05rem;
  --bs-body-font-weight: 400;
  --bs-body-line-height: 1.65;
  --bs-heading-color: #0f4c81;
}

$font-size-base: 1.05rem;
$line-height-base: 1.65;
$headings-font-family: "Poppins", sans-serif;
$headings-font-weight: 600;
$headings-color: #0f4c81;

@import "bootstrap/scss/bootstrap";

Cargar una tipografía web (Google Fonts)

Bootstrap no incluye fuentes: usa el stack del sistema. Para usar una fuente propia hay que cargarla y luego indicarla en la variable correspondiente.

<!-- En el <head>, antes del CSS de Bootstrap -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Poppins:wght@600;700&display=swap" rel="stylesheet">

:root {
  --bs-body-font-family: "Inter", system-ui, -apple-system, "Segoe UI", sans-serif;
  --bs-heading-font-family: "Poppins", "Inter", sans-serif;
}

/* Bootstrap no tiene una variable para la familia de los títulos:
   se aplica con una regla propia. */
h1, h2, h3, h4, h5, h6,
.h1, .h2, .h3, .h4, .h5, .h6 {
  font-family: var(--bs-heading-font-family);
}
  • Mantener siempre fuentes de respaldo (system-ui, sans-serif) por si la web font no carga.
  • display=swap evita que el texto quede invisible mientras se descarga la fuente.
  • Cargar solo los pesos que se usan (cada peso extra suma peso a la página).
  • Alternativa recomendada en producción: descargar la fuente y servirla con @font-face y font-display: swap.
@font-face {
  font-family: "Inter";
  src: url("../fonts/Inter-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

11. Responsive y breakpoints

Bootstrap es mobile-first: lo que se escribe sin infijo vale para todos los tamaños; los infijos sm, md, lg, xl y xxl aplican desde ese ancho hacia arriba.

Breakpoint Infijo Ancho mínimo Ejemplo
Extra pequeño (móvil) ninguno < 576px .d-none, .col-12, .p-2
Pequeño sm ≥ 576px .d-sm-block, .col-sm-6
Mediano (tablet) md ≥ 768px .text-md-center, .mt-md-5
Grande (escritorio) lg ≥ 992px .d-lg-flex, .col-lg-4
Extra grande xl ≥ 1200px .justify-content-xl-between
Extra extra grande xxl ≥ 1400px .col-xxl-2

Sintaxis del infijo

  <div class="col-12 col-md-6 col-lg-3">...</div>
  <div class="col-12 col-md-6 col-lg-3">...</div>
</div>

<!-- Texto centrado en móvil, alineado a la izquierda desde md -->

  backdrop: 'static',
  keyboard: false
});
miModal.show();
miModal.hide();
miModal.toggle();

// Otros componentes

Eventos

Cada componente emite eventos antes y después de la transición. Se escuchan sobre el elemento:

const modalEl = document.getElementById('modalEjemplo');

modalEl.addEventListener('show.bs.modal', () => {
  console.log('antes de mostrarse');
});

modalEl.addEventListener('shown.bs.modal', () => {
  // el modal ya es visible: buen momento para enfocar un input
  modalEl.querySelector('input')?.focus();
});

modalEl.addEventListener('hidden.bs.modal', () => {
  console.log('ya se cerró');
});

Patrón: show / shown / hide / hidden + .bs. + componente (por ejemplo shown.bs.dropdown, slide.bs.carousel).

Bootstrap 5.3 incorpora data-bs-theme. Al aplicarlo, cambian las variables de color de ese subárbol.

  ...
</html>

<!-- Solo un componente -->
<div data-bs-theme="dark" class="p-3 bg-body rounded">
  Contenido en modo oscuro.
</div>

<!-- Forzar claro dentro de una zona oscura -->

Alternar con JavaScript

const html = document.documentElement;

function aplicarTema(tema) {
  html.setAttribute('data-bs-theme', tema);
  localStorage.setItem('tema', tema);
}

aplicarTema(localStorage.getItem('tema') || 'light');

document.getElementById('btnTema').addEventListener('click', () => {
  const actual = html.getAttribute('data-bs-theme');
  aplicarTema(actual === 'dark' ? 'light' : 'dark');
});

Colores adaptativos

En lugar de… Usar…
.bg-white / .bg-light .bg-body, .bg-body-secondary, .bg-body-tertiary
.text-black / .text-muted .text-body, .text-body-secondary, .text-body-emphasis
.border con color fijo .border (usa --bs-border-color)
.navbar-dark data-bs-theme="dark" en la navbar

Las utilidades .bg-primary, .text-danger, etc. mantienen su color en ambos modos. Para que se adapten, usar las variantes -subtle y -emphasis o definir variables propias.

24. Personalización avanzada con Sass

La personalización “de verdad” se hace recompilando Bootstrap con Sass. Permite cambiar la paleta completa (incluidos .btn-*, .text-*, .alert-*), la tipografía, los radios, los breakpoints y hasta generar utilidades nuevas.

Instalación

  "scripts": {

    "primary":   #0d6efd,

    "success":   #198754,

@import "bootstrap/scss/bootstrap";

También se puede escribir solo el mapa completo con los 10 colores, sin map-merge. La ventaja de map-merge es que deja explícito qué se agrega y qué se conserva.

Al recompilar se generan automáticamente .text-brand, .bg-brand, .btn-brand, .alert-brand, .border-brand, etc.

Utilities API

Permite crear utilidades propias sin escribir CSS a mano:

@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/utilities";

$utilities: map-merge(
  $utilities,
  (
    "cursor": (
      property: cursor,
      class: cursor,
      values: auto pointer grab not-allowed
    ),
    "opacity": (
      property: opacity,
      values: (0: 0, 25: .25, 50: .5, 75: .75, 100: 1)
    )
  )
);

@import "bootstrap/scss/bootstrap";

Luego se usa .cursor-pointer, .cursor-grab, etc. Es la forma recomendada de extender Bootstrap sin pelear con la especificidad.

Qué conviene personalizar y qué no

Conviene Sass Conviene CSS propio
Paleta de colores de tema. Ajustes puntuales de un componente.
Tipografía base y de títulos. Estilos de un bloque muy específico.
Radios, sombras, espaciados globales. Animaciones propias.
Breakpoints y anchos de contenedor. Integración con un diseño externo.

25. Errores típicos y checklist

Errores frecuentes

Error Por qué falla Solución
Falta el meta viewport El responsive no se activa en móvil. Agregar <meta name="viewport" content="width=device-width, initial-scale=1">.
Usar .row sin .col El contenido queda con márgenes negativos. Siempre .row → .col-*.
Poner contenido directo en .row Rompe el gutter y el layout. Envolver en una columna.
Columnas que suman más de 12 La última baja de línea. Revisar la suma por breakpoint.
Mezclar clases de Bootstrap 4 Ya no existen en v5. .ml-*→.ms-*, .float-left→.float-start, .text-left→.text-start, .form-group→.mb-3, .btn-block→.w-100, .no-gutters→.g-0.
Cargar bootstrap.min.js sin Popper Dropdowns, tooltips y popovers no funcionan. Usar bootstrap.bundle.min.js.
No inicializar tooltips/popovers Son opt-in. Inicializarlos con JS.
JS ejecutado antes del DOM No encuentra los elementos. Script al final o DOMContentLoaded.
CSS propio antes de Bootstrap Bootstrap pisa los estilos propios. Cargar Bootstrap primero.
Abusar de !important Dificulta el mantenimiento. Subir especificidad o usar una clase propia.
Usar .text-muted Deprecado en 5.3. .text-body-secondary.
Usar .navbar-dark Deprecado en 5.3. data-bs-theme="dark".
Modal dentro de un ancestro con transform El position: fixed se rompe. Mover el modal al final del body.
Ancho de progress por clase No existe .w-60. Usar style="width: 60%".
Imágenes sin alt Problema de accesibilidad. Agregar texto alternativo.
No cargar Bootstrap Icons Los <i class="bi ..."> no muestran nada. Incluir el CSS de iconos.

Checklist antes de entregar

  • Viewport presente y CSS/JS cargados una sola vez.
  • Un <h1> por página y jerarquía de títulos correcta.
  • Todas las imágenes con alt; formularios con label.
  • Grilla revisada en móvil, tablet y escritorio.
  • Navbar colapsable probada en pantalla chica.
  • Tablas anchas dentro de .table-responsive.
  • Contraste de color suficiente; foco visible.
  • Sin clases de Bootstrap 4 ni estilos inline innecesarios.
  • Componentes JS inicializados y probados (modal, dropdown, tooltip).
  • Consola del navegador sin errores 404.
  • Impresión revisada si el trabajo se entrega en PDF.
