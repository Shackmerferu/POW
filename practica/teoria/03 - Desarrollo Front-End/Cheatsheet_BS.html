Cheatsheet Bootstrap 5

Componentes listos para copiar y pegar en cualquier parcial. Cada bloque muestra el resultado en vivo arriba y el código abajo, con botón de copia. No hace falta pensar la sintaxis: buscá el componente, copiá y adaptá ids/textos.

0 · Arranque: el esqueleto mínimo

Si el parcial pide "un archivo con Bootstrap local", usá la segunda variante. Si permite internet, la primera con CDN.

Código → no hay demo visible.
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi página</title>

  <!-- OPCIÓN A: por CDN (pide internet) -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>

  <!-- contenido -->

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.0.2/dist/js/bootstrap.bundle.min.js"></script>
  <script src="js/app.js"></script>   <!-- tu JS siempre después -->
</body>
</html>
Variante con librería LOCAL (autocontenida, funciona sin internet).
<!-- Estructura de carpetas:
     mi-carpeta/
       index.html
       lib/bootstrap/css/bootstrap.min.css
       lib/bootstrap/js/bootstrap.bundle.min.js
       css/styles.css
       js/app.js -->

<link rel="stylesheet" href="lib/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/styles.css">   <!-- SIEMPRE después de Bootstrap -->

<script src="lib/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/app.js"></script>
Regla Oro: tu styles.css y tu app.js SIEMPRE después de los de Bootstrap, para poder pisar estilos y tener las constantes cargadas.

1 · Grilla (grid)

container → row → col. Los números en barritos: hasta 12 por fila. col-md-* apila en celulares y separa en tablet/PC.

GRID BÁSICO RESPONSIVO
col-12 / md-6 / xl-4
col-12 / md-6 / xl-4
col-12 / md-6 / xl-4
<div class="container">             <!-- ancho centrado (o container-fluid = 100%) -->
  <div class="row g-3">             <!-- g-3 = gutter (separación) entre columnas -->
    <div class="col-12 col-md-6 col-xl-4">Columna 1</div>
    <div class="col-12 col-md-6 col-xl-4">Columna 2</div>
    <div class="col-12 col-md-6 col-xl-4">Columna 3</div>
  </div>
</div>

<!-- Anchos:  col-1 … col-12  |  auto: col / col-md-auto
     Breakpoints:  xs  <576  |  sm ≥576  |  md ≥768  |  lg ≥992  |  xl ≥1200 -->
CENTRAR, OFFSET, ORDEN
2 mitades centradas
2 mitades centradas
<!-- Centrar columnas -->
<div class="row justify-content-center">
  <div class="col-6">...</div>
  <div class="col-6">...</div>
</div>

<!-- Desplazar 2 columnas a la derecha -->
<div class="col-md-6 offset-md-2">...</div>

<!-- Columna de ancho automático + alinear vertical -->
<div class="row align-items-center">
  <div class="col-auto"> ... </div>
</div>

9 · Formularios y validación nativa

FORM COMPLETO
El usuario debe tener al menos 3 caracteres.
Ingresá la contraseña.
Elegí una ciudad.
Debés aceptar.
<form id="form-datos" class="needs-validation" novalidate>
  <div class="mb-3">
    <label for="usuario" class="form-label">Usuario</label>
    <input type="text" id="usuario" name="usuario" class="form-control" required minlength="3">
    <div class="invalid-feedback">Mensaje si falla la validación</div>
  </div>

  <div class="mb-3">
    <label for="ciudad" class="form-label">Ciudad</label>
    <select class="form-select" id="ciudad" required>
      <option value="">Seleccioná una ciudad</option>
    </select>
    <div class="invalid-feedback">Elegí una ciudad</div>
  </div>

  <div class="mb-3 form-check">
    <input type="checkbox" class="form-check-input" id="terminos" required>
    <label class="form-check-label" for="terminos">Acepto los términos</label>
    <div class="invalid-feedback">Debés aceptar</div>
  </div>

  <div class="form-check">
    <input class="form-check-input" type="radio" name="tipo" id="t1" value="a" checked>
    <label class="form-check-label" for="t1">Empresa</label>
  </div>

  <button type="submit" class="btn btn-success">Enviar</button>
</form>

<!-- Atributos de validación: required, minlength, maxlength, min/max, step, type -->
Patrón validación custom (JS): con novalidate el formulario pinta rojo recién cuando JS agrega was-validated. Ver #RECETA-VALIDACION en el cheatsheet JS.

15 · Modal (ventana emergente)

BOTÓN QUE ABRE UN MODAL 
<!-- 1) Botón que lo abre (data-bs-target = id del modal) -->
<button class="btn btn-warning" data-bs-toggle="modal" data-bs-target="#modalNuevo">+ Nuevo</button>

<!-- 2) El modal (va al final del body) -->
<div class="modal fade" id="modalNuevo" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog modal-lg modal-dialog-centered modal-dialog-scrollable">
    <div class="modal-content">

      <div class="modal-header">
        <h5 class="modal-title">Nuevo termo</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Cerrar"></button>
      </div>

      <div class="modal-body">
        <form id="form-termo" enctype="multipart/form-data" novalidate>
          <div class="mb-3">
            <label class="form-label">Título</label>
            <input type="text" name="titulo" class="form-control" required>
          </div>
          <div class="mb-3">
            <label class="form-label">Imagen</label>
            <input type="file" name="imagen" class="form-control" accept="image/*" required>
          </div>
        </form>
      </div>

      <div class="modal-footer">
        <button type="button" class="btn btn-outline-secondary" data-bs-dismiss="modal">Cancelar</button>
        <button type="submit" form="form-termo" class="btn btn-success">Guardar</button>
      </div>

    </div>
  </div>
</div>

<!-- tamaños:  modal-sm  | (nada) | modal-lg | modal-xl
     variantes: modal-dialog-centered (vert. centrado)
                modal-dialog-scrollable (scroll interno) -->
JS: abrir/cerrar con código: bootstrap.Modal.getOrCreateInstance(el).show() / .hide() · escuchar cierre: el.addEventListener("hidden.bs.modal", fn).
