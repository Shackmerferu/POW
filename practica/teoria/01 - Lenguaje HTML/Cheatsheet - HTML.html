1. Estructura mínima de un documento

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Título de la página</title>
</head>
<body>
  <h1>Hola mundo</h1>
  <p>Contenido del documento.</p>
</body>
</html>
Parte Para qué sirve
<!DOCTYPE html> Declara el tipo de documento. En HTML5 es única y no es una etiqueta HTML (viene de SGML).
<html> Elemento raíz. lang="es" indica el idioma.
<head> Metainformación: no se muestra en el cuerpo.
<body> Contenido visible de la página.
<meta charset="UTF-8"> Codificación de caracteres. En HTML5, UTF-8 es lo esperado.
<title> Título en la pestaña y en los resultados de búsqueda.

HTML no respeta los espacios múltiples ni los saltos de línea del código: todo se interpreta como un único espacio. El navegador decide dónde cortar la línea. Para saltos explícitos se usa <br>; para párrafos, <p>.

DOCTYPE en HTML 4 (solo como referencia histórica)

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.0//EN">              <!-- Strict -->
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.0 Transitional//EN"> <!-- Loose -->
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.0 Frameset//EN">     <!-- Frameset -->

2. Cabecera: title, meta, link

<head>
  <title>Mi sitio</title>

  <meta charset="UTF-8">
  <meta name="author" content="Nombre Apellido">
  <meta name="description" content="Descripción breve de la página">
  <meta name="keywords" content="html, css, web, facultad">
  <meta name="generator" content="Visual Studio Code">

  <!-- Redirigir a otra URL a los 5 segundos -->
  <meta http-equiv="Refresh" content="5; URL=https://www.example.com">

  <!-- Vincular una hoja de estilos -->
  <link rel="stylesheet" href="estilos.css" type="text/css" media="screen">
</head>
meta name Uso
author Autor de la página.
description Descripción; la usan los buscadores.
keywords Palabras clave separadas por comas.
generator Programa con el que se creó la página.
classification Clasificación temática.
meta http-equiv Uso
Refresh Recargar la página o redirigir (content="5; URL=...").
expires Fecha de vencimiento del contenido.

Atributos de link: rel="stylesheet", type="text/css", href, media (screen, print, projection, aural, braille, tty, tv, all), title (estilo preferido/alterno).

3. Texto y formato

Encabezados y párrafos

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Sección</h3>
<h4>Subsección</h4>
<h5>Detalle</h5>
<h6>Mínimo</h6>

<p>Un párrafo de texto.</p>
<p>Otro párrafo.<br>Con un salto de línea.</p>

Usar un solo <h1> por página y no saltear niveles (h2 → h4) por estética: la jerarquía es semántica.

Formato de texto

Etiqueta Efecto Nota
<strong> Importancia (negrita) Semántica.
<b> Negrita visual Sin importancia semántica.
<em> Énfasis (itálica) Semántica.
<i> Itálica visual Sin énfasis semántico.
<u> Subrayado Puede confundirse con un enlace.
<s> Tachado —
<mark> Texto resaltado HTML5.
<small> Texto pequeño Letra chica, comentarios.
<sub> / <sup> Subíndice / superíndice H<sub>2</sub>O, x<sup>2</sup>.
<code> Código Fuente monoespaciada.
<pre> Texto preformateado Respeta espacios y saltos.
<kbd> Tecla Ctrl + S.
<abbr title="..."> Abreviatura Muestra el significado al pasar el mouse.
<blockquote> Cita en bloque cite para la fuente.
<q> Cita en línea —
<hr> Línea horizontal Separador temático.
<br> Salto de línea Elemento vacío. 
<p>El <strong>parcial</strong> es <em>teórico-práctico</em>.</p>
<p>Fórmula: H<sub>2</sub>O — Potencia: x<sup>2</sup></p>
<pre>
  Este texto
    conserva   los espacios
</pre>
<blockquote cite="https://www.w3.org/">
  La Web es para todos.
</blockquote>

Elementos vacíos (sin cierre)

<br>, <hr>, <img>, <input>, <meta>, <link>, <source>, <track>, <area>, <base>, <col>, <embed>, <wbr>.

4. Listas

Ordenada

<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
  <li>Tercer paso</li>
</ol>

<ol start="3" type="A">
  <li>Empieza en C</li>
  <li>Sigue D</li>
</ol>

No ordenada

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

De definiciones

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado para estructurar páginas web.</dd>

  <dt>CSS</dt>
  <dd>Lenguaje de hojas de estilo para la presentación.</dd>
</dl>

Anidadas

<ul>
  <li>Front-end
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Back-end</li>
</ul>
Etiqueta Significado
<ol> Lista ordenada (numerada).
<ul> Lista no ordenada (viñetas).
<li> Ítem de lista.
<dl> Lista de definiciones.
<dt> Término.
<dd> Definición del término.

Atributos útiles de ol: type (1, A, a, I, i), start, reversed.

5. Enlaces

<!-- A otra página del mismo sitio (ruta relativa) -->
<a href="contacto.html">Contacto</a>

<!-- A un sitio externo (ruta absoluta) -->
<a href="https://www.w3.org/" target="_blank" rel="noopener">W3C</a>

<!-- Ancla dentro del mismo documento -->
<a href="#seccion-2">Ir a la sección 2</a>
<h2 id="seccion-2">Sección 2</h2>

<!-- Ancla en otro documento -->
<a href="apuntes.html#tablas">Tablas de apuntes</a>

<!-- Correo -->
<a href="mailto:usuario@example.com">Enviar mail</a>
<a href="mailto:usuario@example.com?subject=Consulta">Consulta</a>

<!-- Teléfono -->
<a href="tel:+542302123456">Llamar</a>

<!-- Descarga -->
<a href="archivo.pdf" download>Descargar PDF</a>
Tipo de ruta Ejemplo Cuándo usarla
Relativa img/logo.png, ../index.html Dentro del mismo sitio.
Absoluta https://sitio.com/pagina Fuera del sitio.
Raíz /css/estilos.css Desde la raíz del servidor.
Ancla #id Dentro de la misma página.

target="_blank" abre en otra pestaña. Conviene acompañarlo con rel="noopener" por seguridad.

Estados de un enlace (se estilan con CSS): :link (no visitado), :visited (visitado), :hover (mouse encima), :active (al hacer clic), :focus (teclado).

6. Imágenes y figure

<img src="img/foto.jpg"
     alt="Descripción de la imagen"
     width="320"
     height="240"
     title="Texto al pasar el mouse"
     loading="lazy">

<figure>
  <img src="img/grafico.png" alt="Evolución de ventas 2025">
  <figcaption>Figura 1. Ventas del último año.</figcaption>
</figure>
Atributo Para qué
src Ruta de la imagen.
alt Texto alternativo (obligatorio por accesibilidad).
width / height Dimensiones; evitan saltos de layout.
title Tooltip.
loading="lazy" Carga diferida.
srcset / sizes Imágenes adaptativas.

Formatos: JPG (fotos), PNG (transparencia), GIF (animación simple), SVG (vectores), WebP/AVIF (modernos, mejor compresión).

alt no es opcional: si la imagen es decorativa se usa alt=""; si transmite información, se describe brevemente.

7. Tablas

<table>
  <caption>Notas del parcial</caption>
  <thead>
    <tr>
      <th scope="col">Alumno</th>
      <th scope="col">Nota</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ana Gómez</td>
      <td>8</td>
    </tr>
    <tr>
      <td>Luis Pérez</td>
      <td>7</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Promedio</td>
      <td>7,5</td>
    </tr>
  </tfoot>
</table>
Etiqueta Función
<table> Contenedor de la tabla.
<caption> Título de la tabla.
<thead> Grupo de filas de encabezado.
<tbody> Cuerpo de la tabla.
<tfoot> Pie de la tabla.
<tr> Fila (table row).
<th> Celda de encabezado.
<td> Celda de datos.
<colgroup> / <col> Agrupar columnas para darles estilo.

colspan y rowspan

<table border="1">
  <tr>
    <td colspan="2">Ocupa 2 columnas</td>
    <td rowspan="2">Ocupa 2 filas</td>
  </tr>
  <tr>
    <td>Normal 1</td>
    <td>Normal 2</td>
  </tr>
</table>
  • colspan="n": la celda se expande n columnas.
  • rowspan="n": la celda se expande n filas.

Las tablas son para datos tabulados, no para diagramar la página. Para layout se usa CSS (Flexbox/Grid).

9. Formularios

Estructura

<form action="procesar.php" method="post" enctype="multipart/form-data">
  <fieldset>
    <legend>Datos personales</legend>

    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre" name="nombre"
           placeholder="Tu nombre" required autofocus>

    <label for="email">Correo:</label>
    <input type="email" id="email" name="email" required>

    <label for="edad">Edad:</label>
    <input type="number" id="edad" name="edad" min="1" max="120">

    <label for="clave">Clave:</label>
    <input type="password" id="clave" name="clave" minlength="8" required>

    <label for="fecha">Fecha:</label>
    <input type="date" id="fecha" name="fecha">

    <label for="archivo">Archivo:</label>
    <input type="file" id="archivo" name="archivo" accept="image/*">

    <label for="comentario">Comentario:</label>
    <textarea id="comentario" name="comentario" rows="4" cols="40"></textarea>

    <label for="pais">País:</label>
    <select id="pais" name="pais">
      <option value="">Seleccione...</option>
      <option value="ar">Argentina</option>
      <option value="br">Brasil</option>
    </select>

    <label>
      <input type="checkbox" name="acepto" value="1"> Acepto los términos
    </label>

    <p>Sexo:</p>
    <label><input type="radio" name="sexo" value="f"> Femenino</label>
    <label><input type="radio" name="sexo" value="m"> Masculino</label>

    <button type="submit">Enviar</button>
    <button type="reset">Limpiar</button>
  </fieldset>
</form>

Método Dónde van los datos Cuándo usarlo
GET En la URL (?clave=valor) Búsquedas, filtros; no para datos sensibles.
POST En el cuerpo de la petición Altas, login, datos sensibles o largos.

enctype:

Valor Uso
application/x-www-form-urlencoded Por defecto.
multipart/form-data Obligatorio para subir archivos.
text/plain Poco usado.

Tipo Uso

Atributo Función

Otros controles

  <option value="Chrome">
  <option value="Firefox">
  <option value="Edge">
</datalist>

10. HTML5 semántico

<body>
  <header>
    <h1>Mi sitio</h1>
    <nav>
      <ul>
        <li><a href="/">Inicio</a></li>
        <li><a href="/noticias">Noticias</a></li>
        <li><a href="/contacto">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <header>
        <h2>Título de la noticia</h2>
        <p><time datetime="2026-10-25">25/10/2026</time></p>
      </header>
      <section>
        <p>Cuerpo de la noticia...</p>
      </section>
    </article>

    <aside>
      <h2>Relacionado</h2>
      <ul><li><a href="#">Otra nota</a></li></ul>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 Mi sitio</p>
  </footer>
</body>
Etiqueta Significado
<header> Cabecera de la página o de una sección.
<nav> Bloque de navegación.
<main> Contenido principal (uno por página).
<section> Sección genérica con título.
<article> Contenido independiente y reutilizable (noticia, post, comentario).
<aside> Contenido tangencial (barra lateral, relacionados).
<footer> Pie de página o de sección.
<figure> Contenido autocontenido (imagen, gráfico, código).
<figcaption> Pie de la figura.
<details> / <summary> Bloque plegable y su título visible.
<mark> Texto resaltado.
<time> Fecha/hora legible por máquina (datetime).
<dialog> Cuadro de diálogo.
<address> Datos de contacto del autor.

Ventaja: el HTML semántico mejora accesibilidad, SEO y mantenimiento. Un <div> no dice nada; <nav> sí.

Ejemplo de details

<details>
  <summary>Ver respuesta</summary>
  <p>La respuesta correcta es la B.</p>
</details>

11. Multimedia, canvas y SVG

Video y audio

<video src="video.mp4" controls poster="portada.jpg"
       width="640" height="360" preload="metadata">
  <source src="video.webm" type="video/webm">
  <source src="video.mp4" type="video/mp4">
  Tu navegador no soporta video HTML5.
</video>

<audio src="audio.mp3" controls preload="metadata">
  <source src="audio.ogg" type="audio/ogg">
  <source src="audio.mp3" type="audio/mpeg">
  Tu navegador no soporta audio HTML5.
</audio>
Atributo Función
controls Muestra los controles.
autoplay Reproduce automáticamente (muchos navegadores lo bloquean).
loop Repite.
muted Silenciado.
preload none, metadata, auto.
poster Imagen previa al video.

Formatos: MP4/H.264 (video), WebM/OGG (video), MP3/AAC (audio), OGG (audio).

canvas

<canvas id="lienzo" width="200" height="100"
        style="border: 1px solid #ccc;">
  Tu navegador no soporta canvas.
</canvas>

<script>
  const c = document.getElementById("lienzo");
  const ctx = c.getContext("2d");

  ctx.fillStyle = "#FAA200";
  ctx.fillRect(0, 0, 150, 75);          // rectángulo
  ctx.beginPath();
  ctx.arc(95, 50, 40, 0, 2 * Math.PI);  // círculo
  ctx.stroke();
  ctx.font = "20px Arial";
  ctx.fillText("Hola", 10, 30);
</script>
  • <canvas> es solo un contenedor: sin JavaScript no dibuja nada.
  • getContext("2d") da acceso a la API de dibujo.
  • Métodos: fillRect, strokeRect, moveTo, lineTo, arc, fillText, strokeText, drawImage, createLinearGradient, createRadialGradient.

SVG

<svg width="300" height="200" viewBox="0 0 300 200">
  <circle cx="100" cy="100" r="60"
          fill="purple" stroke="lime" stroke-width="5" />
  <rect x="180" y="60" width="80" height="80" fill="orange" />
</svg>
Canvas SVG
Mapa de píxeles. Vectores (XML).
Se dibuja con JS. Se describe con etiquetas.
Pierde calidad al escalar. No pierde calidad.
Mejor para animaciones y muchos objetos. Mejor para íconos y gráficos simples.

12. Atributos globales y accesibilidad

Atributo Función
id Identificador único en el documento.
class Uno o más estilos/clases separados por espacio.
style CSS en línea (evitar salvo casos puntuales).
title Información adicional (tooltip).
lang Idioma del contenido.
dir Dirección (ltr, rtl, auto).
hidden Oculta el elemento.
tabindex Orden de tabulación.
contenteditable Permite editar el contenido.
data-* Datos personalizados (data-id="5").
accesskey Atajo de teclado.

Buenas prácticas de accesibilidad

  1. alt descriptivo en imágenes informativas; alt="" en decorativas.
  2. Un solo <h1> y jerarquía de encabezados coherente.
  3. <label> asociado a cada control de formulario.
  4. No transmitir información solo por color.
  5. Enlaces con texto descriptivo (evitar “clic aquí”).
  6. Contraste suficiente entre texto y fondo.
  7. Tablas de datos con <th scope="col|row"> y <caption>.
  8. Navegación posible solo con teclado.

13. Almacenamiento del lado cliente

Tecnología Capacidad Duración Se envía al servidor
Cookie ~4 KB Según expires Sí, en cada petición.
localStorage ~5 MB Hasta que se borre No.
sessionStorage ~5 MB Hasta cerrar la pestaña No. 
// localStorage
localStorage.setItem("usuario", "ana");
const usuario = localStorage.getItem("usuario");
localStorage.removeItem("usuario");
localStorage.clear();

// sessionStorage
sessionStorage.setItem("paso", "2");

// Verificar soporte
if (typeof Storage !== "undefined") {
  // disponible
}

// Cookie básica
document.cookie = "usuario=ana; path=/; max-age=86400";
console.log(document.cookie);

Cookie (formato del encabezado):

Set-Cookie: NAME=VALUE; expires=DATE; path=PATH; domain=DOMAIN; secure
  • expires: fecha de vencimiento (formato Wdy, DD-Mon-YYYY HH:MM:SS GMT).
  • path / domain: dónde se envía.
  • secure: solo por HTTPS.

Offline: Service Workers (concepto)

  • Script que corre en segundo plano y actúa como proxy entre la app y la red.
  • Permite cachear recursos y funcionar sin conexión (base de las PWA).
  • Solo funciona en HTTPS o localhost.
  • Estrategias: cache-first, network-first, stale-while-revalidate.
if ("serviceWorker" in navigator) {
  navigator.serviceWorker.register("/sw.js");
}

14. Errores típicos y checklist

Error Causa Solución
La página se ve “rota” Etiquetas sin cerrar o mal anidadas. Cerrar en orden inverso al de apertura.
Tildes y ñ se ven mal Falta charset o el archivo no está en UTF-8. <meta charset="UTF-8"> y guardar en UTF-8.
El enlace no lleva a ningún lado href="#" o ruta incorrecta. Revisar ruta relativa/absoluta.
La imagen no carga Ruta o extensión incorrecta. Revisar src y mayúsculas/minúsculas.
El formulario no envía archivos Falta enctype. enctype="multipart/form-data".
El servidor no recibe un campo Falta name o está disabled. Agregar name; no usar disabled.
Los radio buttons se seleccionan todos Tienen distinto name. Mismo name para el grupo.
La tabla se descuadra colspan/rowspan mal calculados. Contar columnas por fila.
El CSS no se aplica Ruta del link incorrecta o caché. Revisar href; recargar con Ctrl+F5.
HTML inválido Atributos repetidos o etiquetas obsoletas. Validar en validator.w3.org.

Checklist antes de entregar

  • [ ] <!DOCTYPE html> y <html lang="es">.
  • [ ] <meta charset="UTF-8"> y <meta name="viewport">.
  • [ ] <title> descriptivo.
  • [ ] Un solo <h1>; jerarquía de encabezados correcta.
  • [ ] Todas las imágenes con alt.
  • [ ] Todos los controles con <label>.
  • [ ] Formularios con action, method y name en los campos.
  • [ ] Enlaces probados (internos y externos).
  • [ ] HTML validado.
  • [ ] Contenido estructurado con etiquetas semánticas, no solo <div>.

15. Plantilla completa

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="Página de ejemplo de la materia POW">
  <meta name="author" content="Nombre Apellido">
  <title>Mi página — POW</title>
  <link rel="stylesheet" href="css/estilos.css">
</head>
<body>

  <header>
    <h1>Mi sitio</h1>
    <nav>
      <ul>
        <li><a href="index.html">Inicio</a></li>
        <li><a href="noticias.html">Noticias</a></li>
        <li><a href="contacto.html">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <header>
        <h2>Primera noticia</h2>
        <p><time datetime="2026-10-25">25 de octubre de 2026</time></p>
      </header>

      <figure>
        <img src="img/foto.jpg" alt="Descripción de la foto" width="600">
        <figcaption>Epígrafe de la imagen.</figcaption>
      </figure>

      <p>Contenido de la noticia con <strong>texto importante</strong>
         y un <a href="https://www.w3.org/">enlace externo</a>.</p>

      <section>
        <h3>Datos</h3>
