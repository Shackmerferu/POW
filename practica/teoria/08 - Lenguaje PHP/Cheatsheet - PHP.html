1. Qué es PHP y cómo funciona

  • PHP es un lenguaje de script del lado del servidor. Otros similares: ASP, JSP, ColdFusion.
  • Los scripts PHP están incrustados en el documento HTML; el servidor los interpreta y ejecuta antes de servir la página.
  • El cliente no ve el código PHP, sino los resultados que produce.
  • Creado por Rasmus Lerdorf en 1994. PHP = Personal Hypertext Processor.
  • Es un módulo que se añade al servidor web (Apache, Nginx, etc.).
  • Versión actual de referencia: PHP 8.4 (nov. 2024).
Cliente (navegador)  --HTTP-->  Servidor web (Apache)  -->  Intérprete PHP
                                                                  |
Cliente (navegador)  <--HTML--  Servidor web  <-------------------+
Página HTML estática Página con PHP
El servidor entrega el archivo tal cual. El servidor ejecuta el PHP y entrega el HTML resultante.
El cliente ve todo el código. El cliente nunca ve el código PHP.

6. Variables y ámbito

  • Siempre empiezan con $.
  • El nombre es sensible a mayúsculas: $edad ≠ $Edad.
  • Comienzan con letra o guion bajo, seguido de letras, números o guiones bajos.
$valor = 5;
print "El valor es: " . $valor . "\n";
print "El valor es: $valor\n";   // solo con comillas dobles

Ámbito

Ámbito Dónde se define Comportamiento
Global Fuera de funciones Visible en el archivo, no dentro de funciones.
Local Dentro de una función Solo existe dentro de esa función.
Static Dentro de una función con static Conserva el valor entre llamadas. 
// static: conserva el valor
function myTest() {
  static $x = 0;
  echo $x;
  $x++;
}
myTest();  // 0
myTest();  // 1
myTest();  // 2

// global: hay que declararla
$x = 5;
$y = 10;

function sumar() {
  global $x, $y;
  $y = $x + $y;
}
sumar();
echo $y;   // 15

// $GLOBALS: acceso directo desde cualquier lado
$x = 5;
$y = 10;

function sumar2() {
  $GLOBALS['y'] = $GLOBALS['x'] + $GLOBALS['y'];
}
sumar2();
echo $y;   // 15

Variables variables ($$)

Convierten el contenido de una variable en el nombre de otra.

$mes = "enero";
$$mes = 1;      // crea $enero = 1
echo $enero;    // 1

10. Estructuras de control

if / elseif / else

if ($nota >= 8) {
  echo "Promociona";
} elseif ($nota >= 6) {
  echo "Regulariza";
} else {
  echo "Recursa";
}

while

$i = 1;
while ($i <= 10) {
  echo $i . "<br>\n";
  $i++;
}

do ... while

$i = 1;
do {
  echo $i;
  $i++;
} while ($i <= 10);

for

for ($i = 1; $i <= 10; $i++) {
  echo "$n x $i = " . ($n * $i) . "<br>\n";
}

foreach

foreach ($color as $valor) {
  print "Valor: $valor<BR>\n";
}

foreach ($color as $clave => $valor) {
  print "Clave: $clave; Valor: $valor<BR>\n";
}

switch

switch ($categoria) {
  case "promociones":
    echo "Ofertas";
    break;
  case "costas":
    echo "Costa";
    break;
  default:
    echo "General";
}

La expresión del case puede ser integer, float o string. No olvidar los break.

break / continue

foreach ($items as $item) {
  if ($item == "salir") break;      // corta el bucle
  if ($item == "ignorar") continue; // salta a la siguiente iteración
  echo $item;
}

11. Funciones

function suma($x, $y) {
  $s = $x + $y;
  return $s;
}

$a = 1;
$b = 2;
echo suma($a, $b);   // 3
Concepto Detalle
Parámetros Por defecto se pasan por valor.
Por referencia Se antepone & al parámetro.
Valores por defecto Deben ser los últimos parámetros.
Tipo de retorno Se declara después de los paréntesis: : int, : string, : iterable. 
// Paso por referencia
function incrementa(&$a) {
  $a = $a + 1;
}
$a = 1;
incrementa($a);
print $a;   // 2

// Argumentos por defecto
function muestranombre($nombre, $titulo = "Sr.") {
  print "Estimado $titulo $nombre:\n";
}
muestranombre("Fernández");            // Estimado Sr. Fernández
muestranombre("Fernández", "Prof.");   // Estimado Prof. Fernández

// Declaración de tipo (PHP 7+)
function sumar(int $a, int $b): int {
  return $a + $b;
}

15. Validación de datos

Toda la información proveniente de un formulario debe considerarse "contaminada" y validarse antes de procesarla.

Esquema

si se envió el formulario:
    validar datos
fin si

si se envió el formulario y no hay errores:
    procesar
si no:
    mostrar formulario (con valores por defecto o ya enviados)
fin si

Ejemplo

<?php
$errores = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {

  $nombre = trim($_POST['nombre'] ?? '');
  $email  = trim($_POST['email'] ?? '');
  $edad   = filter_input(INPUT_POST, 'edad', FILTER_VALIDATE_INT);

  if ($nombre === '') {
    $errores[] = "El nombre es obligatorio.";
  }

  if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    $errores[] = "El correo no es válido.";
  }

  if ($edad === false || $edad < 1 || $edad > 120) {
    $errores[] = "La edad debe estar entre 1 y 120.";
  }

  if (empty($errores)) {
    // procesar
  }
}
?>
Función Para qué
trim() Quita espacios al inicio y al final.
isset() ¿Existe y no es NULL?
empty() ¿No existe o es "vacío"?
filter_var() Valida emails, URLs, IPs, enteros.
filter_input() Obtiene y filtra una variable externa.
htmlspecialchars() Escapa caracteres para mostrar en HTML.
strip_tags() Elimina etiquetas HTML.
is_numeric() ¿Es un número?
preg_match() Valida con expresión regular.
strlen() Longitud.

17. Sesiones

Las sesiones permiten disponer de variables persistentes durante toda la conexión del usuario (carrito, login, preferencias).

Funciones

Función Qué hace
session_start() Inicia la sesión y asigna un ID único; si ya existe, carga las variables.
$_SESSION['clave'] = valor Registra una variable de sesión (reemplaza a session_register).
unset($_SESSION['clave']) Elimina una variable (reemplaza a session_unregister).
isset($_SESSION['clave']) Comprueba si existe (reemplaza a session_is_registered).
session_destroy() Cierra la sesión. 
<?php
session_start();

$_SESSION['usuario'] = "ana";

if (isset($_SESSION['usuario'])) {
  echo "Bienvenida " . $_SESSION['usuario'];
}

unset($_SESSION['usuario']);
session_destroy();
?>

Regla de oro: session_start() debe estar antes de cualquier salida HTML, en todas las páginas que usen la sesión.

Autenticación de usuarios

inicio
  ├── ¿sesión iniciada? --sí--> menú
  └── no
        ├── ¿formulario enviado? --sí--> ¿datos correctos?

        │                                   └── no --> mostrar error

  • Los usuarios autorizados se guardan en una tabla de la base de datos.
  • Las contraseñas se almacenan encriptadas (password_hash() / password_verify()).
  • Alternativa sin PHP: archivos .htaccess de Apache.

18. Cookies

Las sesiones mantienen los datos del lado del servidor; si se quieren mantener variables del lado del cliente, se usan cookies.

setcookie("nombre", $valor, $expiracion);

setcookie("persona", $nombre, time() + 86400 * 365);  // 1 año
setcookie("migalleta", "mivalor");                    // sesión del navegador
setcookie("cookie2", "mivalor2", time() + 3600);      // 1 hora
setcookie("otracookie", "valorfinal", time() + 3600, "/", ".midominio.com");

Leer

echo $_COOKIE["migalleta"];

Contador de visitas

if (isset($_COOKIE['webtaller'])) {
  $_COOKIE['webtaller']++;
  setcookie("webtaller", $_COOKIE['webtaller'], time() + 30 * 24 * 60 * 60);
} else {
  setcookie("webtaller", 1, time() + 30 * 24 * 60 * 60);
}

Borrar

unset($_COOKIE['webtaller']);
setcookie("webtaller", "");

La cookie no está disponible hasta que el usuario recargue la página. setcookie() también debe ir antes de cualquier salida HTML.

20. Programación Orientada a Objetos

PHP no fue un lenguaje OO hasta la versión 5.0. La POO crea objetos que contienen datos y funciones; la programación procedimental escribe funciones que operan sobre los datos.

Ventajas

  • Más rápida y fácil de ejecutar.
  • Estructura clara para los programas.
  • Código LIMPIO (DRY: Don't Repeat Yourself), más fácil de mantener, modificar y depurar.
  • Aplicaciones reutilizables con menos código.

Clase y objeto

class Fruit {
  public $name;
  public $color;

  function set_name($name) {
    $this->name = $name;
  }

  function get_name() {
    return $this->name;
  }
}

$apple = new Fruit();
$apple->set_name('Apple');
echo $apple->get_name();
Concepto Definición
Clase Plantilla / modelo (ej. Fruta, Auto).
Objeto Instancia concreta de una clase (ej. manzana, Ferrari).
Propiedad Variable de la clase.
Método Función de la clase.
$this Referencia al objeto actual; solo dentro de métodos.
new Crea una instancia.

Visibilidad

Modificador Acceso
public Desde cualquier lugar (predeterminado).
protected Desde la clase y sus clases derivadas.
private Solo desde la clase que lo definió. 
class Fruit {
  public $name;
  protected $color;
  private $weight;
}

$mango = new Fruit();
$mango->name   = 'Mango';    // OK
$mango->color  = 'Yellow';   // ERROR
$mango->weight = '300';      // ERROR

var equivale a public, pero está en desuso.

Constructor y destructor

class Fruit {
  public $name;
  public $color;

  function __construct($name, $color) {
    $this->name  = $name;
    $this->color = $color;
  }

  function __destruct() {
    echo "The fruit is {$this->name} and the color is {$this->color}.";
  }
}

$apple = new Fruit("Apple", "red");

__construct() se ejecuta automáticamente al crear el objeto; __destruct() al destruirlo o al terminar el script.

Herencia

class Fruit {
  public $name;
  public $color;

  public function __construct($name, $color) {
    $this->name  = $name;
    $this->color = $color;
  }

  public function intro() {
    echo "The fruit is {$this->name} and the color is {$this->color}.";
  }
}

class Strawberry extends Fruit {
  public function message() {
    echo "Am I a fruit or a berry? ";
  }
}

$strawberry = new Strawberry("Strawberry", "red");
$strawberry->message();
$strawberry->intro();
  • La subclase hereda propiedades y métodos públicos y protegidos.
  • La herencia va en una sola dirección: el padre no tiene lo de la hija.
  • protected no se puede llamar desde fuera, solo desde la clase o sus hijas.

Constantes de clase

class Goodbye {
  const LEAVING_MESSAGE = "Gracias a ti!";

  public function byebye() {
    echo self::LEAVING_MESSAGE;     // desde dentro
  }
}

echo Goodbye::LEAVING_MESSAGE;      // desde fuera

Se accede con :: (operador de resolución de alcance). Distinguen mayúsculas; se recomienda escribirlas en MAYÚSCULAS.

Clases y métodos abstractos

abstract class Car {
  public $name;

  public function __construct($name) {
    $this->name = $name;
  }

  abstract public function intro(): string;
}

class Audi extends Car {
  public function intro(): string {
    return "Choose German quality! I'm an $this->name!";
  }
}
Regla Detalle
Clase abstracta Tiene al menos un método abstracto.
Método abstracto Se declara pero no se implementa.
No se instancia new Car() da error.
Firma La hija debe usar el mismo nombre y modificador igual o menos restrictivo.
Argumentos Misma cantidad de requeridos; puede agregar opcionales.

Interfaces y polimorfismo

interface Animal {
  public function makeSound();
}

class Cat implements Animal {
  public function makeSound() {
    echo "Meow";
  }
}

$animal = new Cat();
$animal->makeSound();
Clase abstracta Interface
Propiedades Sí No
Visibilidad de métodos public o protected Todos public
Implementación Puede tener métodos concretos Todos abstractos
Palabra abstract Necesaria No
Herencia múltiple No Se pueden implementar varias
Palabra clave extends implements

Polimorfismo: varias clases usan la misma interfaz y se pueden tratar de la misma manera.

Traits

PHP solo admite herencia única. Los traits permiten reutilizar métodos en varias clases.

trait message1 {
  public function msg1() {
    echo "OOP is fun! ";
  }
}

trait message2 {
  public function msg2() {
    echo "OOP reduces code duplication!";
  }
}

class Welcome {
  use message1;
}

class Welcome2 {
  use message1, message2;
}

$obj2 = new Welcome2();
$obj2->msg1();
$obj2->msg2();

Los traits pueden tener métodos (con cualquier visibilidad) y métodos abstractos. Se usan con use.

Métodos y propiedades estáticas

class greeting {
  public static function welcome() {
    echo "Hello World!";
  }
}

greeting::welcome();          // sin instanciar

class pi {
  public static $value = 3.14159;
}

echo pi::$value;

class x extends pi {
  public function xStatic() {
    return parent::$value;    // desde la clase hija
  }
}
Acceso Sintaxis
Método estático Clase::metodo()
Propiedad estática Clase::$propiedad
Desde dentro de la clase self::metodo() / self::$propiedad
Desde la clase hija parent::$propiedad

Espacios de nombres

<?php
namespace Html;

class Table {
  public $title = "";
  public $numRows = 0;

  public function message() {
    echo "<p>Table '{$this->title}' has {$this->numRows} rows.</p>";
  }
}
?>

namespace Code\Html;      // anidados
use Html as H;            // alias de espacio
use Html\Table as T;      // alias de clase

La declaración namespace debe ser lo primero en el archivo.

Iterables

function printIterable(iterable $myIterable) {
  foreach ($myIterable as $item) {
    echo $item;
  }
}

$arr = ["a", "b", "c"];
printIterable($arr);

function getIterable(): iterable {
  return ["a", "b", "c"];
}

iterable (PHP 7.1+) acepta arrays y objetos Traversable.

21. Acceso a MySQL con MySQLi

MySQLi vs. PDO

MySQLi PDO
Bases soportadas Solo MySQL 12+ (PostgreSQL, SQLite, Oracle...)
Estilos Procedural y OO Solo OO
Seguridad Hay que sanitizar Exige sanitizar (prepared statements)

Pasos

  1. Conectar con el servidor.
  2. Seleccionar la base de datos.
  3. Enviar la instrucción SQL.
  4. Obtener y procesar los resultados.
  5. Cerrar la conexión.
Paso Función
Conectar mysqli_connect()
Seleccionar BD mysqli_select_db()
Enviar SQL mysqli_query()
Contar filas mysqli_num_rows()
Obtener fila mysqli_fetch_array() / mysqli_fetch_object()
Cerrar mysqli_close()

La extensión vieja mysql_* quedó obsoleta desde PHP 7. mysqli_* cambia el orden de algunos parámetros: primero la conexión.

Conexión

$conexion = mysqli_connect("localhost", "root", "pepe", "lindavista")
  or die("No se puede conectar con el servidor");

mysqli_select_db($conexion, "noticias")
  or die("No se puede seleccionar la base de datos");

Consulta y resultados

$consulta = mysqli_query($conexion, "SELECT * FROM noticias WHERE categoria='promociones'")
  or die("Fallo en la consulta");

$nfilas = mysqli_num_rows($consulta);

if ($nfilas > 0) {
  for ($i = 0; $i < $nfilas; $i++) {
    $fila = mysqli_fetch_array($consulta);

    echo "Título: " . $fila["titulo"];
    echo "Fecha: "  . $fila["fecha"];
  }
}
Acceso Sintaxis
Por nombre de campo $fila["titulo"]
Por índice numérico $fila[0] 
mysqli_close($conexion);

Insertar

$sql = "INSERT INTO noticias (titulo, copete, cuerpo, categoria, fecha)
        VALUES ('$titulo', '$copete', '$cuerpo', '$categoria', '$fecha')";

mysqli_query($conexion, $sql) or die("Fallo en la inserción");

22. Paginación y filtrado

Paginación con LIMIT

SELECT * FROM noticias LIMIT 0, 5

Recupera 5 elementos a partir de la posición 0.

SELECT * FROM noticias LIMIT $comienzo, $num
  • $num es constante (por ejemplo 5).
  • $comienzo se incrementa o decrementa en 5 al pasar de página.
  • Se pasa como parámetro en el enlace del botón.
$num = 5;
$comienzo = isset($_GET['comienzo']) ? (int) $_GET['comienzo'] : 0;

$consulta = mysqli_query($conexion,
  "SELECT * FROM noticias LIMIT $comienzo, $num");

echo "<a href='{$_SERVER['PHP_SELF']}?comienzo=" . ($comienzo + $num) . "'>Siguiente</a>";

Hay que comprobar que el nuevo valor de comienzo esté dentro de los límites de la tabla.

Filtrado con WHERE

SELECT * FROM noticias WHERE categoria = '$categoria'

<select name="categoria" onchange="actualizaPagina()">
  <option value="promociones">promociones</option>
  <option value="ofertas" selected>ofertas</option>
  <option value="costas">costas</option>
</select>

Obtener las opciones de un ENUM

SHOW COLUMNS FROM noticias LIKE 'categoria'

Devuelve, entre otras cosas:

enum("promociones","ofertas","costas")

A partir de eso se generan las opciones del <select> y se marca con selected la que vino por formulario. Así no hay que mantener la lista a mano.

23. Seguridad

Inyección SQL

Un ataque clásico: 1' OR '1'='1';#

Opciones en MySQLi:

  1. Escapar los datos (menos seguro):
$titulo = mysqli_real_escape_string($conexion, $titulo);
  1. Consultas preparadas con parámetros vinculados (más seguro):
$stmt = mysqli_prepare($conexion,
  "INSERT INTO noticias (titulo, copete, cuerpo, imagen, categoria, id_usuario, fecha)
   VALUES (?, ?, ?, ?, ?, ?, ?)");

mysqli_stmt_bind_param($stmt, 'sssssds',
  $titulo, $copete, $cuerpo, $imagen, $categoria, $id_usuario, $fecha);

mysqli_stmt_execute($stmt);
Letra Tipo
i integer
d double (float)
s string
b binary (imagen, PDF...)

Otras medidas

Riesgo Medida
XSS (scripts inyectados) htmlspecialchars($texto, ENT_QUOTES, 'UTF-8') al mostrar.
Inyección SQL Consultas preparadas; nunca concatenar entrada del usuario.
Contraseñas password_hash() / password_verify(); nunca texto plano.
Subida de archivos Validar extensión, MIME y tamaño; generar nombre único; guardar fuera del webroot si es posible.
Sesiones session_regenerate_id() al iniciar sesión; session_start() antes de todo.
Datos del formulario Validar y filtrar siempre en el servidor.

// Mostrar texto seguro
echo htmlspecialchars($_POST['comentario'], ENT_QUOTES, 'UTF-8');

// Contraseñas
$hash = password_hash($clave, PASSWORD_DEFAULT);

  // correcto
}

24. Errores típicos y checklist

Error Causa Solución
Se ve el código PHP en el navegador El servidor no interpreta PHP o el archivo es .html. Usar extensión .php y verificar Apache/módulo.
Undefined variable La variable no está definida en ese ámbito. Inicializar o usar ??.
Headers already sent setcookie() o session_start() después de HTML. Ponerlos al inicio, antes de cualquier salida.
El formulario llega vacío Los campos no tienen name. Agregar name a cada control.
No llega el archivo Falta enctype="multipart/form-data". Agregarlo al <form>.
El archivo subido no aparece Se leyó $_POST en vez de $_FILES. Usar $_FILES y move_uploaded_file().
move_uploaded_file() falla Permisos de la carpeta destino. Dar permisos de escritura.
La consulta falla SQL mal escrito o conexión inválida. Revisar con mysqli_error($conexion).
Acentos rotos Codificación distinta entre PHP, HTML y BD. UTF-8 en todos lados (set_charset("utf8mb4")).
Fechas corridas Zona horaria del servidor. date_default_timezone_set().
session_start() avisa que la sesión ya existe Se llama dos veces. Verificar con session_status().
La cookie no se lee Todavía no se recargó la página. Recargar o redirigir.
$_POST['x'] da error si no existe No se envió ese campo. isset() / empty() / ??.
Concatenar arrays da "Array" Se usó . con un array. implode() o print_r().

Checklist antes de entregar

  • [ ] Todos los archivos con extensión .php.
  • [ ] session_start() y setcookie() antes de cualquier HTML.
  • [ ] Formularios con action, method y name en todos los campos.
  • [ ] enctype="multipart/form-data" si hay archivos.
  • [ ] Datos del usuario validados y escapados en el servidor.
  • [ ] Consultas SQL con prepared statements (o al menos mysqli_real_escape_string).
  • [ ] Contraseñas con password_hash().
  • [ ] Conexión a la base cerrada con mysqli_close().
  • [ ] Errores controlados (or die, try/catch, validación).
  • [ ] UTF-8 en HTML, PHP y base de datos.
  • [ ] Zona horaria configurada si se usa fecha/hora.
  • [ ] Sin var_dump() ni print_r() de depuración en la entrega.
  • [ ] display_errors desactivado en producción.

<?php

ini_set('display_errors', '1');

date_default_timezone_set("America/Argentina/Salta");

session_start();

// ===== 2. Conexión =====
$conexion = mysqli_connect("localhost", "root", "", "lindavista")
  or die("No se pudo conectar con el servidor");

mysqli_set_charset($conexion, "utf8mb4");

// ===== 3. Datos de entrada =====
$errores = [];
$enviado = ($_SERVER['REQUEST_METHOD'] === 'POST');

$titulo    = trim($_POST['titulo'] ?? '');
$categoria = $_POST['categoria'] ?? '';
$cuerpo    = trim($_POST['cuerpo'] ?? '');

// ===== 4. Validación =====
if ($enviado) {
  if ($titulo === '') {
    $errores[] = "El título es obligatorio.";
  }

  if (!in_array($categoria, ['promociones', 'ofertas', 'costas'], true)) {
    $errores[] = "Categoría inválida.";
  }

  if (strlen($cuerpo) < 10) {
    $errores[] = "El cuerpo debe tener al menos 10 caracteres.";
  }
}

// ===== 5. Procesamiento =====
if ($enviado && empty($errores)) {
  $stmt = mysqli_prepare($conexion,
    "INSERT INTO noticias (titulo, cuerpo, categoria, fecha)
     VALUES (?, ?, ?, ?)");

  $fecha = date("Y-m-d");

  mysqli_stmt_bind_param($stmt, 'ssss', $titulo, $cuerpo, $categoria, $fecha);
  mysqli_stmt_execute($stmt);
  mysqli_stmt_close($stmt);

  header("Location: lista_noticias.php");
  exit;
}

// ===== 6. Listado paginado =====
$num      = 5;
$comienzo = isset($_GET['comienzo']) ? max(0, (int) $_GET['comienzo']) : 0;

$consulta = mysqli_query($conexion,
  "SELECT * FROM noticias ORDER BY fecha DESC LIMIT $comienzo, $num");

$nfilas = mysqli_num_rows($consulta);
?>

      <article>
        <h2><?= htmlspecialchars($fila["titulo"], ENT_QUOTES, 'UTF-8') ?></h2>

        <small><?= htmlspecialchars($fila["fecha"], ENT_QUOTES, 'UTF-8') ?></small>
