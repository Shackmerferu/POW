jQuery – AJAX – Load()
➢Metodo Load()
▪Es el método mas simple de Ajax con jQuery
▪El resultado devuelto es colocado en un contendor
▪Solo muestra el texto, si el texto devuelto tiene etiquetas html no las muestra.
$(selector).load(URL,data,callback);
URL: Valor requerido, Dirección de la url que se desa llamar
data: (opcional) es la dupla clave/valor de los datos que se enviaran al servidor
callback: es opcional, es el nombre de una función que se ejecutará después de que se
complete el método load ().

jQuery – AJAX – get() y post()
➢Metodos get() y post()
▪Se utilizan para solicitar datos del servidor con una solicitud HTTP GET o POST.
▪GET: solicita datos de un recurso específico. Se usa básicamente para obtener (recuperar)
algunos datos del servidor. Este método puede devolver datos almacenados en cache.
▪POST: envía datos para su procesamiento a un recurso específico. POST también se
puede utilizar para obtener algunos datos del servidor. Sin embargo, el método POST
NUNCA almacena datos en caché
▪Respeta el contenido devuelto, si la respuesta tiene etiquetas html las interpetara el
navegador.

===== PAGINA 40 (960.00 x 540.00) =====
jQuery – AJAX – ajax()
$.ajax({
url: "ruta/del/servidor.php",   // URL a la que se hace la petición
type: "GET",                   // Método HTTP: GET, POST, PUT, DELETE
data: { nombre: "Juan", edad: 25 }, // Datos que se envían al 
servidor
dataType: "json",              // Tipo de datos esperados en la 
respuesta: json, text, html, xml
timeout: 5000,                 // Tiempo máximo de espera (en 
milisegundos)
beforeSend: function(xhr) {
// Se ejecuta antes de enviar la petición
console.log("Enviando petición...");
},
success: function(response, status, xhr) {
// Se ejecuta si la petición fue exitosa
console.log("Respuesta:", response);
console.log("Estado:", status); // "success"
console.log("Código HTTP:", xhr.status);
},
error: function(xhr, status, error) {
// Se ejecuta si ocurre un error
console.error("Error:", error);
console.error("Estado:", status);
console.error("Código HTTP:", xhr.status);
},
complete: function(xhr, status) {
// Se ejecuta siempre (éxito o error)
console.log("Petición finalizada con estado:", status);
}
});

===== PAGINA 41 (960.00 x 540.00) =====
jQuery – AJAX – ajax()
Parámetros más comunes de $.ajax()
➢url →la dirección a la que se envía la petición.
➢type o method →método HTTP (GET, POST, etc.).
➢data →datos a enviar al servidor.
➢dataType →formato esperado de la respuesta (json, xml, html, text).
➢timeout →tiempo máximo de espera.
➢beforeSend →callback antes de enviar la petición.
➢success →callback cuando la petición se resuelve correctamente.
➢error →callback cuando ocurre un error.
➢complete →callback que se ejecuta al final, sin importar éxito o error.

jQuery – noConflict() Method
➢¿Qué sucede si desea usar otros marcos en sus páginas, mientras sigue usando
jQuery?
▪jQuery usa el signo $ como atajo para jQuery.
▪Hay muchos otros marcos de JavaScript populares como: Angular, Backbone,
Ember, Knockout, prototype y más.
▪Si dos frameworks diferentes están usando el mismo atajo, uno de ellos podría
dejar de funcionar.
▪El equipo de jQuery ya ha pensado en esto e implementó el método noConflict ().
.
