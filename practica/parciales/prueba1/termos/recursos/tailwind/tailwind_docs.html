Guía interactiva 100% offline impulsada por la distribución local en tailwindcss-v4-dist/tailwindcss-browser.js. Incluye la guía oficial de instalación con Vite, todas las utilidades de diseño y los 24 componentes de interfaz equivalentes a Bootstrap listos para copiar.

Instalación de Tailwind CSS v4 usando Vite

@tailwindcss/vite

La forma recomendada de integrar Tailwind CSS v4 en proyectos modernos (React, Vue, Svelte o Vanilla JS) es utilizando el plugin dedicado de primera clase para Vite (extraído de https://tailwindcss.com/docs/installation/using-vite):

Paso 1 y 2 — Crear el proyecto Vite e instalar Tailwind CSS v4
Paso 3 — Configurar el plugin de Vite en vite.config.ts
Paso 4 y 5 — Importar Tailwind en tu CSS (src/style.css) y ejecutar npm run dev

Uso Local 100% Offline sin Node.js (tailwindcss-v4-dist)

@tailwindcss/browser v4.3.3

Para trabajar directamente en archivos HTML o en servidores PHP/XAMPP sin necesidad de ejecutar un servidor Vite, hemos descargado el motor compilador oficial de navegador de Tailwind v4 en tailwindcss-v4-dist/tailwindcss-browser.js. Solo debes enlazarlo con una etiqueta <script> y compilará en vivo cualquier clase de utilidad o directiva @theme / @utility que escribas.

Modo Oscuro (dark:*)

@custom-variant dark

En Tailwind CSS v4 puedes prefijar cualquier utilidad con dark: (por ejemplo bg-white dark:bg-slate-800) para definir cómo se ve en modo oscuro. Para controlarlo manualmente mediante la clase .dark en la etiqueta <html>, declara @custom-variant dark (&:where(.dark, .dark *));.

Diseño Responsivo (Breakpoints) y Contenedores

sm: / md: / lg: / xl: / 2xl: / max-w-*

Tailwind utiliza un sistema mobile-first: las clases sin prefijo aplican a todas las pantallas, y las clases con prefijo (sm:, md:, lg:, xl:, 2xl:) se aplican desde ese ancho mínimo en adelante:

Prefijo Ancho Mínimo Media Query CSS Generada
sm:640px (40rem)@media (width >= 40rem)
md:768px (48rem)@media (width >= 48rem)
lg:1024px (64rem)@media (width >= 64rem)
xl:1280px (80rem)@media (width >= 80rem)
2xl:1536px (96rem)@media (width >= 96rem)
Contenedor centrado con ancho máximo y padding responsivo
max-w-4xl mx-auto px-4 sm:px-6 lg:px-8

Sistema CSS Grid y Flexbox

grid / grid-cols-* / col-span-* / flex / gap-*

A diferencia del sistema rígido de 12 columnas de Bootstrap, en Tailwind puedes crear grillas de cualquier número de columnas con grid grid-cols-{n}, hacer que una celda abarque varias columnas con col-span-{n} y alinear elementos con Flexbox (flex items-center justify-between gap-4).

Checks, Radios y Switches con Estado peer

accent-* / peer / peer-checked:*

La clase peer de Tailwind permite estilizar un elemento hermano cuando un checkbox o radio está marcado (peer-checked:bg-sky-600, peer-checked:translate-x-5), lo que permite construir interruptores (Switches) y tarjetas seleccionables 100% en CSS sin JavaScript.

¿Cómo funciona Tailwind CSS v4 con Vite? ▼

El plugin @tailwindcss/vite detecta automáticamente todas las clases utilizadas en tus plantillas y genera únicamente el CSS necesario en milisegundos.

¿Necesito un archivo tailwind.config.js en v4? ▼

No. En Tailwind CSS v4 la configuración es CSS-first usando la directiva @theme { ... } directamente dentro de tu archivo CSS principal.

¿Puedo usarlo offline en clases prácticas? ▼

Sí, enlazando el archivo local tailwindcss-v4-dist/tailwindcss-browser.js incluido en esta carpeta.
