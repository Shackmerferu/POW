## ✨ Descripción

Portfolio web personal con un diseño **minimalista y pop**, inspirado en la paleta de colores **violeta, negro y blanco**. Incluye animaciones suaves, sombras vibrantes, modos **oscuro y claro** y una galería de proyectos traídos directamente de mi GitHub.

---

## 🚀 Características

- 🎨 **Diseño minimalista pop** con acentos violetas
- 🌗 **Modo oscuro / claro** con persistencia en `localStorage`
- 💫 **Animaciones y transiciones** suaves (hover, reveal on scroll, barras de skills)
- 🧊 **Sombras** color violeta en tarjetas y botones
- 📱 **Responsive** en todos los tamaños de pantalla
- 🖼️ **Galería de proyectos** automatizada desde mis repos públicos

---

## 🧱 Stack

| Tecnología | Uso |

## 🛠️ Personalización

Cada tarjeta de proyecto en `index.html` tiene una imagen con un **border redondeado de 16px**. Solo reemplaza el valor `RUTA imagen.jpg` por la ruta de tu captura:

```html
<div class="project-image">
  <img src="tu-imagen.jpg" alt="Nombre del proyecto">
</div>
```
