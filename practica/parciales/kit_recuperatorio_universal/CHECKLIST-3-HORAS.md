# Checklist de ejecución en 180 minutos

- [ ] 0–10 min: leer consigna y listar entidades, tablas, endpoints y pantallas.
- [ ] 10–20 min: importar SQL, comprobar conexión, rutas y API.
- [ ] 20–35 min: login, token y acceso al panel.
- [ ] 35–80 min: listado, alta, edición y baja de entidad principal.
- [ ] 80–105 min: consulta/búsqueda especial (DNI/código).
- [ ] 105–135 min: registro con imagen y campos/metadatos requeridos.
- [ ] 135–155 min: modal, detalles y maquetado faltante.
- [ ] 155–170 min: probar cada operación desde el navegador.
- [ ] 170–180 min: corregir errores, revisar consola, rutas y entrega.

## Antes de copiar
- [ ] Confirmé la ruta real de la API.
- [ ] Confirmé los nombres exactos de parámetros.
- [ ] Confirmé la estructura JSON de cada endpoint.
- [ ] Confirmé cómo se envía el token.
- [ ] Confirmé si el alta/edición recibe POST o JSON.
- [ ] Confirmé nombre y tipo de archivo de imagen.
- [ ] Probé cada endpoint de forma aislada.

## Regla de oro
No pierdas 30 minutos intentando adaptar un archivo genérico sin mirar primero qué recibe y devuelve la API del profesor.
