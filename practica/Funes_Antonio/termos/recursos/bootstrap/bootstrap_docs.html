Introducción y Plantilla Inicial (Starter Template)

Getting Started

Bootstrap es un potente toolkit frontend repleto de funciones para construir sitios responsivos ("mobile-first"). Para utilizarlo de manera offline mediante la carpeta local bootstrap-5.3.8-dist, solo debes enlazar bootstrap.min.css en el <head> y bootstrap.bundle.min.js (que ya incluye Popper para Dropdowns, Popovers y Tooltips) antes de cerrar el </body>.

Utilidades (Espaciado, Flexbox, Colores, Bordes y Sombras)

.m-* / .p-* / .d-flex / .shadow-* / .rounded-*

La API de utilidades de Bootstrap permite diseñar sin escribir CSS adicional:

  • Espaciado (Margin / Padding): {m|p}{t|b|s|e|x|y}-{0..5|auto} (ej. .mt-3, .px-4, .mx-auto).
  • Flexbox: .d-flex, .justify-content-between, .align-items-center, .flex-wrap, .gap-3.
  • Colores y Fondos: .text-primary, .bg-body-secondary, .bg-opacity-25, .text-bg-dark.
  • Bordes y Sombras: .border, .border-primary, .rounded-3, .rounded-circle, .shadow-sm, .shadow, .shadow-lg.
